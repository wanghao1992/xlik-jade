# 天赋「剑气」实现计划

## 一、需求概述

新增一组 5 张逐级天赋卡（qi1 ~ qi5）。玩家学会 qi1 后，普通攻击命中时有几率向**攻击方向**发射一道穿透剑气：

- 剑气沿直线向前飞行，路径上每个敌人各受一次伤害（同一次剑气对同一敌人不重复命中）
- 伤害口径：本次普攻实际伤害 × 倍率，**物理伤害**，走天赋机制伤害流程（不触发分裂等二次机制）
- qi2 ~ qi5 逐级提升：触发几率、伤害倍率、飞行距离、判定宽度
- 近战/远程英雄均可触发，与分裂、闪电链的触发范围口径一致

#### (4) 新增剑气发射实现

插入位置：法球 `startOrbit` 实现之后、普攻事件 `slkc_talent_mech` 之前（当前 [L1427-L1431](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua#L1427-L1431)）。此处 `enemiesAround`、`talentMechanicDamage` 均已定义。

```lua
--- ==== 剑气系统 ====
local QI_MODEL = "剑气.mdx"          -- model_self.lua 中声明的 jianqi01 别名
local QI_SPEED = 1800                -- 飞行速度(px/秒)
local QI_SCALE = 1.0                 -- 模型缩放(进图后按视觉调)
local QI_HIT_SCALE = 1.8             -- 命中特效缩放

--- 普攻命中后按几率向攻击方向发射穿透剑气
--- 参数取 hero._attr['剑气几率'|'剑气倍率'|'剑气距离'|'剑气宽度']
---@param hero Unit
---@param target Unit
---@param base number 本次普攻伤害
---@return void
local function fireSwordQi(hero, target, base)
    local attr = hero._attr or {}
    local chance = attr["剑气几率"] or 0
    if (chance <= 0 or math.rand(1, 100) > chance) then
        return
    end
    local ratio = attr["剑气倍率"] or 0.60
    local distance = attr["剑气距离"] or 700
    local width = attr["剑气宽度"] or 120
    local owner = hero:owner()
    local hx, hy = hero:x(), hero:y()
    local facing = vector2.angle(hx, hy, target:x(), target:y())
    local tx, ty = vector2.polar(hx, hy, distance, facing)
    local amount = base * ratio
    --- 同一次剑气对同一敌人只结算一次
    local hit = {}
    ability.missile({
        model = QI_MODEL,
        sourceUnit = hero,
        targetVec = { tx, ty },
        speed = QI_SPEED,
        scale = QI_SCALE,
        height = 0,
        onMove = function(_, vec)
            if (false == class.isObject(hero, UnitClass) or true == hero:isDead()) then
                return false
            end
            local list = enemiesAround(vec[1], vec[2], width, owner, nil)
            for _, u in ipairs(list) do
                local h = u:handle()
                if (nil == hit[h]) then
                    hit[h] = true
                    job.pointEffect([[Abilities\Spells\Other\Cleave\CleaveDamageTarget.mdl]], u:x(), u:y(), u:z(), 0.5, QI_HIT_SCALE)
                    talentMechanicDamage(hero, u, amount, injury.damageType.physics)
                end
            end
            return true
        end,
    })
end
```

## 五、假设与决策

1. 沿用项目「机制卡 1 级/张、逐级依赖 I→V」结构，与分裂/多重箭/闪电链/法球一致。
2. 触发条件为**普通攻击命中**（`unitAttack`），近战/远程均可；不做武器类型限制。
3. 方向取英雄与本次攻击目标的连线（普攻时英雄必然面向目标），即用户描述的「向前」。
4. 剑气**穿透**路径上所有敌人，同一道剑气对同一敌人只结算一次；伤害为物理伤害并走 `talentMechanicDamage`，避免与专属装备/分裂等互相触发。
5. 剑气伤害基于 `evtData.damage`（本次普攻实际伤害），因此会随暴击、攻击力成长同步放大。
6. 投射物使用框架图 `resource/特效/剑气.mdx`（复制为 `tx/jianqi02.mdx`），7 张贴图复制到 `war3mapTextures` 并已改写模型 TEXS 路径。
7. 模型朝向按「+X 为前进方向」处理（`ability.missile` 自动 `rotateZ` 朝向）；若进图发现朝向/大小异常，仅调整 `QI_SCALE` 与模型别名即可，不改逻辑。
8. 数值为初版：冷却 15→10 秒（逐级 15/14/13/12/10）、倍率 60%→120%、距离 1500→2500、宽度 500→1000；后续可按实测强弱直接改 `TALENT_EFFECTS` 中的四个 `setExtra`。

## 六、验证步骤

1. 构建（不加密 + 热更新调试）：`.\xlik.exe run demo -t`；确认无 Lua 报错、无资源缺失/「可能未曾使用」相关告警。
2. 进图后用测试命令获取天赋点，反复打开天赋面板直到出现「剑气·出鞘」，学会后：
   - 攻击小怪，观察是否按约 5% 几率从英雄位置向目标方向飞出月牙剑气；
   - 剑气穿过多个敌人时，每个敌人只掉一次血，且命中点有斩击特效；
   - 确认剑气造成的是物理伤害，且不会引发分裂/闪电链/法球等二次机制连锁。
3. 依次学会 qi2 ~ qi5，核对几率、伤害、射程、宽度是否随描述提升。
4. 观察剑气模型的朝向、大小与飞行速度；如视觉异常，调整 `QI_SCALE`（大小）或 `QI_SPEED`（速度）后重新构建。
5. 让英雄在剑气飞行途中死亡/被销毁，确认无报错、无残留特效。
6. 回归检查：法球、分裂、多重箭、闪电链仍正常触发（同一普攻事件内多机制共存）。
