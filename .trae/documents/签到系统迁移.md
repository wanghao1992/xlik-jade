# 签到系统迁移（老图 死灵狂潮 → xlik-jade demo）

## 一、目标与范围

把老图 [内容/签到](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E7%AD%BE%E5%88%B0) 搬进 demo：

- **6 轮 × 7 天**奖励（每轮奖励完全相同，只有计数槽位与提示文字不同），照搬老图数值与图标。
- **每日只能签到一次**，判定基准 = 服务器时间的**自然日**（北京时间 UTC+8），每天推进 1 天，满 7 天该轮结束（玩家切到下一轮继续签）。
- 面板：新建独立套件 `xlik_qiandao`，照老图布局（左侧轮次列表 + 7 个天格子横排 + 底部「签到」按钮 + 关闭）。
- 入口：功能栏「签到(F4)」（当前是 `print` 占位），交互与「存档(F2)」一致。
- 存储：照搬老图存档键（组 `签到` → 平台 key `k9`，位宽 1；单值键 `QDDATE`），复用 demo 已有 [存档.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/存档.lua) 的位宽打包底层。

**明确不做（已确认，代码内留注释 + TODO）**：

- **第 7 天的「解锁一个衣柜里的装扮」**：demo 无衣柜系统、也无装扮模型资源 → 第 7 天只落地属性奖励（伤害增幅 +1.5%），衣柜部分**只预留接口**（面板 tips 标注「衣柜装扮（待衣柜系统接入）」，代码注释标注老图做法：满 7 天后衣柜内某装扮的 `check_condition` 满足，见 [衣柜/数据.lua:182-220](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E8%A1%A3%E6%9F%9C/%E6%95%B0%E6%8D%AE.lua#L182-L220)）。
- **「新春签到」（完成游戏 +1 新春积分 `XC`）**：与签到面板是两套东西，本次不做。
- **老图客户端的反作弊时间分支**（`yday - qd_day == 1` + `time.hour < h0`，[类声明.lua:307-317](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E7%AD%BE%E5%88%B0/%E7%95%8C%E9%9D%A2/%E5%AE%A2%E6%88%B7%E7%AB%AF/%E7%B1%BB%E5%A3%B0%E6%98%8E.lua#L307-L317)）：本版改为服务端按自然日判定，不做该分支（代码注释标注来源行号）。
- **老图遗留键 `QD%d`**（[数据.lua:15](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E7%AD%BE%E5%88%B0/%E6%95%B0%E6%8D%AE.lua#L15) 里参与天数计算，但全图**没有任何地方写入**，仅在单机预设里被置 0）→ 本版不读该键，天数只取 `签到` 组。
- **老图自定义图片资源**（`签到2\签到特效 (N).blp`、`通用边框.tga`、`Frame\64禁用图层.tga`）→ demo 没有，改用框架通用资源（见 §3.3），不新增图片文件。

### 2.3 差异点

| 老图 | demo 落地 |
|---|---|
| 客户端直接读平台存档（`get_key` / `get_server_value2`）做判定 | 客户端不读存档：点击 → `sync.send` → 服务端校验 + 写入 → 下发数据刷新面板（与 xlik_save / xlik_treasure 一致） |
| `lost.attribute{永久= true, 不重置 = true, name=..., value=..., source='签到存档'}` | 复用 `saveFlow.applyAttr`（`hero:attack/defend/hp/str/agi/int` + `hero:ampl` + `hero._attr`） |

**自然日（服务端权威）**：

```lua
local BJ_OFFSET = 8 * 3600    --- 北京时间
local MIN_VALID_TS = 946684800  --- 2000-01-01, 小于该值视为平台时间不可用

--- 今天(北京时间自然日) -> 20260921
--- 平台时间不可用(离线/未取到开局时间)时回退 os.time()
local function today()
    local ts = time.unix()
    if (type(ts) ~= 'number' or ts < MIN_VALID_TS) then
        ts = os.time()
    end
    local d = time.date(ts + BJ_OFFSET)
    return tonumber(d.Y) * 10000 + tonumber(d.m) * 100 + tonumber(d.d)
end
```
