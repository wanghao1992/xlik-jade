# 天赋「环绕法球」实现计划

## 一、需求概述

新增一组 5 张逐级天赋卡（orb1 ~ orb5）。玩家学会 orb1 后，英雄周围生成 3 个法球环绕自身旋转：

- 旋转半径由小到大再由大到小循环：`100 → 600 → 100`
- 法球撞击敌人造成伤害：`(500 + 智力 × 100%) × (1 + 英雄等级 × 0.02)`
- 伤害类型：**法术伤害**
- 命中频率：**每个法球独立 0.5 秒冷却**（同一敌人可被不同法球分别命中）
- orb2 ~ orb5 逐级提升伤害系数、最大半径与撞击冷却（详见下表）

#### (5) 环绕系统实现

插入位置：`chainLightningHit` 之后、普攻命中事件 `slkc_talent_mech` 之前（约 [L1145](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua#L1144-L1146)）。此处 `enemiesAround`、`talentMechanicDamage` 均已定义。

常量：

```lua
local ORB_COUNT = 3              -- 法球数量
local ORB_TICK = 0.05            -- 刷新间隔(秒)
local ORB_RADIUS_MIN = 100       -- 最小半径
local ORB_CYCLE = 4.0            -- 半径一个往返周期(2秒放大 + 2秒收缩)
local ORB_ANGULAR_SPEED = 120    -- 角速度(度/秒)
local ORB_HIT_RADIUS = 90        -- 法球命中判定半径
local ORB_HEIGHT = 60            -- 法球离地高度
local ORB_MODEL = [[Abilities\Weapons\SpiritOfVengeanceMissile\SpiritOfVengeanceMissile.mdl]]
```

具体逻辑：

1. `stopOrbit(hero)`：取 `hero._talentOrbState`，置空后 `class.destroy(timer)` 并 `effector.destroy` 全部法球。
2. `startOrbit = function(hero)`
   - 非 Unit 或已销毁直接 return；`hero._talentOrbState` 已存在则 return（防止重复启动）。
   - 状态：`{ orbs = {}, cd = {}, tick = 0, elapsed = 0, angle = 0, hidden = false }`。
   - 以英雄为中心按 `i × 120°`、半径 `ORB_RADIUS_MIN` 创建 3 个 `effector.agile(ORB_MODEL, x, y, japi.Z(x,y) + ORB_HEIGHT)`。
   - `time.setInterval(ORB_TICK, fn)`：
     - 英雄已销毁 → `stopOrbit(hero)` 后 return。
     - 英雄死亡 → 首次 `effector.visible(orb, false)` 后 return；复活后恢复可见。
     - `state.tick = state.tick + 1`；`state.elapsed` 累加；`state.angle` 按角速度推进。
     - 半径三角波：`phase = (elapsed % ORB_CYCLE) / ORB_CYCLE`；`t = phase<=0.5 ? phase*2 : (1-phase)*2`；`radius = 100 + (maxR-100)*t`。
     - 一次性取敌：`enemiesAround(hero:x(), hero:y(), maxR + ORB_HIT_RADIUS, owner, nil)`。
     - 对每个法球：计算坐标 → `effector.position` 移动 → 遍历敌人：
       - 按 `state.cd[i][u:handle()]` 判冷却（tick 计数制：`到期tick = state.tick + math.floor(cd/ORB_TICK + 0.5)`）。
       - 距离平方 ≤ `ORB_HIT_RADIUS²` 才命中；命中后写冷却、挂命中特效（`CleaveDamageTarget.mdl`，`effector.point`，0.5 秒）、调用 `talentMechanicDamage(hero, u, (500+int)×(1+lvl×0.02)×coeff, injury.damageType.magic)`。
     - 每 tick 清理已过期的冷却键，避免表无限增长。

关键取数：

```lua
local attr = hero._attr or {}
local coeff = attr["法球伤害系数"] or 1.00
local maxR = attr["法球最大半径"] or 600
local cd = attr["法球命中冷却"] or 0.50
local intVal = hero:int() or 0
local lv = tonumber(hero:level()) or 1
local amount = (500 + intVal) * (1 + lv * 0.02) * coeff
```

## 五、假设与决策

1. 系列沿用项目「机制卡 1 级/张、逐级依赖 I→V」的统一结构；基础形态即用户描述的 100-600-100。
2. orb2~orb5 在基础形态上叠加：伤害系数 +15%/级、最大半径 +50/级、冷却在第 3/5 级各 -0.05 秒（与分裂卡「范围 +50/级、倍率递增」的节奏一致）。若希望半径恒为 600，只需把各卡 `法球最大半径` 改为 600。
3. 伤害按**法术伤害**、走 `talentMechanicDamage`（与现有天赋机制伤害同一条流程，避免触发专属装备等普攻机制）。
4. 冷却按**每个法球独立**记录，键为敌方单位 `handle`，用 tick 计数而非系统时钟，避免时钟依赖。
5. 英雄死亡时隐藏法球并暂停结算，复活后自动恢复；英雄销毁时自动清理计时器与特效。
6. 天赋为局内成长、不跨局存档，因此不处理读档重建；`startOrbit` 自身做幂等保护。
