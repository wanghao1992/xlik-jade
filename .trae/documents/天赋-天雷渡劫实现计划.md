# 天赋「天雷·渡劫」实现计划

## 一、需求概述

新增一组 5 张逐级天赋卡（`thunder1` ~ `thunder5`），走现有「机制卡」体系：

- **被动触发**：英雄受到攻击时按概率触发，带内置冷却（不占技能栏）。
- **雷劫化身**：触发后在英雄当前位置生成一个与英雄同模型、同缩放的化身；化身缓缓升空、无敌、暂停、无碰撞，**英雄本体不改变状态**。
- **嘲讽**：化身升空期间，每 0.5 秒对 2000 码内敌人重发「攻击化身」命令，把怪聚到化身脚下。
- **落雷**：雷暴持续 5 秒，每 0.25 秒在化身 1500 码内随机选取 1 个敌人落雷，对主目标造成全额法术伤害（共 20 次），并对主目标 300 码内其他敌人造成主目标伤害 40% 的溅射伤害（30%~50% 可调）。
- **演出**：化身周围雷电环绕、上空乌云密布、随机环境雷击、命中落雷柱 + 地面冲击环。
- **伤害**：按主属性成长，单次 = 基础值 + 主属性 ×（系数 + 英雄等级 × 成长）。

## 四、特效演出设计

### 4.1 起手（t=0）

- 在英雄当前位置创建「雷劫化身」：与英雄同模型、同缩放；无敌、暂停、无碰撞、无攻击、无技能/物品栏。
- 化身 `origin` 附着 `LightningShieldTarget`，形成环绕电球。
- 以化身为中心生成 5 团 `CloudOfFog`（蓝色乌云），位置在化身周围 200~480 码、高度约 620~820，缩放 4~6，颜色压暗为 `(55,65,85,220)`，随机朝向，持续到雷暴结束。
- 可叠加一层 `MonsoonRain` 雨幕（可选，若画面过重则去掉）。

### 4.2 升空（t=0 ~ 1.0 秒）

- 化身 `flyHeight` 从 0 平滑升到 450，使用 `0.05` 秒周期 + easeOut 曲线，避免瞬移。
- 升空期间环境雷击：每 0.2 秒从云层高度向化身周围 120~520 码随机地面点劈一道 `thunderFork` 闪电，并在落点播 `MonsoonBoltTarget`。

### 4.3 雷暴（t=0 ~ 5.0 秒）

- **落雷结算**：每 0.25 秒取化身 1500 码内存活敌人（排除建筑），随机选 1 个主目标：
  - 目标点播 `MonsoonBoltTarget`（雷柱）
  - 目标脚下播 `ThunderClapCaster`（地面冲击环，缩放 1.2）
  - 从云层高度到目标 `h()` 拉一条 `lightning.kind.thunderShot` 闪电（0.2 秒）
  - 主目标走 `talentMechanicDamage(hero, target, amount, injury.damageType.magic)` 全额伤害
  - 再取主目标 300 码内其他敌人（排除主目标），每人走 `talentMechanicDamage(hero, u, amount * 0.40, injury.damageType.magic)` 溅射伤害，并挂 `CleaveDamageTarget` 命中特效
- **环境雷**：每 0.25 秒在化身周围随机方向、120~520 码处补一道无伤害闪电，保证画面连续。
- **嘲讽**：每 0.5 秒对化身 2000 码内敌人（排除建筑）执行 `orderAttackTargetUnit(avatar)`，把敌人持续拉向化身。
- 化身处于 `pause + invulnerable`，敌人会围过来攻击但打不掉血；英雄本体照常行动。

### 4.4 收尾（t=5.0 ~ 5.8 秒）

- 停止落雷与嘲讽。
- 化身 `flyHeight` 从 450 平滑降回 0，落地时播一次 `ThunderClapCaster`（缩放 2.0）。
- `class.destroy(avatar)`，清空 `hero._talentThunderState`；乌云/闪电/雷柱按自身 duration 自然消失。

## 五、伤害设计

单次落雷主目标伤害：

```text
主目标伤害 = 基础值 + 主属性 × (系数 + 英雄等级 × 等级成长)
```

主目标 300 码内其他敌人：

```text
溅射伤害 = 主目标伤害 × 0.40   -- 需求允许 30%~50%，实现为可调常量
```

一次触发总伤害（20 次落雷，全部命中同一主目标时）：

| 等级 | 基础值合计 | 主属性系数合计 | 等级成长合计 |
| --- | --- | --- | --- |
| I | 5000 | 9.0 | 0.40 |
| II | 6000 | 11.0 | 0.50 |
| III | 7000 | 13.0 | 0.60 |
| IV | 8000 | 15.0 | 0.70 |
| V | 10000 | 18.0 | 0.80 |

> 上表只统计主目标；主目标 300 码内每多一个敌人，还会额外吃到 40% 的溅射伤害。

- 伤害类型：法术（`injury.damageType.magic`），吃目标的法术抗性。
- 伤害来源：**英雄本体**（不是化身），保证击杀归属、经验/金币、法术增伤、杀敌事件都记在英雄身上。
- 主目标与溅射目标都走 `talentMechanicDamage`，带 `_slkcMechanic/_extraDamage` 标记，不会再次触发分裂、闪电链、剑气等机制。
- 溅射范围固定 300 码，排除主目标，避免主目标被结算两次；怪越密集，单次落雷的总收益越高。
- 随机目标每次独立掷骰，同一敌人可被连续命中；怪多时伤害自然分散，单体 BOSS 时 20 次全中。
- 数值为初版，后续只需改 `TALENT_EFFECTS` 里的 5 个 `_attr` 数值即可调整。

local function thunderParams(hero)

    if (odds <= 0) then

    return {
        odds = odds,

local function thunderStrike(hero, avatar, params)
    local list = job.enemiesAround(avatar:x(), avatar:y(), params.search, hero, nil)
    local targets = {}
    for _, u in ipairs(list) do
        if (false == u:isBuilding()) then
            targets[#targets + 1] = u
        end
    end
    if (#targets <= 0) then
        return
    end
    local u = targets[math.rand(1, #targets)]
    local ux, uy, uz = u:x(), u:y(), u:z()
    job.pointEffect(THUNDER_BOLT_MODEL, ux, uy, uz, 0)
    job.pointEffect(THUNDER_IMPACT_MODEL, ux, uy, uz, 0.4, 1.2)
    lightning.create(lightning.kind.thunderShot, ux, uy, uz + 800, ux, uy, u:h(), 0.2)
    local amount = params.base + job.primary(hero) * (params.coeff + job.level(hero) * params.growth)
    --- 主目标全额伤害
    talentMechanicDamage(hero, u, amount, injury.damageType.magic)
    --- 主目标周围 300 码内其他敌人: 30%~50% 溅射(默认 40%), 排除主目标
    local splashList = job.enemiesAround(ux, uy, params.splash, hero, u)
    for _, other in ipairs(splashList) do
        if (false == other:isBuilding()) then
            effector.attach(other, [[Abilities\Spells\Other\Cleave\CleaveDamageTarget.mdl]], "origin", 0.5)
            talentMechanicDamage(hero, other, amount * params.splashRatio, injury.damageType.magic)
        end
    end
end

#### (5) 注册受击触发事件

插入位置：`slkc_talent_killattr` 事件之后、`cfg` 函数之前（当前 [L1668-L1688](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua#L1668-L1688)）。

```lua
--- 天雷: 受到攻击时按概率触发(内置冷却, 不叠加)
event.syncRegister(UnitClass, eventKind.unitHurt, "slkc_talent_thunder", function(evtData)
    ---@type Unit
    local hero = evtData.triggerUnit
    if (false == class.isObject(hero, UnitClass) or true == hero:isDead()) then
        return
    end
    --- 仅普通攻击/攻击类伤害触发, 机制附加伤害不触发
    if (evtData.damageSrc ~= injury.damageSrc.attack or job.isExtraDamage(evtData)) then
        return
    end
    local params = thunderParams(hero)
    if (nil == params) then
        return
    end
    if (nil ~= hero._talentThunderLock or nil ~= hero._talentThunderState) then
        return
    end
    if (math.rand(1, 100) > params.odds) then
        return
    end
    hero._talentThunderLock = true
    time.setTimeout(params.cd, function()
        if (false == class.isDestroy(hero)) then
            hero._talentThunderLock = nil
        end
    end)
    startThunderStorm(hero, params)
end)
```

## 七、假设与决策

1. 沿用项目「机制卡 1 级/张、逐级依赖 I→V」结构，与分裂/多重箭/闪电链/剑气一致。
2. 「受到攻击」判定为 `eventKind.unitHurt` + `damageSrc == injury.damageSrc.attack`，只吃普攻/攻击类伤害；机制附加伤害不触发。
3. 内置冷却用 `hero._talentThunderLock`，不显示 UI；持续期间用 `hero._talentThunderState` 防叠加。
4. 化身是真实单位，挂在英雄所属玩家下；创建后 `pause(true)` + `preInvulnerable()`，英雄本体不加任何状态。
5. 雷暴中心固定在化身生成点，不跟随英雄移动；英雄可以继续走位/输出。
6. 嘲讽用「每 0.5 秒重发 `orderAttackTargetUnit`」近似，排除建筑；无敌单位仍可被下达命令，但打不掉血。
7. 落雷每次独立随机选 1 个敌人，同一敌人可被连续命中；20 次落雷严格按 0.25 秒间隔。
8. 每次落雷对主目标造成全额伤害，并对主目标 300 码内其他敌人造成 40% 溅射；溅射比例按需求区间 30%~50% 取中值 40%，放在 `_attr["雷霆溅射比例"]` 便于调整。
9. 溅射排除主目标，主目标不会在同一发落雷中被结算两次。
10. 伤害来源用英雄本体，保证击杀/经验/金币归属；主目标与溅射都走 `talentMechanicDamage`，不会二次触发其他天赋机制。
11. 演出总时长约 5.8 秒：雷暴结算 5 秒 + 落地 0.8 秒；升空 1 秒与雷暴前 1 秒重叠。
12. 数值为初版，后续只改 `TALENT_EFFECTS` 中 thunder1~5 的 `_attr` 即可。

## 八、验证步骤

1. 构建（不加密 + 热更新调试）：`.\xlik.exe run demo -t`；确认无 Lua 报错、无资源缺失告警。
2. 进图后用 `-tf` 获取天赋点，反复打开天赋面板（V）并刷新，依次学会 `thunder1` ~ `thunder5`（或测试时临时把 `player:talent_thunder1..5` 置 1）。
3. 让英雄被小怪普攻，确认：
   - 触发时英雄本体不暂停、不无敌、不改变状态；
   - 英雄位置出现同模型化身，缓缓升空到约 450；
   - 化身周围有闪电护盾、上空有暗色乌云；
   - 2000 码内小怪被拉向化身并攻击化身（化身不掉血）。
4. 确认 5 秒内每 0.25 秒有一次落雷（共 20 次），落点带雷柱 + 地面冲击环，且每次只打 1500 码内随机 1 个敌人。
5. 核对伤害公式：记录英雄主属性/等级，主目标单次伤害应等于 `基础值 + 主属性×(系数+等级×成长)`，且为法术伤害（受法术抗性影响）。
6. 拉两只距离 300 码内的怪验证溅射：主目标吃全额伤害，旁边那只吃约 40% 伤害；主目标不会被同一发落雷结算两次。
7. 确认落雷伤害（主目标+溅射）不会触发分裂/闪电链/剑气/法球等机制（看是否出现额外弹射或额外伤害）。
8. 让英雄在雷暴期间死亡/被销毁，确认计时器停止、化身销毁、无报错、无残留乌云/闪电。
9. 连续触发两次，确认内置冷却生效；冷却结束后可再次触发，且不会同时存在两个化身。
10. 回归检查：分裂、多重箭、闪电链、法球、剑气仍正常触发。
