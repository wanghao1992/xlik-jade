# 天赋三选一面板 实施方案

## 一、需求

把现在的「一次列出全部 11 个天赋、点谁谁升级」改成 **三选一**：每次按天赋键（T）时，从玩家**所有未满级天赋**中随机抽 3 个候选，玩家从中选 1 个升级（消耗 1 点天赋点）。

面板底部两个按钮：

* **刷新(n)**：重新抽一组候选，**消耗 1 点「天赋刷新点」**；n = 剩余刷新点。
* **暂不选择**：只关闭面板，**当前候选保留**；再次按 T 打开时直接沿用同一组（不重抽）。

已确认的设计选择：

1. **触发方式**：保留手动入口 —— 按 T（`TPL_ABILITY.TALENTS`）时三选一。
2. **候选规则**：从所有**未满级**天赋中随机抽 3 个不重复（可选项不足 3 个时有多少给多少）。
3. **面板样式**：改成卡片式三选一，但**不引入 `ability_select` 套件**，直接在 `xlik_learn` 上改造；卡片内直接展示**天赋说明**。
4. **刷新点**：一次性固定数量（不补充），由 `game.config` 配置，首次使用时发放。
5. **刷新重抽**：尽量与当前这组不同（池子够时排除当前 3 个）。
6. **选完后续**：整组重抽 3 个。

## 二、现状分析

### 调用链

1. 玩家按 T（`TPL_ABILITY.TALENTS`，技能栏槽位 \[8]）→ [天赋.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua#L457-L485) 的 `eventKind.abilityEffective`：把 **全部 11 项**（`buildItems`）通过 `async.call(player, ...)` 交给本地面板 `UIKit("xlik_learn"):open(items, {title=...})`。
2. 本地面板 [xlik_learn/main.lua](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_learn/main.lua)：12 格网格（11 项 + 末格「取消」），点格子 → `sync.send("xlik_learn_pick", { player:index(), item.key })`。
3. 服务端同步回调 [天赋.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua#L487-L529)：校验天赋点 / 等级上限 → `player:set("天赋点", count-1)`、`player:set("talent_"..key, cur+1)`、`applyTalentEffects(...)` → 触发引导事件 `slkc_guide_talent_done`（仅 `新手引导阶段 == 2` 时）→ 本地 `learn:refresh(buildItems(player))`。

### 关键既有设施（复用，不改）

* 天赋定义表 `TALENT_DEFS`（11 项：key/name/icon/levelMax/desc）与效果 `applyTalentEffects`（含普攻触发的分裂/多重箭/闪电链）→ 全部保留。
* 天赋点来源：转职成功 +1（[刷怪.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/process/刷怪.lua#L384)）、资源挑战奖励、引导奖励、开发期 100（[创建英雄.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/process/创建英雄.lua#L59)）→ 不改。
* 面板已有的：鼠标焦点释放 `releaseFocus`、打开时接管技能栏（隐藏 `xlik_plate` 技能栏，关闭时延迟 2 帧恢复）、标题每秒刷新 → 全部保留。
* 同步 key `xlik_learn_pick` 及数据格式 `{玩家index, key}` → 保持不变（减少改动面）。
* 刷新语义参照 [转职.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/process/转职.lua#L284-L314) 的 `转职刷新次数`（玩家字段 + `cfg(...)` 默认值 + `刷新(%d)` 按钮文案）。

### 现有卡点

* 面板是「技能栏同款小格子」，没有卡片感；一次展示全部天赋，没有「三选一」的取舍感；没有重抽手段。

**说明文字折行工具**（放在 `xlik_learn/main.lua` 顶部，面板私有）：

```lua
--- 每行最多显示的字符数 / 说明最多显示的行数(超出补省略号)
local DESC_CHARS_PER_LINE = 8
local DESC_MAX_LINES = 6

--- 把说明文本按每行 limit 个字折行(按字符计数,中文算 1 个字),最多 maxLines 行
---@param text string|table
---@param limit number
---@param maxLines number
---@return string
local function foldDesc(text, limit, maxLines)
    if (type(text) == "table") then
        text = table.concat(text, '\n')
    end
    text = tostring(text or '')
    local lines, buf, count = {}, '', 0
    for i = 1, mbstring.len(text) do
        local ch = mbstring.sub(text, i, i)
        if (ch == '\n') then
            lines[#lines + 1] = buf
            buf, count = '', 0
        else
            buf = buf .. ch
            count = count + 1
            if (count >= limit) then
                lines[#lines + 1] = buf
                buf, count = '', 0
            end
        end
    end
    if (buf ~= '') then
        lines[#lines + 1] = buf
    end
    if (#lines > maxLines) then
        local cut = {}
        for i = 1, maxLines do
            cut[i] = lines[i]
        end
        cut[maxLines] = mbstring.sub(cut[maxLines], 1, math.max(1, limit - 1)) .. '...'
        lines = cut
    end
    return table.concat(lines, '\n')
end
```

> `mbstring` 是框架内置的多字节字符串库（[text.lua](file:///d:/Lua/xlik-jade/library/class/ui/text.lua#L52) 已在用）；`DESC_CHARS_PER_LINE / DESC_MAX_LINES` 为可调常量，实机看效果后只改这两个数即可。

### 3.2 [天赋.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua)：抽卡 / 沿用 / 刷新 / 校验


**面板数据字段约定**：`天赋候选` = 同步字段，存当前候选 `"attack|life|all"`；`天赋刷新点` = 同步字段，剩余刷新次数。

**抽卡与沿用工具**（替换原 `buildItems`）：

```lua
local function cfg(key, def)
    local v = game.config[key]
    if (nil == v) then
        return def
    end
    return v
end

local OFFER_COUNT = 3              -- 每次展示的候选数量
local OFFER_KEY = "天赋候选"        -- 当前候选(同步字段)
local REFRESH_KEY = "天赋刷新点"     -- 剩余刷新点(同步字段)

--- 天赋定义 -> 面板数据
local function toItem(player, d)
    return { key = d.key, name = d.name, icon = d.icon,
             level = talentLevel(player, d.key), levelMax = d.levelMax, desc = d.desc }
end

--- 未满级天赋列表
---@param player Player
---@return table[]
local function availableTalents(player)
    local pool = {}
    for _, d in ipairs(TALENT_DEFS) do
        if (talentLevel(player, d.key) < d.levelMax) then
            pool[#pool + 1] = d
        end
    end
    return pool
end

--- 从池中随机抽 n 个;exclude 为 {key=true},排除后不够 n 个时退回不排除(允许重复)
---@param pool table[]
---@param n number
---@param exclude table|nil
---@return table[]
local function drawFrom(pool, n, exclude)
    local list = {}
    for _, d in ipairs(pool) do
        if (nil == exclude or true ~= exclude[d.key]) then
            list[#list + 1] = d
        end
    end
    if (#list < n and nil ~= exclude) then
        list = {}
        for _, d in ipairs(pool) do
            list[#list + 1] = d
        end
    end
    local out = {}
    for _ = 1, math.min(n, #list) do
        out[#out + 1] = table.remove(list, math.rand(1, #list))
    end
    return out
end

--- 整组重抽(排除 excludeKeys 里的 key)
---@param player Player
---@param excludeKeys table|nil
---@return table[] items, string keysText
local function rollOffer(player, excludeKeys)
    local items, keys = {}, {}
    for _, d in ipairs(drawFrom(availableTalents(player), OFFER_COUNT, excludeKeys)) do
        items[#items + 1] = toItem(player, d)
        keys[#keys + 1] = d.key
    end
    return items, table.concat(keys, "|")
end

--- "a|b|c" -> { a=true, b=true, c=true }
---@param keysText string|nil
---@return table
local function keySet(keysText)
    local set = {}
    for k in string.gmatch(keysText or '', '([^|]+)') do
        set[k] = true
    end
    return set
end

--- 沿用已存候选(过滤已满级项),不足 3 个时用其它未满级天赋补齐
---@param player Player
---@return table[] items, string keysText
local function inheritOffer(player)
    local kept = keySet(player:get(OFFER_KEY))
    local items, keys = {}, {}
    for _, d in ipairs(TALENT_DEFS) do
        if (true == kept[d.key] and talentLevel(player, d.key) < d.levelMax) then
            items[#items + 1] = toItem(player, d)
            keys[#keys + 1] = d.key
        end
    end
    if (#items > 0 and #items < OFFER_COUNT) then
        local used = keySet(table.concat(keys, "|"))
        for _, d in ipairs(drawFrom(availableTalents(player), OFFER_COUNT - #items, used)) do
            items[#items + 1] = toItem(player, d)
            keys[#keys + 1] = d.key
        end
    end
    return items, table.concat(keys, "|")
end

--- 面板参数
---@param player Player
---@return table
local function panelOpts(player)
    return { title = "天赋三选一", refreshLeft = player:get(REFRESH_KEY) or 0 }
end

--- 本地刷新面板(未打开则不处理)
---@param player Player
---@param items table[]
local function localRefresh(player, items)
    local opts = panelOpts(player)
    async.call(player, function()
        if (isUIKit("xlik_learn")) then
            local learn = UIKit("xlik_learn")
            if (learn:isOpen()) then
                learn:refresh(items, opts)
            end
        end
    end)
end

--- 打开面板(已存候选有效则沿用,不重抽)
---@param player Player
---@return void
local function openOffer(player)
    --- 刷新点:一次性固定数量,首次使用时发放
    if (nil == player:get(REFRESH_KEY)) then
        player:set(REFRESH_KEY, cfg("talent_refresh_points", 3))
    end
    --- 没有天赋点则不开面板
    if ((player:get("天赋点") or 0) <= 0) then
        alerter.message(player, "没有可用的天赋点")
        return
    end
    --- 沿用上一次候选(暂不选择后再打开不重抽)
    local items, keys = inheritOffer(player)
    if (#items == 0) then
        items, keys = rollOffer(player, nil)
    end
    if (#items == 0) then
        alerter.message(player, "所有天赋已满级")
        return
    end
    player:set(OFFER_KEY, keys)
    local opts = panelOpts(player)
    async.call(player, function()
        if (isUIKit("xlik_learn")) then
            UIKit("xlik_learn"):open(items, opts)
        end
    end)
end
```

**T 键入口**（`eventKind.abilityEffective`）：删掉「遍历 `TALENT_DEFS` 判断有无可学项」与 `buildItems(player)` 的旧逻辑，改为一行 `openOffer(player)`。

**选择回调**（`sync.receive("xlik_learn_pick")`）：

* **新增候选校验**（`string.find` 用 plain 模式，避免 key 含魔法字符）：

**刷新回调**（新增 `sync.receive("xlik_learn_refresh")`）：

```lua
sync.receive("xlik_learn_refresh", function(syncData)
    ---@type Player
    local player = Player(syncData.transferData[1])
    if (false == class.isObject(player, PlayerClass)) then
        return
    end
    if ((player:get("天赋点") or 0) <= 0) then
        alerter.message(player, "没有可用的天赋点")
        return
    end
    local left = player:get(REFRESH_KEY) or 0
    if (left <= 0) then
        alerter.message(player, "没有可用的天赋刷新点")
        return
    end
    --- 尽量与当前这组不同(池子不够时允许重复)
    local items, keys = rollOffer(player, keySet(player:get(OFFER_KEY)))
    if (#items == 0) then
        alerter.message(player, "所有天赋已满级")
        return
    end
    player:set(REFRESH_KEY, left - 1)   --- 消耗 1 点刷新点
    player:set(OFFER_KEY, keys)
    localRefresh(player, items)
end)
```

## 四、决策与假设

| 项 | 决定 |
| --- | --- |
| 候选池 | 仅「未满级」天赋；已投点/未投点同等概率 |
| 抽取时机 | ① 无有效候选时（首次 / 全部失效）② 选定一个天赋后（整组重抽）③ 点「刷新」 |
| 「暂不选择」语义 | 只关面板；候选写入同步字段 `天赋候选` 保留，再次按 T 显示同一组（其中已满级的项会被过滤并补齐到 3 个） |
| 刷新消耗 | 1 点 `天赋刷新点`；`天赋刷新点` 为一次性固定数量（`game.config.talent_refresh_points`，默认 3），首次打开面板时发放，不随转职/波次补充 |
| 刷新结果 | 池子里还有 ≥3 个可选时排除当前这 3 个；不足时允许重复（但刷新点照扣） |
| 候选权威性 | 抽卡在同步环境进行（`math.rand`），当前组合写入同步字段 `天赋候选`，点击时校验 key 是否属于该组 |
| 面板可见性 | 仅本人可见（沿用 `async.call(player, ...)`） |
| 引导任务2 | `slkc_guide_talent_done` 保持原触发条件（阶段==2 时每次学习都发） |
| 全部满级/无点数 | 面板不打开，聊天栏提示（无刷新点也只提示、不重抽） |
| 卡片贴图 | 用框架内置 FDF（`LK_SLKC_BUTTON_PANEL`）+ 天赋图标，不新增美术资源 |
| 天赋说明 | 卡片内直接展示（`icon/name/level/desc` 四段式）：每行 8 字折行、最多 6 行，超出补 `...`；悬停提示仍给完整全文 |
| 说明字号 | 7 号、左对齐（比名称 9 号/等级 8 号小一号，避免抢视觉） |
| 尺寸微调 | `cardW/cardH/gap`、`DESC_CHARS_PER_LINE/DESC_MAX_LINES`、按钮宽高为起始值，实机预览后按需微调 |
