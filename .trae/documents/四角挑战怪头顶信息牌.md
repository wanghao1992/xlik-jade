# 四角挑战怪头顶信息牌（名称 / 血条 / 等级）

## 一、目标概述（Summary）

给地图四角的常驻挑战怪（`cornerChallenge`）也在头顶套上信息牌，复用现有 [xlik_overhead/main.lua](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_overhead/main.lua) 的逐帧投影机制，展示：

- **红色名称**（如「金币挑战」，敌对感，与玩家英雄牌按玩家色区分）
- **生命条**（血条，绿色，无蓝条）
- **等级数字**（挑战等级 = 本局难度 + 该角击杀次数，沿用挑战怪现有 `level`）

英雄牌逻辑保持完全不变，挑战怪牌为**新增的独立一组控件**。

## 二、现状分析（Current State Analysis）

### 现有头顶牌机制（hero）
[xlik_overhead/main.lua](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_overhead/main.lua)：

- `onStart` 按 `player.startQuantity` 为每个玩家槽位建 1 个 `buildPlate(index)`；`async.loc` 内 `async.setInterval(1, refresh)` 逐帧刷新。
- `refresh()` 里先取黑边参数（`_wfBottom/_wfInner/_wfScale`），再对每块牌 `refreshPlate`。
- `refreshPlate`：取 `whichPlayer.hero` → 存活 + `localPlayer:isVisibleUnit` 判定 → `self:project(x,y,z+HEAD_Z_OFFSET)` 自算世界→屏幕 → 出屏剔除 → `root:relation(...)` 定位 → 写名称/等级/血条/蓝条比率。
- 布局常量：`PLATE_W`、`BAR_W`、`HP_BAR_H/HP_BAR_Y`、`MP_BAR_H/MP_BAR_Y`、`LEVEL_BOX_*`、`LEVEL_GAP`、`NAME_H/NAME_Y`、`PLATE_H`；`applyLevelBox` 在窗口缩放时按 `squareW()` 重算等级框宽度。
- 名称着色走 `ui:nameText(player)`（按 `PLAYER_HEX` 槽位色）。

### 四角挑战怪数据（已有，直接复用）
[四角挑战.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/%E5%9B%9B%E8%A7%92%E6%8C%91%E6%88%98.lua) 全局 `cornerChallenge`：

- `cornerChallenge.monsters[i]`：各角落当前挑战怪（`Unit` 或 `nil`），死亡后置 `nil`，30 秒后同角重刷（索引不变）。

- 创建/销毁都在同步环境，与英雄一致 → UI 的 `async.loc` 中可直接读取 `cornerChallenge.monsters[i]`（与现有 `whichPlayer.hero` 同机制）。同文件顶部已 `cornerChallenge = cornerChallenge or {}` 且 `corners` 在文件加载时即赋值，开局前即可用。

## 三、改造方案（Proposed Changes）

**只改一个文件**：[xlik_overhead/main.lua](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_overhead/main.lua)（`main.fdf` 复用现有 `LK_XLIK_OVERHEAD_LEVEL`，无需改；无需新资源）。

### 3.1 新增常量（紧随现有一组常量之后）

```lua
---@type number 挑战怪头顶世界高度偏移(HeroPitLord 体型较大, 略高于英雄的 70)
ui.MONSTER_HEAD_Z_OFFSET = 100
---@type number 挑战怪屏显额外偏移(默认0)
ui.MONSTER_HEAD_SCREEN_OFFSET = 0.0
---@type number 挑战怪血条: 贴牌底(无蓝条), 高度同英雄血条
ui.MON_HP_BAR_H = 0.005
ui.MON_HP_BAR_Y = 0.0003
---@type number 挑战怪等级框纵向: 以血条区中心为中心
ui.MON_BOX_Y = ui.MON_HP_BAR_Y + ui.MON_HP_BAR_H / 2 - ui.LEVEL_BOX_SIZE / 2
---@type number 挑战怪名称行底边与信息牌总高
ui.MON_NAME_Y = ui.MON_HP_BAR_Y + ui.MON_HP_BAR_H + 0.0005
ui.MON_PLATE_H = ui.MON_NAME_Y + ui.NAME_H
```

### 3.2 新增控件容器声明

在 `ui._plates = {}` 旁新增：

```lua
---@type table<number, table> 各角落挑战怪的信息牌控件(索引与 cornerChallenge.corners 对齐)
ui._monsters = {}
```

### 3.3 泛化 `applyLevelBox`（支持自定义等级框 Y）

保持对英雄牌调用不变，仅让纵坐标可被单块牌覆盖：

```lua
local boxY = plate.boxY or self.LEVEL_BOX_Y
plate.levelBg:relation(UI_ALIGN_LEFT_BOTTOM, plate.root, UI_ALIGN_LEFT_BOTTOM, levelX, boxY)
plate.levelText:relation(UI_ALIGN_LEFT_BOTTOM, plate.root, UI_ALIGN_LEFT_BOTTOM, levelX, boxY)
```

（英雄牌不设 `boxY` → 行为与现在完全一致。）

### 3.4 新增 `ui:buildMonsterPlate(index)`

结构照 `buildPlate`，但**去掉蓝条、蓝条相关布局**，等级框纵坐标用 `MON_BOX_Y`，牌高用 `MON_PLATE_H`：

- `root = UIBackdrop(key, UIGame)`：`LEFT_BOTTOM` 对齐 `UIGame`，`size(PLATE_W, MON_PLATE_H)`，`show(false)`。
- `nameText = UIText(key..":name", root)`：`LEFT_BOTTOM` 于 root `(0, MON_NAME_Y)`，`size(PLATE_W, NAME_H)`，居中，`fontSize(9)`。
- `levelBg = UIBackdrop(key..":levelBg", root, { _fdfName = "LK_XLIK_OVERHEAD_LEVEL" }):alpha(220)`。
- `levelText = UIText(key..":level", root)`：居中，`fontSize(9)`。
- `hpBar = UIBar(key..":hp", root)`：`(BAR_X, MON_HP_BAR_Y)`，`valueTexture(BLP_COLOR_GREEN)`。
- `plate = { root, nameText, levelBg, levelText, hpBar, boxY = self.MON_BOX_Y }` → `self:applyLevelBox(plate)` → 返回。

### 3.5 新增 `ui:ensureMonsterPlates(n)`（懒建，容错加载顺序）

```lua
for i = #self._monsters + 1, n do
    self._monsters[i] = self:buildMonsterPlate(i)
end
```

### 3.6 `onStart` 内建挑战怪牌

在建完英雄牌后：

```lua
local cornerCount = (type(cornerChallenge) == 'table' and type(cornerChallenge.corners) == 'table')
    and #cornerChallenge.corners or 0
self:ensureMonsterPlates(cornerCount)
```

窗口缩放回调里，除遍历 `self._plates` 外同样遍历 `self._monsters` 调 `applyLevelBox`。

### 3.7 新增 `ui:refreshMonsters(localPlayer)`

对第 `i` 块挑战怪牌：

- `cc = cornerChallenge`；`corners = cc ~= nil and cc.corners or nil`；非表则全部 `show(false)` 返回。
- `self:ensureMonsterPlates(#corners)`。
- `monster = cc.monsters[i]`；可见条件：`class.isObject(monster, UnitClass)` 且 `not class.isDestroy(monster)` 且 `monster:isAlive()` 且 `localPlayer:isVisibleUnit(monster)`。
- 投影：`self:project(monster:x(), monster:y(), monster:z() + self.MONSTER_HEAD_Z_OFFSET)`；出屏剔除用与英雄相同的 `CULL_MARGIN` 规则；不显示则 `show(false)`。
- 定位：`root:relation(UI_ALIGN_LEFT_BOTTOM, UIGame, UI_ALIGN_LEFT_BOTTOM, px - PLATE_W/2, uiY + HEAD_SCREEN_OFFSET + MONSTER_HEAD_SCREEN_OFFSET)`（`uiY = _wfBottom + py * _wfScale`）。
- 文本：名称 = `colour.hex(colour.red, corners[i].name)`（兜底 `monster:name()`）；等级 = `math.floor(monster:level() or 0)`。
- 血条：`hpBar:ratio(hp > 0 and hpCur / hp or 0, BAR_W, MON_HP_BAR_H)`；`root:show(true)`。

### 3.8 `refresh()` 末尾接入

英雄牌循环之后加一行：

```lua
self:refreshMonsters(localPlayer)
```

> `_wfBottom/_wfInner/_wfScale` 已在 `refresh()` 开头算好，挑战怪牌直接复用。

## 四、假设与决策（Assumptions & Decisions）

1. **内容**：名称 + 血条 + 等级（用户确认）；**无蓝条**、无玩家槽位色（改用红色）。
2. **名称颜色**：`colour.hex(colour.red, name)`（用户确认，红色敌对感）。名称取 `corners[i].name`（静态「金币挑战」等），兜底 `monster:name()`。
3. **等级**：直接读 `monster:level()`（即挑战等级 = 难度 + 击杀数），与挑战怪设定一致，不另算。
4. **布局**：挑战怪牌为独立常量组（血条贴牌底、等级框以血条为中心、名称在上），不复用英雄的双条堆叠布局；`PLATE_W/BAR_W/NAME_H/LEVEL_BOX_*` 复用英雄同值，视觉风格统一。
5. **头顶偏移**：`MONSTER_HEAD_Z_OFFSET = 100`（HeroPitLord scale1.2 高于英雄，取略高于英雄的 70）；实机若偏高/偏低只调此一个常量。
6. **复用同一 kit/资源**：仍用 `xlik_overhead` 套件与 `LK_XLIK_OVERHEAD_LEVEL` 边框，不新增文件/资源。
7. **可见性/剔除**：与英雄牌同一套 `isVisibleUnit` + 逐帧投影 + `CULL_MARGIN` 规则，只显示本地玩家视野内者。
8. **容错**：`ensureMonsterPlates` 懒建牌，`refreshMonsters` 对 `cornerChallenge` 缺失/未就绪做空处理，`cornerChallenge` 为 nil 时不报错。
9. 不执行打包/游戏内测试（按既有约定），仅做静态检查。

## 五、验证步骤（Verification）

1. **静态检查**：`luac -p vendor/assets/war3mapUI/xlik_overhead/main.lua` 语法通过。
2. **回归确认**：英雄牌逻辑未变（`buildPlate/refreshPlate/nameText` 均未改；`applyLevelBox` 仅在显式给了 `boxY` 时才走新分支）。
3. **逻辑自检**（人工核对）：
   - 开局四角各 1 只怪 → 对应位置出现红色名称 + 血条 + 等级；英雄牌照旧。
   - 击杀后该牌随之隐藏（`monsters[i]` 置 nil / `isAlive` false）；30s 重刷后同一定位牌重新出现（索引复用）。
   - 视野外 / 出屏 / 相机背后 → 正确隐藏；窗口缩放后等级框宽度按 `squareW` 重算。
4. **游戏内测试（由用户执行）**：站到四角观察四只挑战怪头顶的名称/血条/等级；打掉一只等重刷；切分辨率核对等级框宽度。
