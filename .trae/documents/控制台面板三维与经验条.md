# 控制台面板改造：两列布局 + 力量/敏捷/智力 + 经验条

## 一、需求（已确认）

底部控制台面板（`xlik_plate` 套件）**保持现有宽度**（`0.19`），参照老图 `unit_detail` 改造成**两列**内容：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 名称条（现状：`Lv{n}` + 名称）+ **新增横向经验条** |
| 列1（左） | **攻击**（图标+数值）、**护甲/防御**（图标+数值） |
| 列2（右） | **一个主属性图标** + **力量 / 敏捷 / 智力** 三行数值 |
| 悬停提示 | 攻击图标 → 攻击力/范围/**攻击间隔**/攻击速度；护甲图标 → 护甲/减伤/法术抗性/**移动速度** |
| 面板最下方 buff | **不在面板内实现**（框架已有 `xlik_buff` 套件在左下显示，见 [xlik_buff/main.lua](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_buff/main.lua#L26-L28)） |

约束：
- **不加宽面板**；攻击间隔 / 移动速度不再单独占行，改由悬停提示展示（老图口径）。
- **列2（三维 + 属性图标）与经验条仅英雄显示**；普通单位只显示列1（攻击/护甲）。

参考老图：`d:\Lua\死灵狂潮\map\scripts\core\ui\war3\unit_detail.lua`（左：`attack_icon`/`armor_icon`；右：`attribute_icon` + `str/agi/int`；顶部 `exp_bar`；底部 `buff_list`）。

## 三、方案

### 变更 1：`vendor/assets/war3mapUI/xlik_plate/main.lua`

#### 1.1 监听三维属性变化

`listenParams`（[L45-L50](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_plate/main.lua#L45-L50)）追加 `"str", "agi", "int"`：

```lua
local listenParams = {
    "exp", "level", "levelMax", "name",
    "hp", "hpCur", "mp", "mpCur",
    "attack", "attackSpeed", "attackSpaceBase", "noAttack",
    "invulnerable", "defend", "move",
    "str", "agi", "int",
}
```

#### 1.2 信息区改为「两列」布局（在 `t == "Unit"` 分支内重写 `plateInfo` 部分）

**删除** `plateInfo.attackSpeed`、`plateInfo.move` 两个可见标签（它们的内容改由悬停提示展示）。

**保留并重排** `plateInfo.attack` / `plateInfo.defend`（列1，纵向两项）：
- `plateInfo.attack`：`UILabel`，锚 `relation(UI_ALIGN_LEFT_TOP, self.plate[t], UI_ALIGN_LEFT_BOTTOM, 0.005, 0.088)`，`size(0.078, 0.030)`，`icon("UI\\Widgets\\Console\\Human\\infocard-neutral-attack-melee.blp")`，保留 `uiEnter→plateInfoEnter(_, "attack")` / `uiLeave→plateInfoLeave`
- `plateInfo.defend`：`UILabel`，`relation(UI_ALIGN_LEFT_TOP, self.plateInfo.attack, UI_ALIGN_LEFT_BOTTOM, 0, -0.004)`，`size(0.078, 0.030)`，`icon("UI\\Widgets\\Console\\Human\\infocard-neutral-armor-medium.blp")`，保留 `uiEnter→plateInfoEnter(_, "defend")` / `uiLeave`

**新增** 列2 控件（主属性图标 + 三维）：
- `plateInfo.attrIcon`：`UIBackdrop(kp .. ":info:attrIcon", self.plate[t])`，`relation(UI_ALIGN_LEFT_TOP, self.plate[t], UI_ALIGN_LEFT_BOTTOM, 0.105, 0.070)`，`size(0.02, 0.02)`，`:show(false)`
- `plateInfo.str` / `plateInfo.agi` / `plateInfo.int`：`UIText`（无图标，纯文本），x=`0.129`，自上而下 y≈`0.086 / 0.062 / 0.038`，`size(0.055, 0.022)`，`textAlign(TEXT_ALIGN_LEFT)`，`fontSize(infoFontSize)`，均 `:show(false)`

> 说明：列2 使用**一个**主属性图标（对应老图 `attribute_icon`）+ 三行文本 `力量 12 / 敏捷 5 / 智力 7`；列1 保持与套件一致的「图标 + 数值」样式。

#### 1.3 新增经验条（面板顶部横向细条）

在 `t == "Unit"` 分支内新增（`UIBar` + 自绘黑底，**不新增图片资源**，与「通行证/签到面板」替换自定义贴图的做法一致）：

```lua
-- 经验条(仅英雄显示): 面板顶部横向细条(宽度沿用名称条宽度, 不加宽面板)
self._expBarWidth = 0.178
self._expBarHeight = 0.007
self.plateExpBack = UIBackdrop(kp .. ":expBack", self.plate[t])
    :relation(UI_ALIGN_TOP, self.plate[t], UI_ALIGN_TOP, 0, -0.002)
    :size(self._expBarWidth, self._expBarHeight)
    :texture(X_UI_BLACK)
    :show(false)
self.plateExp = UIBar(kp .. ":exp", self.plateExpBack)
    :relation(UI_ALIGN_CENTER, self.plateExpBack, UI_ALIGN_CENTER, 0, 0)
    :valueTexture(BLP_COLOR_GREEN)
    :markTexture(X_UI_BLACK)
    :ratio(0, self._expBarWidth, self._expBarHeight)
```

#### 1.4 不变部分

`plate[Unit]` 尺寸、`plateTopNameBlack/plateTopName`、`plateHP/MP/Shield`、能力栏/物品栏/仓库区**均不改动**。

### 变更 2：`vendor/assets/war3mapUI/xlik_plate/scripts/plate.lua`

#### 2.1 `ui:plateInfoEnter(evtData, field)` —— 悬停提示承载「攻击间隔 / 移动速度」

- 删除 `field == "attackSpeed"` 与 `field == "move"` 两个分支（对应可见标签已移除）。
- 扩展 `field == "attack"` 分支，追加（老图 attack 悬停口径）：
  - `攻击范围: {attackRange}`
  - `攻击间隔: {attackSpace} 秒/击`
  - `攻击速度: {100 + attackSpeed}%`
- 扩展 `field == "defend"` 分支，追加（老图 armor 悬停口径）：
  - `伤害减少: {护甲减伤%}%`（`0.04*armor/(1+0.04*armor)*100`，与 [英雄属性.lua#L67-L69](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/英雄属性.lua#L67-L69) 同口径）
  - `法术抗性: {_attr['法术减免%']}%`
  - `移动速度: {move}`
- 复用文件内既有 `_attrLabel` 与 `colour.hex` 风格；`portrait` 死分支可一并删除。

#### 2.2 `ui:updatePlate()` —— 刷新与显隐

`class.isObject(selection, UnitClass)` 分支内，把原 `self.plateInfo.attackSpeed:text(...)`、`self.plateInfo.move:text(...)` 两行去掉，改为：

```lua
self.plateInfo.attack:text(attack):alpha(attackAlpha)
self.plateInfo.defend:text(defend)

--- 仅英雄: 主属性图标 + 力量/敏捷/智力 + 经验条
local owner = selection:owner()
local isHero = class.isObject(owner, PlayerClass) and owner.hero == selection
if (isHero) then
    local key = game.method.primaryKey(selection)          -- "str"/"agi"/"int"
    self.plateInfo.attrIcon
        :texture(attribute.icon(key))                      -- 主属性图标
        :show(true)
    self.plateInfo.str:text(colour.hex(colour.gold, "力量") .. " " .. colour.hex("FF3636", math.floor(selection:str() or 0))):show(true)
    self.plateInfo.agi:text(colour.hex(colour.gold, "敏捷") .. " " .. colour.hex("62FF36", math.floor(selection:agi() or 0))):show(true)
    self.plateInfo.int:text(colour.hex(colour.gold, "智力") .. " " .. colour.hex("36BCFF", math.floor(selection:int() or 0))):show(true)

    local lv = math.floor(selection:level() or 1)
    local cur = selection:exp() or 0
    local prev = game.unitExpNeeds(lv)
    local next = game.unitExpNeeds(lv + 1)
    local ratio = 1
    if (lv < (selection:levelMax() or 0) and next > prev) then
        ratio = math.trunc((cur - prev) / (next - prev), 3)
    end
    self.plateExpBack:show(true)
    self.plateExp:ratio(ratio, self._expBarWidth, self._expBarHeight)
else
    self.plateInfo.attrIcon:show(false)
    self.plateInfo.str:show(false)
    self.plateInfo.agi:show(false)
    self.plateInfo.int:show(false)
    self.plateExpBack:show(false)
end
```

> 刷新时机无需额外改动：`str/agi/int` 由 1.1 的 `listenParams` 驱动；`exp/level/levelMax` 原监听已覆盖。`plate.Unit:show(false)`（未选中单位）时，作为其子控件的列2 与经验条会一并隐藏。

## 四、假设与决策

1. **英雄判定用 `owner().hero == selection`**：本项目英雄是普通单位（无原生 hero 标记），`player.hero` 是项目通用英雄引用。不新增框架级标记。
2. **面板宽度保持不变**（`0.19`）；列1/列2 在现有面板内排布（列1 x≈`0.005`，列2 x≈`0.105`），不牵动血/蓝条与名称条。
3. **攻击间隔 / 移动速度改悬停展示**（老图口径），面板内不再单独占行。
4. **不新增图片资源**：经验条用 `UIBar` + `BLP_COLOR_GREEN` + `X_UI_BLACK`；图标复用魔兽内置 `infocard-*` 与 `attribute.icon(key)`。
5. **buff 不在控制台面板内实现**（沿用 `xlik_buff`）。
6. 名称/等级维持现状（名称条 + `Lv{n}` 前缀），不单列「等级」控件。
7. 列2 与经验条的像素位置为初值，最终以游戏内观感微调（只改上述常量）。

1. 静态检查（不跑打包命令）：
   - `luac -p vendor/assets/war3mapUI/xlik_plate/main.lua`

2. 用户游戏内验证：
   - 选中**英雄**：面板呈两列——列1「攻击、护甲」图标+数值；列2 主属性图标 + 力量/敏捷/智力；面板顶部出现绿色经验条；名称行仍为 `Lv{n} 名称`。
   - 击杀小怪涨经验 → 经验条按当前等级内进度增长；升级后回退到新等级起点、`Lv` 递增。
   - 悬停攻击图标 → 提示含 攻击力/范围/**攻击间隔**/攻击速度；悬停护甲图标 → 提示含 护甲/伤害减少/法术抗性/**移动速度**。
   - 选中**普通单位**（小怪/BOSS/NPC）：仅显示列1（攻击/护甲），列2 与经验条不显示。
   - 面板宽度、血/蓝条、名称条位置与改动前一致（未加宽）。
