# 宝库系统迁移（老图 死灵狂潮 → xlik-jade demo）

## 一、目标与范围

把老图 [内容/宝库](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E5%AE%9D%E5%BA%93) 整套搬进 demo：

- **5 个等级 × 60 条 = 300 条宝库装备**（`N / R / SR / SSR / UR`），名称与图标照搬（`R/SR/SSR/UR` 全量 50 条有名字有图标，第 51~60 条老图本身无名 → 沿用老图兜底名 `等级:序号` + 默认图标）。
- **掉落**：照搬老图 `游戏-团队BOSS死亡` 钩子 —— 击杀团队BOSS（团本「魔君」）随机掉落 `jf` 个宝库装备，逐个写入存档（`宝库掉落2`），并给出播报 + 图标飞行动画。
- **面板**（新套件 `xlik_baoku`）：5 个等级标签（带该等级"段等级"）+ 10 列滚动网格（60 格）+ 每格计数条（`当前/上限`）+ 未拥有蒙版 + 等级边框 + 悬停说明 + 「当前增幅 / 宝库加成」文本 + 「关闭」。
- **加成**：照搬老图"拥有即加成"——每条的属性 = `该条计数(封顶后) × 老图基础值 × (1+宝库加成) × 等级序号`；每等级额外给"集齐一套（60 条计数最小值 = 段等级）"的 `全属性增幅%` 奖励。
- **持久化**：照搬老图存档组 `宝库掉落`（key `bk1..bk5`，位宽 1）与 `宝库掉落2`（key `bka1..bka15`，位宽 3），槽位 = 装备序号 1..300。
- **宝库加成落地**：老图该值来自 `无尽存档` 各模式积分阈值累计（`pla:set_data('宝库加成', …)`）。demo 目前是 TODO（恒 0，见 [存档流程.lua:954-955](file:///d:/Lua/xlik-jade/projects/demo/scripts/process/%E5%AD%98%E6%A1%A3%E6%B5%81%E7%A8%8B.lua#L954-L955)）→ **本次一并落地**，并在 `存档流程.lua` 关闭该 TODO。
- **入口**：功能栏「宝库(B)」（当前是 `print` 占位，见 [xlik_funcbar/main.lua:88-90](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_funcbar/main.lua#L88-L90)）。

**明确不做 / 降级**（逐条在代码里注释）：

- `传国玉玺数量 / 孤独王者数量 / 突破丹数量`（老图 `get_data`，来源是积分道具/平台抽奖）在 demo 无来源 → 按 0 读，因此掉落数量倍率、宝库上限的两项系数在 demo 恒为 1（DX 阈值部分照常生效）。
- 老图 `lost.是否特殊团队BOSS` 的 ×1.1 掉落倍率对应 demo 团本"彩蛋特殊团本"（`saveChallenge.raid.egg` 恒 false）→ 倍率恒 1。
- 老图 `获取宝库上限` 里的 `宝库额外上限`（老图全仓只在 `数据.lua:636` 赋值 1，无其它修改点）→ 常量 1。
- 老图掉落动画的"图标残影/淡出"用 demo 现成能力近似（详见 §3.7），不做逐帧序列帧。

--- 宝库加成(老图 pla:get_data('宝库加成'): 无尽存档每个满足阈值累加一次)
--- 正常模式 -> 阈值奖励值; 进阶/追击 -> 阈值奖励值 * 2  (照搬 无尽存档/数据.lua:53)
---@param player Player
---@return number
function saveFlow.endlessBonus(player)
    local handle = player:handle()
    local bonus = 0
    for _, def in ipairs(ENDLESS_SUBS) do
        local cur = valueInt(handle, def.key)
        for _, row in ipairs(ENDLESS_LIST) do
            if (cur >= row[1]) then
                bonus = bonus + ((def.name == '正常') and row[2] or row[2] * 2)
            end
        end
    end
    return bonus
end
