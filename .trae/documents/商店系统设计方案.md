# 商店系统（替代战功商店）实施方案

## 一、Summary

用技能入口 + 单套件商店 UI 替换现有「战功商店」：

- 新增入口技能「商店」，放到技能栏**第 1 行第 4 列**（顶部行最右，热键 G）；再次发动则关闭面板。
- 新商店 UI（沿用套件名 `xlik_shop`）：上方 3 个 TAB（Buff / 属性 / 功能），左侧商品网格（图标 + 名称 + 价格），右侧详情（图标 / 名称 / 价格 / 描述 / 购买按钮）；左键选中，**双击或右键直接购买**。
- Buff 商品与功能商品消耗 **杀敌数（worth.kill）**；属性商品消耗 **金币（worth.gold）**。
- 功能商品对随机事件「雷霆扑杀 / 天降巨剑 / 坐骑冲锋 / 分身诱饵 / 凌波微步」做**永久本局叠加**增幅（持续 +5 秒、伤害系数、伤害范围、追击速度等）。
- 删除旧战功商店 process 文件，`xlik_shop` 套件文件整体重写（套件名与 `assets_ui` 注册保持不变）。

## 三、Proposed Changes

### 3.1 新增入口技能 `projects/demo/scripts/globals/tpl/ability/商店.lua`

参照 [天赋.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua#L17-L22) 写法：

```lua
TPL_ABILITY.SHOP = AbilityTpl()
    :name("商店")
    :description({ [[发动后打开/关闭商店面板]] })
    :targetType(ability.targetType.none)
    :icon([[ReplaceableTextures\CommandButtons\BTNGoldRing.blp]])

TPL_ABILITY.SHOP:onEvent(eventKind.abilityEffective, function(abData)
    local player = abData.triggerPlayer
    if (false == class.isObject(player, PlayerClass)) then return end
    shopFlow.toggle(player)
end)
```

- `shopFlow` 为 process 中定义的全局表（与旧写法一致，运行时解析）。
- 不新增热键配置：位置由槽位 12 决定，热键为 G。

### 3.3 删除旧文件、新增 `projects/demo/scripts/process/商店.lua`

- 删除 `projects/demo/scripts/process/战功商店.lua`（全仓仅 `shopFlow` 自引用，无外部依赖）。
- 新文件 `Process("shop")`，结构：

**商品数据结构**

```lua
---@class ShopGoods
--- key/tab("buff"|"attr"|"func")/name/desc/icon/cost/limit/currency("kill"|"gold")
```

**面板数据 `shopFlow.makeData(player)`**

```lua
{
  playerIndex = player:index(),
  kill = player:worth()["kill"] or 0,
  gold = player:worth()["gold"] or 0,
  tabs = { {key="buff",name="Buff商品"}, {key="attr",name="属性商品"}, {key="func",name="功能商品"} },
  goods = { {key,tab,icon,name,desc,cost,currency,limit,owned,left,afford}, ... },
}
```

- 限购计数沿用 `player:set("商店_已购_"..key, n)`，每局重置。
- 价格固定：每件商品只有单一 `cost`，买第 2、3 次仍是同一价格，不随次数递增；限制只靠 `limit`。

**开关 / 购买**

```lua
shopFlow.toggle(player)  -- async.call(player, ui:isOpen() and ui:close() or ui:open(data))
shopFlow.open(player) / shopFlow.refresh(player)
shopFlow.buy(player, key) -- 校验：玩家/英雄存活 → 商品 → 限购 → 货币余额 → 扣费 → 计数 → applyGoods
sync.receive("xlik_shop_buy", ...) -- transferData = { playerIndex, key }
sync.receive("xlik_shop_toggle", ...) -- 可选兜底，客户端只要打开时也可直接请求
```

- 货币扣减：`player:worth("-", { kill = cost })` 或 `{ gold = cost }`；提示文本按货币区分。

**发放**

- 属性商品：直接改英雄/玩家属性（沿用旧 `applyGoods` 的写法：`hero:set("str","+="..v)`、`player:set("金币加成%", ...)`）。
- Buff 商品：复用旧实现（`Buff` / `job.attrBuff`），同 key 先 `BuffClear` 再上 Buff。
- 功能商品：只累加增幅等级：`player:set("商店增幅_"..key, (player:get(...) or 0) + 1)`，上限受 `limit` 约束。

### 3.5 事件增幅接入 `projects/demo/scripts/globals/setup/随机事件.lua`

新增局部工具函数（放在各 start 函数之前）：

```lua
--- 读取商店增幅等级(仅本局有效)
---@param pla Player
---@param key string
---@return number
local function shopBoost(pla, key)
    return math.floor(tonumber(pla:get("商店增幅_" .. key)) or 0)
end
```

在各 start 函数中，**先取基础值，再叠加增幅**（只在 `tag == nil`，即随机事件/存档道具触发时生效；奥义传入自定义 tag 与 duration，不受商店增幅影响）：

- `startHarvest`（[L2318-L2338](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/随机事件.lua#L2318-L2338)）
  - `HARVEST_TIME = HARVEST_TIME + 5 * shopBoost(pla, "boost_harvest_dur")`
  - `AOE_RADIUS = AOE_RADIUS + 100 * shopBoost(pla, "boost_harvest_aoe")`
  - `ATK_MUL = ATK_MUL + 0.5 * shopBoost(pla, "boost_harvest_dmg")`
  - 冲击环视觉半径按 `AOE_FX_BASE_RADIUS` 与 `AOE_RADIUS` 的比例缩放（已有逻辑），增幅后同步放大
- `startSkySword`（[L2611-L2632](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/随机事件.lua#L2611-L2632)）
  - `SWORD_TIME += 5 * boost_dur`
  - `SWEEP_R += 100 * boost_range`
  - `KNOCKUP_ODDS = math.min(100, KNOCKUP_ODDS + 10 * boost_odds)`
- `startMountCharge`（[L2955-L2977](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/随机事件.lua#L2955-L2977)）
  - `MOUNT_TIME += 5 * boost_dur`
  - `SPEED += 300 * boost_speed`
  - `HIT_RADIUS += 50 * boost_hit`
- `startDecoyBait`（[L3337-L3356](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/随机事件.lua#L3337-L3356)）
  - `DECOY_TIME += 5 * boost_dur`
  - `RADIUS += 200 * boost_aura`
  - `DOT_PCT = math.min(0.30, DOT_PCT + 0.02 * boost_dot)`
- `startSerpentine`（[L3608-L3625](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/随机事件.lua#L3608-L3625)）
  - `SERPENTINE_TIME += 5 * boost_dur`

## 四、Assumptions & Decisions

1. **完全替换**旧战功商店：删除 process 文件、重写套件；旧商品（天赋点/刷新点/门票等）不再出售，避免与新经济重复。
2. **货币分配**：Buff 与功能 → 杀敌数；属性 → 金币。
3. **增幅为永久本局叠加**，不随事件消耗；等级存于 `player:set("商店增幅_<key>")`，上限由商品 `limit` 控制，每局重置。
4. **增幅只作用于随机事件触发**（`tag == nil` 的 `startXxx` 调用）；奥义（自定义 tag/duration）与调试命令不受影响。
5. **入口技能位置**：`preAbility[4]` 经镜像落在槽位 12（顶部行第 4 列，热键 G），与现有技能不冲突。
6. **UI 不参与 uiPriority**，可同时与天赋/事件面板共存；关闭只靠技能再按一次、右上角关闭图标或 ESC。
7. 商品图标全部复用 War3 原生命令按钮贴图，不新增美术资源。
8. **价格固定不变**：每件商品单一 `cost`，重复购买同价；去量控制只靠 `limit`（不实现 `costList` 递增曲线）。

## 五、Verification

1. **技能入口**：开图后英雄技能栏顶部行第 4 格出现「商店」；发动打开面板，再次发动关闭；不与其他技能冲突。
2. **TAB 与网格**：三个 TAB 切换后商品集合正确（Buff 6 / 属性 7 / 功能 15）；网格图标不变形、名称与价格正确显示。
3. **选中与购买**：左键选中 → 右侧详情刷新生效；双击与右键均能购买；余额不足/已购满时按钮与提示正确。
4. **扣费**：Buff/功能扣 `worth.kill`，属性扣 `worth.gold`；同一商品第 2、3 次购买价格与第一次相同（固定价）；购买后余额与限购数字即时刷新；面板关闭再打开数据保留。
5. **事件增幅**：分别购买 5 个事件的持续/伤害/范围/速度增幅各 1~3 级，用调试命令 `-ree harvest/sword/mount/decoy/serpentine` 触发，验证持续时间、伤害数字、范围特效半径、冲锋/蛇行速度变化；确认奥义版本（自定义 duration/tag）不受影响。
6. **回归**：旧战功商店入口与按钮不存在且无报错；ESC 可关闭商店；面板不阻塞天赋三选一/随机事件面板。
7. **构建**：按项目现有构建流程重新打包 `projects/demo`，确认无 Lua 语法/加载错误。
