# 战功商店改版方案

## 一、摘要

新建一个**独立的常驻战功商店**（旧商店代码、旧 UI 套件不改动）：

- 面板常驻显示在自定义技能栏上方（`xlik_plate` 的技能栏位于屏幕右下角），不使用技能/快捷键打开。
- 一横排 **5 个商品格 + 右侧 1 个刷新格**，点击刷新格重摇前面 5 个商品。
- 商品池复用旧商店的 **21 件杀敌数商品**（Buff 6 件 + 功能增幅 15 件），分为 **5 个品质**。
- 游戏开始时空格；进入游戏 **3 分钟**时免费自动刷新第一批商品；之后玩家主动刷新，每次消耗 **200 杀敌数**。
- 每次刷新每个格子独立判定是否打折，折扣随机且大折扣概率更低。
- 旧「商店」仅从英雄技能槽位移除；`process/商店.lua`、`xlik_shop` 套件与 `assets_ui("xlik_shop")` 全部保留不动。

## 三、设计决策

| 项 | 决策 |
|---|---|
| 新后端 | 新建 `process/战功商店.lua`，自建商品表（复制旧 21 件杀敌商品配置 + 效果实现），旧文件零修改 |
| 键位/状态 | 复用旧 key 与 `商店_已购_<key>` / `商店增幅_<key>`，效果与旧系统完全一致 |
| 新 UI 套件 | 新建 `vendor/assets/war3mapUI/xlik_zhangong/main.lua`，注册 `assets_ui("xlik_zhangong")` |
| 显示方式 | 常驻显示，无打开/关闭、无快捷键、不参与 `uiPriority`、不进 `ESC_CLOSE_KITS` |
| 布局 | 屏幕右下、自定义技能栏上方；5 商品格横排 + 间隔 + 1 刷新格 |
| 品质 | 5 档：普通/优良/稀有/史诗/传说；名称按品质色显示，图标边框 `边框_lv1..lv5.tga` |
| 品质抽取权重 | 普通 40%、优良 28%、稀有 18%、史诗 10%、传说 4%（每格独立抽，避免 5 格重复） |
| 打折 | 每格独立：45% 不打折；打折时按权重 9折45%、8折28%、7折16%、6折8%、5折3% |
| 首批 | 游戏时间到 **180 秒**时免费自动刷新一次，不扣杀敌数 |
| 主动刷新 | 首批之后可用；每次扣 **200 杀敌数**；杀敌不足服务端拒绝 |
| 点击商品 | 单击直接购买（悬停出完整提示：品质/原价/折后价/限购/描述） |
| 购买后 | 商品格保留，刷新限购/剩余显示；达到限购置灰「已购满」 |

### 3.1 商品品质映射（21 件）

| 品质 | 商品 key |
|---|---|
| 1 普通 | buff_haste、buff_regen、boost_harvest_aoe、boost_sword_range、boost_mount_hit、boost_decoy_aura |
| 2 优良 | buff_iron、boost_harvest_dmg、boost_sword_odds、boost_mount_speed、boost_decoy_dot |
| 3 稀有 | buff_vamp、boost_sword_dur、boost_mount_dur、boost_serpentine_speed、boost_serpentine_dmg |
| 4 史诗 | boost_harvest_dur、boost_decoy_dur、boost_serpentine_dur |
| 5 传说 | buff_bounty、buff_rage |

- 价格沿用旧配置，品质只影响稀有度/颜色/边框，不额外乘价格。
- 5 格同一次刷新不出现重复商品。

### 3.2 打折价格

`折后价 = math.floor(baseCost * 折数 / 10)`，例如 500 → 9折 450、7折 350、5折 250。
折扣只作用于本次出现的格子，购买时按折后价扣杀敌数。

## 四、改动清单

### 4.1 新增 `projects/demo/scripts/process/战功商店.lua`

结构：

```lua
local process = Process("meritShop")
local KIT = "xlik_zhangong"
local REFRESH_COST = 200
local FIRST_OPEN_SEC = 180
local SLOT_COUNT = 5
```

**配置**

- `QUALITY_NAME = { '普通', '优良', '稀有', '史诗', '传说' }`
- `QUALITY_COLOR = { 'FF7AFF0D', 'FF3399FF', 'FFD992FF', 'FFFFA500', 'FFFF69B4' }`（对应 1~5 品）
- `QUALITY_BORDER = { '边框_lv1.tga' ... '边框_lv5.tga' }`
- `QUALITY_WEIGHT = { 400, 280, 180, 100, 40 }`（千分制）
- `DISCOUNT_CHANCE = 450`（千分制，45% 打折）
- `DISCOUNT_TIER = { {9,450}, {8,280}, {7,160}, {6,80}, {5,30} }`（10 分钟权重求和 1000）
- `GOODS`：复制旧 `GOODS` 中 **21 件 `currency="kill"` 商品**，每件新增 `quality = 1..5` 字段；`name/icon/cost/limit/desc` 与旧文件逐字一致。

**每玩家状态**

```lua
local STATE = {} -- [playerIndex] = { inited, autoAt, autoDone, slots, timer }
```

- `STATE[pi].slots`：5 项 `{ key, quality, discount, cost }`，`discount = nil` 表示未打折。
- `autoAt = FIRST_OPEN_SEC`（绝对游戏秒），`autoDone` 首批是否已刷新。

**随机工具**

- `rollQuality()`：千分权重累加随机。
- `pickByQuality(used)`：在对应品质池里均匀取未重复商品；该品质已取完则从其余未使用商品兜底。
- `rollDiscount()`：先判 `DISCOUNT_CHANCE`，再按 `DISCOUNT_TIER` 权重取折数。

**核心接口**

| 接口 | 说明 |
|---|---|
| `meritShopFlow.init(player)` | 建状态；`remain = math.max(0, 180 - time.elapsed())`；`time.setTimeout(remain, autoRefresh)`；立即推一次空商店数据 |
| `meritShopFlow.autoRefresh(player)` | `autoDone=false` 时免费抽 5 件并推送；置 `autoDone=true` |
| `meritShopFlow.manualRefresh(player)` | 未到首批时间 → 播报剩余秒数；杀敌 < 200 → 播报不足；否则 `player:worth("-", { kill = 200 })` → 重抽 → 推送 |
| `meritShopFlow.buy(player, slotIndex)` | 校验玩家/英雄存活/商品/限购/余额 → 扣折后价 → `商店_已购_<key> + 1` → 发放效果 → 推送 |
| `meritShopFlow.makeData(player)` | 下发 `{ playerIndex, kill, refreshCost, autoAt, autoDone, slots }`；每项含 `key,name,icon,desc,quality,qualityName,qualityColor,border,baseCost,cost,discountLabel,limit,left,owned` |
| `meritShopFlow.push(player)` | `async.call(player, function() UIKit(KIT):refresh(data) end)` |

**购买发放**（从旧 `applyBuff` / `applyFunc` 复制，效果与旧商店一致）

- Buff：`BuffClear` + `Buff(...)`，Buff key 仍为 `shop_<key>`；`buff_rage/iron/bounty/vamp/regen` 同旧实现，`buff_haste` 用 `job.attrBuff`。
- 功能增幅：`player:set("商店增幅_" .. key, ownedOf(player, key))`。
- 限购：`ownedOf` 读 `商店_已购_<key>`；达到 `limit` 时拒绝购买并播报「本局已购满」。

**同步**

```lua
sync.receive("xlik_zhangong_refresh", function(syncData) ... end) -- { playerIndex }
sync.receive("xlik_zhangong_buy", function(syncData) ... end)     -- { playerIndex, slotIndex }
```

## 五、假设与决策说明

1. **首批免费**：180 秒自动刷新不扣 200 杀敌数（用户已确认）。
2. **主动刷新时机**：首批出现前刷新格锁定（只显示倒计时），首批后才允许花 200 杀敌数刷新。
3. **商品点击即购买**：横排格子空间小，单击直接购买，详细信息走悬停提示；不设详情区/购买按钮。
4. **品质只影响稀有度与展示**，不改价格/效果数值。
5. **状态复用旧键**：`商店_已购_<key>`、`商店增幅_<key>`，保证功能增幅与随机事件系统无需改动即可生效。
6. **常驻面板不参与 `uiPriority`**，也不注册 ESC 关闭；被其它面板遮挡时按 UI 层级自然覆盖。

## 六、验证步骤

1. **启动**：进入游戏后右下技能栏上方出现 6 格横条，前 5 格为空，刷新格显示「180s 后自动刷新」；旧「商店」技能按钮不再出现。
2. **3 分钟**：到 180 秒时前 5 格自动出现商品，杀敌数不减少；刷新格变为「刷新 / 200杀敌」。
3. **刷新**：杀敌 <200 时点击刷新格被拒（提示杀敌不足）；≥200 时点击扣 200 并重摇 5 件；重复刷新正常。
4. **品质**：多次刷新可观察到 5 种品质色名称/边框；高品质出现频率明显低于普通；5 格不重复。
5. **折扣**：出现「9/8/7/6/5折」角标；5折明显稀少；购买时按折后价扣杀敌数，余额正确。
6. **购买**：
   - Buff 类商品购买后英雄出现对应 Buff（图标/效果，60/120 秒）；
   - 功能类商品购买后 `商店增幅_<key>` +1，随机事件触发时数值提升；
   - 达到限购后该格置灰「已购满」，无法再买。
7. **回归**：旧商店文件与 `xlik_shop` UI 未被修改；英雄技能栏其它技能（天赋/药水/闪烁/传送/范围拾取）位置与热键正常；`xlik_plate`、`xlik_info`、存档/签到/宝库等面板开关不受影响。
8. **断线/重开**：重新开局后商店状态归零，首批仍在 3 分钟刷新。
