# 四角挑战改造方案（替换资源挑战 / 转生挑战）

## 一、目标概述（Summary）

把现有的「资源挑战」「转生挑战」两条独立流程（NPC + 传送房 + 4 档难度技能 + 金币消耗 + 等级门槛/成长）**完全替换**为一套常驻开放世界的「四角挑战」：

- 地图四角各常驻 1 只挑战怪，按奖励分为 4 类：**金币挑战 / 经验挑战 / 天赋挑战 / 宝物挑战**。
- 开局各刷新 1 次；被击杀后 30 秒在同一角落刷新下一只。
- 击杀后**全队每名玩家直接按该角类型获得对应奖励**（无需选择面板）。
- 本局通关（`game.pass`）后**停止刷新并清除**场上挑战怪。

数值取自现有公式（用户确认）：
- 金币 / 经验 / 天赋挑战怪 → 复用 **资源挑战怪** 公式（`scripts/globals/tpl/ability/npc/资源挑战.lua` 的 `get_base_life/defend/attack` 及其倍率表）。
- 宝物挑战怪 → 复用 **转生挑战怪** 公式（`scripts/globals/tpl/ability/npc/转生挑战.lua` 的 `get_base_life/defend/attack` 及其倍率表）。
- 等级基准：`level = game.selected.difficulty`（N1~N49），不再有个人成长等级。

## 三、改造方案（Proposed Changes）

### 3.1 新增：`scripts/globals/setup/四角挑战.lua`（全局 `cornerChallenge`）

一个自包含系统文件，包含配置、公式表、生成/刷新/结算逻辑。结构：

1) **角落配置表**（类型、角落、坐标、怪物模板、数值族、奖励出口），角落坐标沿用现有 NPC 位置：

| 角落 | 类型 | 坐标 (x, y) | 怪物模板 | 数值公式 | 奖励（全队每人） |
|---|---|---|---|---|---|
| 左上 | 金币挑战 | (-3618, 3712) | `ZiYuanTiaoZhanGuai` | 资源挑战怪公式 | 金币 +`val_list[level]` |
| 右上 | 经验挑战 | (3490, 3712) | `ZiYuanTiaoZhanGuai` | 资源挑战怪公式 | 经验 +`reward_exp_list[level]` |
| 右下 | 天赋挑战 | (3490, -4160) | `ZiYuanTiaoZhanGuai` | 资源挑战怪公式 | 天赋点 +`(level-1)//4+1` |
| 左下 | 宝物挑战 | (-3618, -4160) | `ZhuanShengTiaoZhanGuai` | 转生挑战怪公式 | 每人弹宝物 3 选 1 面板 |

> 角落→类型映射为默认方案，改一行配置即可调整。

2) **数值表与公式**：把两个旧文件里的倍率表与公式**原样搬入**（保持缩放口径不变）：
   - 资源族：`mul_list1`、`mul_list2`、`val_list`、`reward_exp_list`、`get_reward_gift`、`get_base_life/defend/attack`（含进阶 ×2/×3/×4、追击 ×20/×30/×40 与 `mul_list*[difficulty]`）。
   - 转生族：`life_list`、`defend_list`、`attack_list`、`mul_list`、`atk_mul_list`、`get_base_life/defend/attack`（含追击 ×30/×10/×30、超进化 ×88）。
   - 统一 `local function challengeLevel() return game.selected.difficulty or 1 end`；旧的 `index`（1~4）与 `资源挑战等级/转生挑战等级` 全部去掉，倍率函数的 `index` 按 **1** 取（即攻速倍率：资源怪 30、转生怪 100）。

3) **怪物属性**（`level = challengeLevel()`）：
   - 资源族（金币/经验/天赋）：`hp=life(level)`、`defend=defend(level)`、`attack=attack(level)`、`attackSpeed=30`、`attackSpaceBase(1)`、`move(400)`、`attackRangeAcquire(800)`、`level(level)`；攻击距离：进阶/追击 `600`，否则 `200`；**进阶模式**追加 `TPL_ABILITY.ZiYuanBoss_BaoJi`。
   - 转生族（宝物）：`hp=life(level)`、`defend=defend(level)`、`attack=attack(level)`、`attackSpeed=100`、`attackSpaceBase(1.25)`、`move(400)`、`attackRangeAcquire(800)`、`level(level)`；攻击距离：进阶/追击 `600`，否则 `300`；**进阶/追击**追加 `TPL_ABILITY.ZhuanShengBoss_BaoJi`。

4) **生成/刷新**：
   - `cornerChallenge.monsters[i]`：4 个角落当前怪（`Unit` 或 nil）。
   - `cornerChallenge.spawn(i)`：在角落坐标创建怪、挂死亡回调、挂 BOSS 暴击（按族与模式）。
   - 死亡回调：标 `monsters[i]=nil` → **给全队发放该角奖励** → 广播 `sync.send("玩家-击破四角挑战怪", { player })`（供引导，逐玩家）→ 若未停止则 `time.setTimeout(30, spawn(i))` 并记录 timer 句柄。
   - `cornerChallenge.spawnAll()`：开局对 4 个角落各 `spawn(i)`。

5) **全队发放**（`giveReward(corner)`）：
   - 遍历 `1..player.startQuantity`，对 `isPlaying()` 且 `class.isObject(pla.hero, UnitClass)` 的玩家发放；金币/天赋点无需英雄（但仍以有效玩家为准统一处理），经验/宝物需英雄句柄。
   - 每个玩家一条 `alerter.message` 提示；宝物逐人 `game.treasure.openPanel(pla)`。

6) **通关清除**：
   - `cornerChallenge.setup()` 注册 `event.syncRegister("player", "slkc_game_clear", ...)`：置 `stopped=true` → `class.destroy` 所有存活挑战怪 → `class.destroy` 所有待刷新 timer。
   - `spawn` 内首行判 `game.pass or stopped` 则直接 return（防止清除后定时器/竞态再刷）。

7) **导出给引导用**：`cornerChallenge.firstAlive()` 返回第一个存活挑战怪（`Unit|nil`）。

## 四、假设与决策（Assumptions & Decisions）

1. **等级基准**：`level = game.selected.difficulty`。⚠️ 注意 **双重难度缩放**：资源/转生族公式本身已乘 `mul_list*[difficulty]`，再令 `level=N` 会让 `level^2.75`/`level` 项也随难度上涨，N 高时数值增长很快。若实机数值过大，只需调整 3.1 的 `challengeLevel()`（例如改回固定 1，或改公式），不影响其它逻辑。
2. **奖励发放口径**：全队 = 所有 `isPlaying()` 且有英雄的玩家，**不要求参与伤害/击杀贡献**；每名玩家各自独立获得该角奖励。
3. **刷新规则**：同一角落死亡后 30 秒刷新**同类型**怪；「下一个」即该角的下一只。
4. **通关行为**：`slkc_game_clear` 后停止刷新并清除场上挑战怪（含取消未触发的刷新定时器）。
5. **移除项**：金币消耗、难度门槛、`资源挑战等级`/`转生挑战等级` 成长、`正在挑战` 互斥在本系统不再使用（`正在挑战` 仍供存档挑战/爬塔复用，保留）。
6. **角落→类型映射**为默认方案，可调整。
7. 商城道具描述的 33% 双倍奖励等本就未实现，本次不新增。
8. 不执行打包/游戏内测试（按用户约定）；仅做静态检查。
