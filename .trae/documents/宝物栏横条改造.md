# 宝物栏改造为「底部居中横条 + 水平滑动条」（照搬老图）

## 一、目标概述（Summary）

把 xlik_treasure 套件里的「宝物栏」（已获得宝物 UI）从现在的 **8 列 × 4 行居中网格面板**，改成老图（死灵狂潮 `内容/宝物/界面/客户端/类声明.lua` 的 `class.宝物栏`）那样的形态：

- **单排横条**：所有宝物格子排成一行（老图 `hcommon_panel` 传 `row_num=1`）。
- **底部居中、控制台上方**：面板水平居中，底边距窗口底部约 205px（老图 `x=500, y=745, w=975, h=130`）。
- **水平滑动条**：底部一条可拖动/滚轮滚动的横向滑动条，内容超出可视区时滚动查看（老图 `hscroll_bar` 等价物）。
- **格数口径**：总格数 = `treasure.volume()`（默认 15，有仙灵琥珀 19），可视 14 格。

**不改动**：「选择宝物」3 选 1 弹窗（`offerLayer`）、左下角「宝物(N)」按钮、N 键开关、悬停提示、冷却遮罩、LK_DEBUG 点格子、服务端同步逻辑（`sync.send` 各键）全部保持。

### 3.4 新增横向滚动逻辑（放在 `toggleBar` 之前或 `_updateBar` 附近）

```lua
--- 滚动到指定列偏移(整数列; offset=0 表示第 1 格在最左)
---@param offset number
---@return void
function ui:_scrollTo(offset)
    local total = math.max(VISIBLE_COLS, tonumber(self._volume) or SLOT_MAX)
    local maxOffset = math.max(0, total - VISIBLE_COLS)
    offset = math.floor(tonumber(offset) or 0)
    offset = math.max(0, math.min(maxOffset, offset))
    self._offset = offset
    --- 行容器整体左移: 第 offset+1 格落在窗口最左(LEFT_TOP 系里负 x = 向左)
    self.grid:relation(UI_ALIGN_LEFT_TOP, self.viewport, UI_ALIGN_LEFT_TOP, -offset * SLOT_PITCH, 0)
    --- 旋钮位置(offset=0 -> 旋钮在最左)
    local kx = (maxOffset > 0) and ((offset / maxOffset) * KNOB_TRAVEL) or 0
    self.knob:relation(UI_ALIGN_LEFT_TOP, self.track, UI_ALIGN_LEFT_TOP, kx, (SCROLL_H - KNOB_H) / 2)
    --- 窗口外 / 超出格数的格子隐藏(虚拟滚动, 不依赖裁剪 API)
    for i = 1, SLOT_MAX do
        self.barSlots[i]:show(i > offset and i <= offset + VISIBLE_COLS and i <= total)
    end
end

--- 滚轮(向上 = 看前面的格子)
---@param delta number
---@return void
function ui:onWheel(delta)
    if (nil == self.barPanel or true ~= self.barPanel:isShow()) then
        return
    end
    delta = tonumber(delta) or 0
    if (delta == 0) then
        return
    end
    self:_scrollTo(self._offset + ((delta > 0) and -1 or 1))
end

--- 开始拖动旋钮
---@return void
function ui:beginDrag()
    local total = math.max(VISIBLE_COLS, tonumber(self._volume) or SLOT_MAX)
    local maxOffset = math.max(0, total - VISIBLE_COLS)
    if (false == ui:isBarShown() or maxOffset <= 0) then
        return
    end
    self._dragKey = kit .. ":knobMove"
    self._dragStartRx = japi.MouseRX()
    self._dragStartOffset = self._offset
    mouse.onMove(self._dragKey, function(msData)
        --- rx 为"从屏幕左侧起算"的坐标: 向右拖 = rx 变大 = 看后面的格子
        local step = KNOB_TRAVEL / maxOffset
        local cols = math.floor((msData.rx - ui._dragStartRx) / step + 0.5)
        ui:_scrollTo(ui._dragStartOffset + cols)
    end)
end

--- 结束拖动旋钮
---@return void
function ui:endDrag()
    if (nil ~= self._dragKey) then
        mouse.onMove(self._dragKey, nil)
        self._dragKey = nil
    end
end
```

`isBarShown()` 若不想新增可直接复用 `self.barPanel:isShow()`，或新增一个薄封装：

### 3.5 适配 `_updateBar()`（现 [main.lua:468-494](file:///d:/Lua/xlik-jade/vendor/assets/war3mapUI/xlik_treasure/main.lua#L468-L494)）

改为：先算 `volume`，再只给 `1..volume` 填图标/遮罩，最后 `self:_scrollTo(self._offset)` 统一管理显隐：

```lua
function ui:_updateBar()
    local panel = self.barPanel
    if (nil == panel or true ~= panel:isShow()) then
        return
    end
    local hero = localHero()
    local pla = localPlayer()
    --- 格数: 默认 15, 有仙灵琥珀 19(取不到模块/玩家时按上限 19 兜底)
    local volume = SLOT_MAX
    if (type(treasure) == "table" and type(treasure.volume) == "function" and nil ~= pla) then
        volume = treasure.volume(pla) or SLOT_MAX
    end
    self._volume = volume
    for i = 1, SLOT_MAX do
        if (i > volume) then
            self.barSlots[i]:show(false)   -- 超出当前格数上限的槽位不显示(_scrollTo 也不会再打开)
        else
            local tre = (nil ~= hero and nil ~= hero.treasure_list) and hero.treasure_list[i] or nil
            if (nil == tre) then
                self.barSlots[i]:texture(EMPTY_SLOT_TEXTURE)
                self.barSlots[i]:maskRatio(0)
            else
                self.barSlots[i]:texture(tre.art or X_UI_QUESTION)
                local ratio = 0
                if (type(tre.cdMax) == "function" and tre:cdMax() > 0 and tre:cdLeft() > 0) then
                    ratio = tre:cdLeft() / tre:cdMax()
                end
                self.barSlots[i]:mask("interfaces/iconCoolDown")
                self.barSlots[i]:maskRatio(ratio)
            end
        end
    end
    self:_scrollTo(self._offset)
end
```
