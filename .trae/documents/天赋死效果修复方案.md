# 天赋死效果修复方案

## 一、摘要

天赋系统（[天赋.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua)）中有 **7 处效果"写了但无人消费"**：天赋点照常扣、`_attr` 也照常写，但没有任何系统读取这些键，玩家等于白花点数。

本次范围（已与用户确认）：**只修死效果** —— 让这 7 处效果真正生效；不改数值公式、不动点数投放/等级上限、不加洗点、不改存档、不改 UI 交互。

## 二、现状分析

`applyTalentEffects` 把部分效果写进 `hero._attr`（额外属性表），但这些键**没有消费方**。逐项核实：

| 天赋 | 档位 | 写入键 | 现状 | 应有语义 |
| --- | --- | --- | --- | --- |
| attack 攻击力 | 10/20 | `攻击恢复%` | 无任何读取者（真正的窃取键是 `生命窃取%`，且仅被个别宝物自结算） | 生命窃取 +10%/+20% |
| attack 攻击力 | 25/30 | `攻击加成` | 仅属性面板展示（[英雄属性.lua:93](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/英雄属性.lua#L93)），无战斗消费 | 攻击力 +10%/+15% |
| life 生命上限 | 25/30 | `生命加成` | 仅属性面板展示（[英雄属性.lua:95](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/英雄属性.lua#L95)），无战斗消费 | 生命上限 +15%/+20% |
| all 全属性 | 15/20 | `主要属性提升` | 无任何读取者 | 主属性 +10%/+15% |
| all 全属性 | 25/30 | `全属性加成` | 无任何读取者 | 全属性（三围）+10%/+15% |
| all 全属性 | 35/40 | `杀敌全属性` | 无任何读取者 | 每次击杀 +0.05/+0.1 全属性 |
| gold 金币加成 | 25/30 | `攻击间隔` | 无任何读取者（`单位额外属性.lua` 定义了键、`存档流程.lua`/`随机事件.lua` 也只会写这个死键） | 攻击间隔 -0.02/-0.03 秒 |

关键结论：

- attack / life / all / gold 四个主力成长天赋，**约 15 级以后基本不再产出生效收益**。
- 项目已有的成熟落地手段（可复用，不新增系统）：
  - **百分比增幅** → 引擎「终结增幅」`hero:ampl(key, v)`（v 为百分比点，读取时额外乘 `(1+v%)`）——见 [专属装备.lua:281-283](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/item/专属装备.lua#L281-L283) 的 `ampl` 分支与 [unitAttr.lua](file:///d:/Lua/xlik-jade/library/class/vast/unitAttr.lua#L207-L225)。
  - **攻击间隔** → 引擎基础攻击间隔 `hero:attackSpaceBase("-=0.02")`（最终 `attackSpace = attackSpaceBase/(1+attackSpeed%)`，见 [_vastModifier.lua:835-851](file:///d:/Lua/xlik-jade/library/class/vast/_vastModifier.lua#L835-L851)）。
  - **回血** → `job.heal(unit, value)`（[职业工具.lua:226](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/职业工具.lua#L226)）。
  - **击杀事件** → `eventKind.unitKill`（[injury.lua:236](file:///d:/Lua/xlik-jade/library/common/injury.lua#L236) 已 `syncTrigger(killer, eventKind.unitKill, ...)`）。
  - **主属性 key** → `game.method.primaryKey(hero)`（返回 `"str"|"agi"|"int"`，[game.lua:410](file:///d:/Lua/xlik-jade/projects/demo/library/common/game.lua#L410)）。

## 三、修改方案

### 3.1 [天赋.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua)：写入端接通 + 新增两个消费点

**（1）新增 ampl 累加小助手**（放在 `addAttackSpeed` 之后）

```lua
--- 累加"终结增幅"(ampl): 在获取该属性最终值时额外乘 (1+v%)
--- 与 专属装备.lua applySource 的 ampl 分支同口径(读当前值再叠加, 便于与其他增幅共存)
---@param hero Unit
---@param key string
---@param val number
---@return void
local function addAmpl(hero, key, val)
    hero:ampl(key, (hero:ampl(key) or 0) + val)
end
```

**（2）attack 分支**

- 10/20 级：`攻击恢复%` 的写入**保持不变**（该键将由 3.1(4) 新增的消费点结算，故不要改成 `生命窃取%`，否则会与「吸血面罩」「撒旦邪力」各自的窃取自结算重复叠加）。
- 25 级：在现有 `addExtra(hero, "攻击加成", 10)` 之外，追加 `addAmpl(hero, "attack", 10)`。
- 30 级：追加 `addAmpl(hero, "attack", 15)`。
  - 保留 `_attr['攻击加成']` 写入是为了让属性面板（`英雄属性.lua` 第 93 行）继续显示该数值。

**（3）life 分支**

- 25 级：在 `addExtra(hero, "生命加成", 15)` 之外，追加 `addAmpl(hero, "hp", 15)`。
- 30 级：追加 `addAmpl(hero, "hp", 20)`。

**（4）all 分支**

- 15 级：在 `addExtra(hero, "主要属性提升", 10)` 之外，追加 `addAmpl(hero, game.method.primaryKey(hero), 10)`。
- 20 级：追加 `addAmpl(hero, game.method.primaryKey(hero), 15)`。
- 25 级：在 `addExtra(hero, "全属性加成", 10)` 之外，对 `str/agi/int` 各 `addAmpl(hero, k, 10)`。
- 30 级：对 `str/agi/int` 各 `addAmpl(hero, k, 15)`。
- 35/40 级：`addExtra(hero, "杀敌全属性", 0.05/0.1)` 的写入**保持不变**，由 3.1(5) 新增的击杀消费点结算。

**（5）gold 分支**

- 25 级：在 `addExtra(hero, "攻击间隔", -0.02)` 之外，追加 `hero:attackSpaceBase("-=0.02")`。
- 30 级：追加 `hero:attackSpaceBase("-=0.03")`。

**（6）新增消费点 A —— 生命窃取结算**（改 `slkc_talent_mech` 普攻处理器）

当前该处理器先判断 `splitLv/multiLv/chainLv` 全为 0 就直接 `return`，导致只投入 attack 天赋的玩家拿不到窃取。调整顺序：把 `base` 取值与窃取结算**提到该 early-return 之前**：

```lua
    --- 现有: 取 base
    local base = evtData.damage or 0
    if (base < 1) then
        return
    end
    --- 攻击力天赋 10/20 级: 生命窃取(按本次普攻伤害比例回血)
    local steal = (hero._attr and hero._attr["攻击恢复%"]) or 0
    if (steal > 0) then
        job.heal(hero, base * steal * 0.01)
    end
    --- 之后才是原有的 splitLv/multiLv/chainLv 判定
    local splitLv = talentLevel(owner, "split")
    ...
```

**（7）新增消费点 B —— 杀敌全属性结算**（新增一个 `unitKill` 处理器，与普攻处理器并列）

```lua
--- 天赋「全属性」35/40 级: 每击杀一个单位, 按 _attr['杀敌全属性'] 增加三围
event.syncRegister(UnitClass, eventKind.unitKill, "slkc_talent_killattr", function(evtData)
    ---@type Unit
    local hero = evtData.triggerUnit
    if (false == class.isObject(hero, UnitClass) or true == hero:isDead()) then
        return
    end
    local v = (hero._attr and hero._attr["杀敌全属性"]) or 0
    if (v <= 0) then
        return
    end
    hero:str("+=" .. v)
    hero:agi("+=" .. v)
    hero:int("+=" .. v)
end)
```

> 说明：`unitKill` 的 `triggerUnit` 即击杀者（见 [injury.lua:236](file:///d:/Lua/xlik-jade/library/common/injury.lua#L236) 的 `syncTrigger(killer, ...)`）。

### 3.2 [英雄属性.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/英雄属性.lua#L89)：让生命窃取可观测

## 四、假设与决策

| 项 | 决定 |
| --- | --- |
| 生命窃取用什么键 | 沿用天赋已写的 `攻击恢复%`，并为其新增一个通用消费点；**不**改写为 `生命窃取%`（后者已被「吸血面罩」「撒旦邪力」各自在普攻时自结算，改键会造成重复叠加） |
| 「%攻击/生命/全属性/主属性」落地方式 | 引擎「终结增幅」`hero:ampl(key, 读当前值 + 增量)`（与鞋子/专属装备/宝库同口径，可在同一属性上共存叠加） |
| `_attr['攻击加成'/'生命加成']` 是否保留 | 保留写入，仅用于属性面板展示；实际效果由 `ampl` 承担 |
| 攻击间隔落地方式 | 直接作用于引擎基础间隔 `attackSpaceBase`（最终间隔 = 基础间隔/(1+攻速%)），最贴近「攻击间隔 -0.02/-0.03 秒」 |
| 杀敌全属性 | 新增 `unitKill` 处理器，击杀时给三围各加 `_attr['杀敌全属性']` |
| 是否影响转职 | 不影响：转职是「增量迁移」（[转职.lua:5-7](file:///d:/Lua/xlik-jade/projects/demo/scripts/process/转职.lua#L5-L7)），等级/物品/天赋成长均保留；`ampl` 与 `_attr` 同样保留 |
| 明确不在本次范围 | 点数投放/等级上限/成长公式的平衡、刷新机制、洗点重置、存档持久化、候选池/UI 改动 |

## 五、验证步骤

1. **语法**：用 `luac -p` 校验 `天赋.lua`、`英雄属性.lua`。
2. **实机**（`xlik.exe run demo -l`）：用 `-tf` 或临时把 `player:set('天赋点', ...)` 调高，并为便于命中特定档位可临时 `player:set("talent_<key>", N-1)` 后按 T 学一级：
   - attack 10 级：攻击一个非满血小怪 → 自身回复约等于本次普攻伤害的 10%；属性面板「生命窃取」显示 10%。
   - attack 25/30 级：面板「当前攻击」相对之前约 +10%/+15%，且「攻击加成」同步显示 10%/15%。
   - life 25/30 级：面板「当前生命」上限约 +15%/+20%，「生命加成」同步显示。
   - all 15/20 级：主属性（按 `primaryKey`）约 +10%/+15%。
   - all 25/30 级：力量/敏捷/智力各约 +10%/+15%。
   - all 35/40 级：击杀若干小怪后力量/敏捷/智力按每次击杀 0.05/0.1 缓慢增长。
   - gold 25/30 级：面板「攻击间隔」各下降约 0.02/0.03 秒。
3. **回归**：
   - 触发一次转职后，上述天赋加成仍保留（等级/物品/天赋不丢）。
   - 分裂/多重箭/闪电链的触发与伤害与改动前一致（仅调整了普攻处理器中窃取结算的位置，未改这三者逻辑）。
   - 同时携带「吸血面罩」（`_attr['生命窃取%']` 自结算）时，生命窃取不出现翻倍（天赋走 `攻击恢复%`、宝物走 `生命窃取%`）。
