# 新手指引独立 UI 设计稿 v3（已实现）

> 设计已确认并落地：`vendor/assets/war3mapUI/slkc_guide` + `projects/demo/scripts/process/界面刷新.lua`。
>
> v3 变更：
> - 主卡移除「引导」按钮，只保留「收起 / 知道了」；
> - 每张主卡用**指向尾 + 引导线箭头**直接指向对应位置；
> - 卡片改为「青铜铭牌 + 羊皮纸内衬」的不规则造型，不再使用纯方框。

## 一、设计方向

每个指引都是独立小卡，锚定在对应 HUD 元素或世界目标旁：

- 说到技能，就贴在技能栏旁，箭头指向 Q/W/E 槽；
- 说到进化，就贴在右下英雄板旁，箭头指向等级/经验区；
- 说到天赋，就贴在技能栏旁，箭头指向 T 槽；
- 说到挑战，就贴在左下挑战按钮旁，箭头指向 4 个按钮；
- 说到商店，就贴在战功商店横条旁，箭头指向商品格；
- 说到泉水/神符/死亡，就用世界坐标悬浮标记。

同一时间最多显示 **1 张主卡 + 1 条轻提示**。主卡不再放「引导」按钮，靠箭头直接告诉玩家“看哪里、点哪里”。

```
┌──────────────────────────────────────────────────────────────────────────┐

│ [P衣柜 ][B宝库 ][F6图鉴][V隐藏 ]              [==== BOSS 血条 ====]         │
│                                                                            │
│  ⑦世界标记·泉水                                        ⑦世界标记·神符        │
│                                                                            │
│                                    [战绩竖标签]                            │
│                                                    ⑤商店卡 → [战功商店横条]  │
│                                         ③天赋卡 ↘ [技能栏 4×3]              │
│  ④挑战卡 ← [金][经][天][宝]                ②进化卡 → [英雄血蓝板]            │
```

> 编号说明：① 操作卡 ② 进化卡 ③ 天赋卡 ④ 挑战卡 ⑤ 商店卡 ⑦ 世界标记。BOSS 与局外系统不显示引导卡。

## 三、主卡造型规范

不再使用“圆角矩形 + 三行文字”的方框，改为一张**青铜铭牌 + 羊皮纸内衬**的指引牌：

```
        ┌──────────────────────────────┐
        │ ●  技能栏 · 基本操作      ✦ │▷  ← 指向尾 + 引导线
        │    右键移动/攻击，Q/W/E 技能 │
        │    ──────────────────────    │
        │    技能栏右下角：Q/W/E / R   │
        │                    收起      │
        └──────────────────────────────┘
```

| 部位 | 设计 |
|---|---|
| 外框 | 青铜色、切角（左上/右下切 12px），不是完整矩形 |
| 内衬 | 羊皮纸色底板，与外框留 2px 青铜边 |
| 徽章 | 已取消：卡面不放圆形徽章与左侧小图标，文字直接从左侧留白起排 |
| 标题 | 金色，压在一条短绶带上；右上角小步骤号 |
| 分割 | 1px 暗金细线，不用单独卡片嵌套 |
| 进度 | 凹槽式细条，绿色填充 |
| 指向 | 侧尾卡在靠近锚点的一侧伸出 10×14px 三角尾；下尾卡在底部伸出三角尾，并接 80px 向下虚线箭头；线头落在目标边缘 |
| 变体 | 侧尾（挑战卡） / 下尾（操作、进化、天赋、商店卡）两种底图 |
| 铆钉 | 卡片右上、左下各 1 颗 3px 青铜铆钉 |
| 按钮 | 只有右下角文字按钮「收起」；操作卡为「知道了」，不再有「引导」按钮 |
| 底材颜色 | 青铜 `#8a6a35`；羊皮纸浅色 `#f3e9d2` / 深色 `#241f16`；标题金 `#e6c884`；正文 `#d8d3c2`；进度绿 `#7cff78` |
| 尺寸 | 256 × 120 px（下尾 256 × 136 px，1920×1080 基准） |
| 动效 | 入场 180ms 淡入 + 4px 位移；完成 120ms 淡出；指向目标 1.2s 呼吸描边（最多 2 次） |

> **落地版说明**：已去掉基础操作卡；进化卡放在「进化 x/N」文字上方；天赋卡放在红色十字天赋技能上方；挑战卡保持左尾；商店卡在商店横条上方。卡片整体加高，文字行距更宽松。
>
> **调试命令**：`-guide evo|talent|challenge|shop|off` 可强制显示/关闭某张指引卡。

### 显示规则

1. 主卡同一时间只显示 1 张，每张卡自己带指向尾与引导线。
2. 第一次进化完成后直接显示「③ 天赋卡」。
3. 开局 3 分钟商店出现时：
   - 若当前没有主卡，立即显示「⑤ 商店卡」；
   - 若当前还有主卡未完成，先发一条“战功商店已上架”的轻提示，等当前主卡完成后再显示商店卡，不插队打断。
4. 玩家乱序完成时，下一次刷新自动跳到第一个未完成的主卡。
5. BOSS 与局外系统不出引导卡；保留在 F9「玩法速查」中。
6. 温泉模式不显示任何新手引导。

## 五、逐卡文案

### ② 进化卡（指向「进化 x/N」）

- 标题：`完成第一次进化`
- 正文：`击杀 30 只小怪，自动进化成新职业`
- 进度：凹槽条 + `(0/30)`
- 奖励：`天赋点 +1`
- 按钮：`收起`
- 指向：卡片底部尖尾，指向英雄板右上的「进化 x/N」文字

### ③ 天赋卡（指向天赋技能）

- 标题：`学会第一个天赋`
- 正文：`按 T 打开天赋，消耗 1 点天赋点三选一`
- 奖励：`天赋永久生效`
- 按钮：`收起`
- 指向：卡片底部尖尾/短引导线，指向红色十字天赋技能

### ④ 挑战卡（指向左下挑战按钮）

- 标题：`击破一只挑战怪`
- 正文：`Alt+1~4 或点击按钮召唤，充能满 1 层可用`
- 次行：`右键按钮可开启自动挑战`
- 奖励：`金币 / 经验 / 天赋点 / 宝物`
- 按钮：`收起`
- 指向：卡片左侧三角尾 + 引导线，箭头落在 4 个挑战按钮右缘

### ⑤ 商店卡（指向战功商店横条）

- 出现时机：开局 3 分钟、战功商店首次上架后
- 标题：`战功商店`
- 正文：`商店已上架：用杀敌数购买本局增幅`
- 次行：`之后每次刷新 200 杀敌数`
- 奖励：`本局生效的增幅 / Buff`
- 按钮：`收起`
- 指向：卡片右侧三角尾 + 引导线，箭头落在商品格上

### ⑥ 专属满级卡（指向物品栏）

- 出现时机：任意一件专属装备升到 100 级
- 标题：`专属装备已满 100 级`
- 正文：`双击右键装备：洗炼词条（换词条/换颜色）`
- 次行：`商店「专属装备」：重铸（15 万金币，+16%）`
- 提示：`洗炼消耗金币，失败越多成功率越高`
- 按钮：`收起`
- 指向：卡片底部尖尾，指向物品栏里的专属装备



### ⑦ 泉水世界标记

- 图标：绿色泉水图标
- 文字：`泉水：每秒回复 10% 生命`
- 出现：首次血量低于 30%
- 消失：5 秒后或离开泉水范围

### ⑧ 神符世界标记

- 图标：神符模型对应图标
- 文字：`神符：拾取获得 20 秒增益`
- 出现：首次神符刷新
- 消失：5 秒后或拾取

### ⑨ 死亡世界标记

- 图标：`BTNAnkh`
- 文字：`还剩 X 次复活机会`
- 出现：首次死亡
- 消失：5 秒

## 六、关键节点弹窗

| 节点 | 形式 | 文案 |
|---|---|---|
| 第一次进化成功 | 主卡切换动画 + 轻提示 | `进化成功！获得 1 点天赋，并解锁 Q/W/E 职业技能` |
| 第一次转职三选一 | 进化面板右侧小提示条 | `选择职业，并保留 W/E 中的一个技能；30 秒未选自动选第一个` |
| 第一次奥义选择 | 奥义面板下方小提示条 | `从 5 个奥义中选 1 个，占用 R 键` |

> 不再新增 BOSS 与局外系统的引导卡/弹窗。

## 七、与旧方案的差异

| 旧方案 | 新方案 |
|---|---|
| 右上角一个固定任务面板 | 每步一张独立卡，锚定到对应 UI/世界目标 |
| 面板写「红色加号升级天赋」 | 箭头直接指向技能栏 T 槽并写「按 T」 |
| 展示未发放的奖励 | 只写真实收益 |
| 有「引导」按钮 | 移除；每张卡用三角指向尾 + 引导线直接指到目标 |
| 纯方框卡片 | 青铜铭牌 + 羊皮纸内衬 + 徽章 + 铆钉 + 切角 |
| 操作提示开局就弹 | 操作卡改为第一次进化、获得 Q/W/E 后再出现 |
| 商店卡在挑战后出现 | 商店卡改为 3 分钟商店出现后触发 |
| 有 BOSS/局外卡 | 移除，保留在 F9 玩法速查 |
