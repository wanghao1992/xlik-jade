# 存档系统迁移（核心 + 通关派生类）

## 一、目标与范围

照搬老图（死灵狂潮）存档系统的**数据结构与数值**，UI 按 xlik 规范**新建套件**（主分类 + 子分类 + 网格 + 上下页 + 关闭），存储照搬老图的**位宽打包**。

**第一版页签（6 个）**：地图等级、通关奖励、单通存档、速通存档、无尽存档、带新存档。

**入口**：功能栏 `xlik_funcbar` 的「存档(F2)」（当前是 `print` 占位）。

**第一版明确不做**（已确认，留注释/TODO）：
- 页签：商城道具、积分道具、存档BOSS、爬塔挑战、活动挑战、存档装备、存档装备改、团本存档、温泉存档、福利礼包、游戏成就
- 老图的 **UID 校验**（3 字符 md5 后缀，`server_api.lua:483-490`）
- **商城道具倍率**（老图 `20072036~20072047` 系列）→ 一律按 1 处理（demo 无商城道具系统）
- **物品类奖励**（传国玉玺/孤独王者/突破丹等）→ 只记录数值 + 面板展示，不实际发放（demo 无对应物品）

### 3.1 新增底层：`scripts/globals/setup/存档.lua`（全局 `saveArchive`）

**编码工具**（照搬 [core/util/string.lua:100-150](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/core/util/string.lua#L100-L150)）：

```lua
--- 90 进制字符表(前 90 个可打印字符, 顺序与老图一致)
local CODING = "..."
local CODE_INDEX = {}      --- 字符 -> 数值
local function toBaseX(dec, base)      --- 十进制 -> 字符串(代替 math.c10ToX)
local function fromBaseX(text, base)   --- 字符串 -> 十进制(代替 string.cXTo10)
```

**字段表**（照搬 [server_value_type.lua](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/core/platform/server_value_type.lua) 中本版用到的组，键名/位宽/类型原样）：

```lua
local FIELD = {
    ['正常模式通关数']     = { keys = {'ZCTGS1'...'ZCTGS9'}, 类型 = '数值', 位宽 = 4 },
    ['进阶模式通关数']     = { keys = {'JJTGS1'...'JJTGS9'}, 类型 = '数值', 位宽 = 4 },
    ['追击模式通关数']     = { keys = {'ZJTGS1'...'ZJTGS9'}, 类型 = '数值', 位宽 = 4 },

    ['超进化进阶模式通关数'] = { keys = {'CJJTGS1'...},      类型 = '数值', 位宽 = 4 },
    ['超进化追击模式通关数'] = { keys = {'CZJTGS1'...},      类型 = '数值', 位宽 = 4 },
    ['完美通关']           = { keys = {'ZCWMTG1','JJWMTG1','ZJWMTG1','CZCWMTG1','CJJWMTG1','CZJWMTG1'}, 类型 = '布尔值' },
    ['单通']               = { keys = {'ZCDT1','JJDT1','ZJDT','CZCDT1','CJJDT1','CZJDT'},              类型 = '布尔值' },
    ['速通']               = { keys = {'ZCST1','JJST1','ZJST1','CZCST1','CJJST1','CZJST1'},            类型 = '布尔值' },
    ['通关刷满']           = { keys = {'zctgsm','jjtgsm','zjtgsm'},                                      类型 = '布尔值' },

```

**记录模型**：每 key = **63 字符**（本版**去掉老图的 3 位 UID 后缀**，容量比老图多 3 → 位宽 4 时每 key 15 槽，布尔时每 key 63 字符 × 6 位 = 378 位）；组内多 key 拼接成虚拟记录（总槽数 = `#keys × (63 // 位宽)`）。

**对外 API**（对应老图同名能力）：

```lua
saveArchive.init(handle)                     --- 预热: 逐组 ServerLoadValue + 解码到内存
saveArchive.get(handle, 组, pos)             --- 数值读(默认 0)
saveArchive.set(handle, 组, pos, v)          --- 数值写(内存 + 编码回写)
saveArchive.add(handle, 组, pos, v)          --- 数值累加
saveArchive.getBool(handle, 组, pos)         --- 布尔读(默认 false)
saveArchive.setBool(handle, 组, pos, bool)   --- 布尔写
saveArchive.value(handle, key)               --- 单值读(对应 get_key/get_key2)
saveArchive.setValue(handle, key, v)         --- 单值写
saveArchive.ready(handle)                    --- japi.DZ_IsServerAlready 包装
```

要点：
- 写：`japi.ServerSaveValue(handle, key, 63字符记录)`（**字符串值不加前缀**，63 字符恰好不超限）；写入前判 `saveArchive.ready(handle)`，否则跳过（避免触发 `Roulette` 的空转与告警）。
- 读：`japi.ServerLoadValue(handle, key)` 返回字符串（无前缀时原样）；nil/空 → 默认值。
- 单值通道直接 `setValue(handle, 'DX', 120)`（number → 框架自动加 `N:` 前缀）。

  1. 按模式/超进化写通关数（`game.selected.mode` + `switch_nightmare`，`pos = game.selected.difficulty`）
  2. 完美通关：`英雄死亡次数 == 0` → `setBool('完美通关', 模式索引)`
  3. 单通：`在线人数 == 1` → `setBool('单通', 模式索引)`
  4. 速通：本局用时 ≤ `速通时间(难度)` → `setBool('速通', 模式索引)`
  5. 低难度自动补刷（`max_sum = 10` + `通关刷满N%d`）
  6. 通关积分：`通关积分 = Σ(积分默认列表[d] × 模式权重)`（权重 正常×1/进阶×2/追击×3/超进化×2/4/6，商城倍率按 1）→ `setValue('TGJF', jf)`

  9. 广播 `存档-写入完毕`（供其它系统挂钩）
- **面板数据组装** `saveFlow.build(player)`：返回 UI 需要的整份数据（见 §3.4 数据格式）。

## 四、决策与假设

| 项 | 决定 |
|---|---|
| 存档通道 | 统一 `japi.ServerSaveValue/ServerLoadValue`（平台存档）；dev 由本地服务器模拟 |
| 记录格式 | 每 key **63 字符**（老图 60+3 位 UID，本版不做 UID 校验）；组内多 key 拼接；数值 90 进制 + 位宽左补 0；布尔 6 位/字符位图 |
| key 命名 | **原样照搬老图**（`ZCTGS1..9`、`CDBOSS..` 等），便于与老图存档共存/迁移 |
| 预热时机 | 存档流程 process 启动时对 `player.startQuantity` 个玩家逐个 `saveArchive.init` |
| 面板数据 | 服务端权威：服务端算好条目 → 本地面板只渲染（客户端不读存档） |
| 面板可写性 | 只读展示（第一版无"领取"操作）；`xlik_save` 不做同步写回 |
| 商城/物品/UID | 全部按 §一 的"不做"清单处理，代码注释标注原文行号 |
| 命名 | 底层全局 `saveArchive`、业务全局 `saveFlow`、套件 `xlik_save`、同步 key `xlik_save_open` |
| 属性加成落点 | 用 xlik 等价物：`hero:attack/defend/hp/str/agi/int` + `hero._attr['xxx%']`（demo 伤害流程消费 `_attr`） |
