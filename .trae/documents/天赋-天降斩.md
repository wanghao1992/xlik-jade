# 新天赋「天降斩」设计与实现计划

## 一、需求与结论

在现有天赋三选一面板中新增一条 5 级机制卡链「天降斩」：

- **触发**：普攻命中时，若 25 秒冷却已就绪，且 2000 码内存在可锁定敌人，必定触发（不赌概率）。
- **表现**：自动锁定 2000 码内一个敌人 → 英雄腾空跳向目标 → 落地砸下 → 落地范围击飞 → 接一道剑气斩击造成物理伤害。
- **节奏**：整套动作重复 3 次，每次间隔 1 秒（起跳/落地/斩击约 0.5 秒，剩余时间留作下一段蓄势）。
- **冷却**：25 秒，固定不随卡牌等级缩短（尊重原始设定）。
- **伤害**：落地只做控制（0 伤害），伤害全部由斩击结算，以触发本次普攻的伤害为基数，物理伤害。

## 二、数值设计（5 级连锁）

| 卡片 | key | 名称 | 斩击倍率（攻击力） | 落地半径 | 剑气射程 | 剑气宽度(判定半径) | 击飞时长 | 击飞高度 |
|---|---|---|---|---|---|---|---|---|
| I | leap1 | 天降斩·坠落 | 110% | 300 | 1000 | 450 | 0.6s | 250 |
| II | leap2 | 天降斩·裂地 | 130% | 350 | 1000 | 450 | 0.6s | 250 |
| III | leap3 | 天降斩·断空 | 150% | 350 | 1000 | 600 | 0.8s | 250 |
| IV | leap4 | 天降斩·诛灭 | 170% | 350 | 1300 | 600 | 0.8s | 250 |
| V | leap5 | 天降斩·天诛 | 190% | 400 | 1300 | 750 | 1.0s | 300 |

- 25 秒内总伤害：I 级 3×110%=330% 攻击力；V 级 3×190%=570% 攻击力。
- 与现有机制卡口径对齐：剑气 5 级为 120% 攻击力/10 秒；天降斩 V 折算约 22.8% 攻击力/秒，同时附带 3 次范围击飞，强度合理。
- 剑气宽度按「半径」口径，与现有「剑气」卡一致（`job.lineSweep` 的 `halfWidth`）。

## 三、特效设计

| 阶段 | 特效 | 实现 |
|---|---|---|
| 起跳 | 风爆 + 残影 | 起跳点 `风爆.mdx`（`job.pointEffect`，缩放 `radius/400`，0.4s）；`az_jugggreen_e1_tailing.mdx` 附着英雄 0.5s |
| 腾空 | 抛物线跳跃 | `ability.leap`，`height = 320`，速度按距离换算使位移约 0.45s |
| 落地 | 践踏 + 击飞环 | 落点 `践踏.mdx`（缩放 `radius/400`，0.8s）；每个被击飞敌人脚下 `击飞.mdx`（0.5s） |
| 斩击 | 剑气飞行体 + 命中火花 | `job.lineSweep`，模型 `剑气.mdx`，速度 2200，缩放 `width/169`；命中点 `T7_zhan_hit02.mdx`（0.4s） |
| 第三段收尾 | 雷爆 | 第 3 次落地额外叠 `雷爆.mdx`（缩放 `radius/400`），强化终结感 |

复用已注册资源：`风爆.mdx`、`践踏.mdx`、`剑气.mdx`、`T7_zhan_hit02.mdx`、`az_jugggreen_e1_tailing.mdx`、`雷爆.mdx`。
仅需新增注册：`击飞.mdx`（`vendor/assets/war3mapModel/特效/击飞.mdx` 已存在，未在 `model_self.lua` 声明）。

#### 1.4 新增「天降斩系统」实现

位置：`fireSwordQi` 之后（第 1552 行后）、`slkc_talent_mech` 事件注册之前。要点：

```lua
local LEAP_RANGE = 2000        -- 锁敌半径
local LEAP_CYCLES = 3          -- 重复次数
local LEAP_INTERVAL = 1.0      -- 每次间隔
local LEAP_HEIGHT = 320        -- 跳跃弧线高度
local LEAP_TRAVEL = 0.45       -- 期望位移耗时
local LEAP_QI_MODEL = "剑气.mdx"
local LEAP_QI_NATIVE_WIDTH = 169
```

- `findLeapTarget(hero, prefer, exclude)`：
  - 优先 `prefer`（触发本次的普攻目标），存活且 2000 内有效则直接返回；
  - 否则用 `enemiesAround(hero:x(), hero:y(), 2000, hero:owner(), nil)` 选最近敌人；
  - 过滤 `isBuilding()`，`exclude` 用于「尽量不连续跳同一只小怪」，排除后无目标再允许重复。
- `startLeapSlash(hero, firstTarget, base)`：
  - 读取 `_attr` 的 7 个参数；
  - 循环 3 次，每次：
    1. 选目标、面向；
    2. 起跳特效（风爆 + 残影）；
    3. `ability.leap({ sourceUnit = hero, targetUnit = target, speed = clamp(dist/0.45, 800, 5000), height = 320, visible = false, onEnd = land })`；
    4. 兜底 `time.setTimeout(预计位移时间 + 0.2, land)`（`landed` 标记去重，处理 leap 被地形/目标死亡中断）；
    5. `land()`：落点 `践踏.mdx`；对 `enemiesAround(落点, 半径, hero:owner(), nil)` 中非建筑/BOSS 目标 `ability.crackFly({ distance = 0, height = 击飞高度, duration = 击飞时长 })` 并挂 `击飞.mdx`；随后 `job.lineSweep` 朝跳跃方向发射剑气，伤害 `base * 倍率`，物理伤害，`extra = { _slkcMechanic = true, _extraDamage = true }`，`onHit` 挂 `T7_zhan_hit02.mdx`；第 3 次额外叠 `雷爆.mdx`；
    6. `time.setTimeout(1.0, 下一段)`；
  - 每段开始/落地前都校验英雄存活、未销毁；英雄死亡则终止。

## 六、设计建议（已采纳 / 未采纳）

**已采纳：**

1. **落地 0 伤害，伤害全给斩击**：让「击飞 → 斩击」两段层次清晰，数字不会糊在一起，也符合原始描述。
2. **目标尽量不重复**：第一段锁定本次普攻目标，后续优先 2000 码内其他最近敌人；只有单目标时才连续跳同一只。避免 3 段全砸在一只小怪身上。
3. **跳过建筑、BOSS 免疫击飞**：沿用 `随机事件.lua` 的 `knockUp` 判定（`isBuilding()` / `get("BOSS")`），BOSS 仍吃斩击伤害。
4. **异常兜底**：`ability.leap` 在地形阻挡/目标消失时不会触发 `onEnd`，必须用计时器兜底落地，保证后续段数与伤害不丢失。
5. **第三段视觉强化**：第 3 次落地额外叠 `雷爆.mdx`，给连段一个收尾高潮（不改变数值与次数）。

**未采纳（可选后续）：**

- 第 3 段改为原地 360° 终结斩（半径 500、1.5 倍伤害）：更炸裂，但会偏离「重复 3 次跳劈」的原描述。
- 冷却随等级递减（25→22→19→16→12 秒）：升级收益更直接，但与用户给定的「25 秒冷却」冲突，默认固定 25 秒。

## 七、假设与决策

- 天赋为全局通用卡，不限制近战/远程（现有机制卡也不按职业过滤）。
- 斩击基数取触发本次普攻的 `evtData.damage`（与「剑气」一致）；若该值 < 1 则用 `hero:attack()` 兜底。
- 所有机制伤害带 `_slkcMechanic` / `_extraDamage` 标记，避免与「专属装备分裂」等系统互相触发。
- 冷却锁字段命名 `_talentLeapLock`，与现有 `_talentQiLock` / `_talentChainLock` 保持一致。
- 跳跃 Buff 传 `visible = false`，避免天赋触发时 buff 栏闪烁。
- 不新增独立文件，所有逻辑内聚到 `天赋.lua`，与法球/剑气/闪电链的现有组织方式一致。
