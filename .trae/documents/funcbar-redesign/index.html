改造影响 · main.lua

  • 按钮贴图由 151 × 50 铭板 改为 256 × 256 透明底图标，去掉底框与铭板，图形即按钮；游戏内按 0.022 × 0.028 展示（宽度收窄）。
  • 单排 8 个横列，GAP 为 0（按钮框紧贴），靠图标自带的透明留白形成视觉间距；文字在图标下方，字号 7、象牙白名称 + 暖灰快捷键。
  • 点击区域仍是方形，透明处也能点；如需更精准可用 UIBackdrop + 独立点击区 控制。
  • 悬停切换同名 「_亮」高亮贴图（内嵌主色光晕），按下沿用高亮层，无需顶点色或额外遮罩。
  • 文字为图标下方 「名称 + 快捷键」，字号 7，名称象牙白、快捷键暖灰。
  • 主色仅用于符文、悬停光晕与四角描金标记（宝库紫红 / 温泉蓝 / 签到绿 / 通行证橙 / 衣柜紫 / 存档青 / 图鉴金 / 隐藏灰），图标本体为暗铁石胎 + 鎏金线刻。
  • 英雄头像内下方显示 F1，颜色与图标快捷键一致（暖灰 #B9A77F），字号 7；随头像一起显隐。
  • 「隐藏 / 展开」逻辑不变：折叠时其余图标淡出缩小，开关图标停靠到首格。
