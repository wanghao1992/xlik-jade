# 新天赋「御剑飞行」实现计划

## 一、需求

在现有天赋三选一面板中新增一条 **5 级机制卡链「御剑飞行」**：

- **触发**：普攻命中时，若 40 秒内置冷却就绪且未在御剑中，自动开启。
- **表现**：英雄脚踩一柄大剑升空；周身 8 把飞剑环绕，自动索敌。
- **攻击**：每把小剑从英雄周身出发，沿圆滑弧线飞向敌人，命中造成 **固定值 + 主属性×系数** 的法术伤害；命中后自动寻找下一个目标。
- **循环**：每把小剑最多攻击 3 个目标后飞回英雄周身，停留 2 秒后再次出击。
- **时长**：基础持续 8 秒、冷却 40 秒；升级提升持续/伤害/索敌等。
- **结束**：持续时间到、英雄死亡或对象销毁时，销毁全部飞剑并还原英雄高度。

用户已确认：5 级分支、普攻命中触发、主属性加成法术伤害、使用 `绝命剑.mdx` 模型、生成 5 张新图标。

- 飞剑数量：8 把
- 环绕半径：170；环绕高度：英雄凌空高度 + 100

**取敌函数**（每次选目标时调用；过滤建筑、已命中目标、死亡单位）：

```lua
local function pickRideTarget(hero, params, hitSet)
    local pool = {}
    for _, u in ipairs(enemiesAround(hero:x(), hero:y(), params.search, hero:owner(), nil)) do
        if (false == u:isBuilding() and nil == hitSet[u:handle()]) then
            pool[#pool + 1] = u
        end
    end
    if (#pool <= 0) then return nil end
    return pool[math.rand(1, #pool)]
end
```

**弧线飞行任务**（使用二次贝塞尔）：

```lua
-- task = {
--   kind = "out"|"back", target = Unit|nil,
--   sx, sy, sz,  -- 起点
--   cx, cy, cz,  -- 控制点
--   t, dur       -- 进度/时长
-- }
-- 位置 = (1-t)^2 * 起点 + 2(1-t)t * 控制点 + t^2 * 终点
```

- `out`：终点每 tick 取目标当前坐标（目标移动时剑跟随弧线追击）；目标死亡则用最后记录坐标。
- `back`：终点每 tick 取英雄当前位置 + 该剑环绕角对应的环绕点。
- 控制点 = 起点与终点的中点向一侧垂直偏移 `min(RIDE_CURVE_MAX, max(60, 距离×0.35))`；左右方向按剑序号奇偶交替，避免 8 把剑走同一条弧线。
- 每 tick 移动后，用上一帧坐标到当前坐标的方向调用 `effector.rotateZ(effect, 角度 + RIDE_YAW_OFFSET)`，让剑身顺着飞行轨迹。
- 到达 `t >= 1` 时结算。

**每把剑的状态机**：

1. `idle`：绕英雄做圆周运动（角度递增，位置 = 英雄坐标极坐标 + 高度 `hero:h() + RIDE_ORBIT_HEIGHT`，朝向取切线方向）；当 `elapsed >= nextAt` 时取目标。
2. 取到目标：重置 `hits = 0`、`hitSet = {}`，以当前位置为起点生成 `out` 任务。
3. `out` 到达：
   - 目标存活：先挂受击特效，再 `talentMechanicDamage(hero, target, state.amount, injury.damageType.magic)`；
   - `hits = hits + 1`、`hitSet[target:handle()] = true`；
   - 若 `hits < params.maxHits` 且还能取到下一个目标 → 从当前位置继续生成 `out` 任务；
   - 否则生成 `back` 任务。
4. `back` 到达：销毁任务，进入 `idle`，`nextAt = elapsed + params.interval`，重置 `hits/hitSet`。
5. 取不到目标：保持 `idle`，每 tick 最多取一次敌（可选：同一 tick 内缓存一次敌群列表，避免 8 把剑重复枚举）。

**大剑表现**：

- 创建 1 把 `effector.agile(RIDE_MODEL, ...)`，缩放 `RIDE_BIG_SCALE`。
- 每 tick 放在英雄脚下：`x/y = hero:x()/hero:y()`，`z = hero:z() + (hero:flyHeight() or 0) + 5`；
- `effector.rotateZ(big, hero:facing() + RIDE_YAW_OFFSET)`。
- 若 `state.mounted` 为 true：隐藏大剑（坐骑已在脚下，避免模型重叠），仍保留 8 把小剑。

**升空与还原（Buff）**：

- 开始时取 `originHeight = tonumber(hero:flyHeight()) or 0`。
- 非骑乘且不在 `hero:isLeaping()` / `hero:isCrackFlying()` 时，创建 Buff：
  - key `talent_sword_ride`，名称「御剑飞行」，图标 `天赋/yujian1.blp`，持续时间 = `params.duration`；
  - `purpose`：若未骑乘，`o:flyHeight(originHeight + RIDE_RISE_HEIGHT)`；
  - `rollback`：若未销毁且未骑乘，`o:flyHeight(originHeight)`。
- 已骑乘时不改高度（坐骑流程每 0.012 秒接管英雄高度）。

**计时器 tick 顺序**：

1. 英雄销毁或死亡 → `stopSwordRide(hero, state)` 并返回；
2. `state.elapsed += RIDE_TICK`；
3. 更新大剑位置/朝向（或骑乘时隐藏）；
4. 逐把更新飞剑状态机与任务；
5. `elapsed >= params.duration` → `stopSwordRide(hero, state)`。

## 五、假设与决策

1. **键名避开剑阵**：使用 `yujian1~5`（卡片）、`_talentSwordRideState` / `_talentSwordRideLock`（状态/冷却）、`RIDE_*`（常量），不改动已实现的 `sword1~5` 剑阵。
2. **5 级链**：按用户选择，`levelMax = 1`，逐级依赖；升级提升持续、伤害基础、主属性系数、索敌、目标数与回归等待。
3. **普攻命中触发**：`unitAttack` 事件中触发，冷却锁从触发时刻开始计 40 秒（升级后 35/30 秒）。
4. **伤害**：开始御剑时快照 `base + job.primary(hero) × coeff`；每次命中走 `talentMechanicDamage(..., injury.damageType.magic)`，不会触发分裂/剑气/剑阵/专属装备等二次机制。
5. **8 把剑固定**：不随等级增加数量，保持用户要求的“周身 8 把小剑”。
6. **弧线路径**：二次贝塞尔；每把剑的弧线左右方向按序号奇偶交替，避免视觉重叠；剑身朝向按路径切线实时旋转。
7. **目标分散**：每次选目标时从索敌范围内随机挑选未被本剑本轮命中过的敌人，减少 8 把剑同时打同一目标。
8. **坐骑兼容**：已骑乘时不改英雄高度、隐藏脚下大剑，只保留 8 把小剑；高度完全交给坐骑流程管理。
9. **位移兼容**：开始御剑时若英雄处于 `leap` / `crackFly`，不修改高度；避免与位移技能争抢 `flyHeight`。
10. **模型朝向**：`绝命剑.mdx` 按剑身沿 +X 处理，仅用 `rotateZ` 控制水平朝向；若进图发现模型竖直/反向，只调 `RIDE_YAW_OFFSET` 或增加一次性 `rotateX`，不改逻辑。
11. **性能**：8 把剑共用一个 0.03 秒计时器；只在需要换目标时调用 `enemiesAround`，每轮御剑约几十次枚举，可接受。
