# 卡片合成系统方案

> 本方案在已实现的「图鉴系统」（见 [图鉴UI套件创建方案.md](file:///d:/Lua/xlik-jade/.trae/documents/图鉴UI套件创建方案.md)）基础上扩展，新增卡片合成。

## 一、目标与范围

新增一套卡片合成系统，包含一个独立 UIKit 套件与配套数据/逻辑：

1. **合成 UI 套件**（新套件 `xlik_cardsynth`）：左右两区。
   - **左区**：展示「拥有的卡片」列表，每格 = 小图标 + 名称 + 数量；点击一张 → 向右侧加一张。
   - **右区**：5 行，每行自左向右 = 三个输入框 + 箭头 + 一个结果框；右区下方一个「合成」按钮。
2. **合成规则**：3 合 1；一次点击处理所有「已填满 3 张」的行（未填满的行跳过）；同一行的 3 张卡**必须同品质**；产出为「对应品质内随机一张卡」。
3. **产出的品质**由配置表按「投入品质」决定（品质越高，升档概率越低，不产出低于投入品质的卡）。
4. **卡片品质**：按卡片在 35 条羁绊配方中的**出场次数**自动分 5 档（出现越多越普通），按排名均分。
5. **入口**：图鉴面板内新增「卡片合成」按钮 → 关闭图鉴、打开合成套件。

**范围边界（按用户确认）**：
- 只做「合成」，不做分解/回收/洗练。
- 复用现有存档组 `图鉴卡牌`（槽位=卡片 id），**不新增存档组**、**不新增图片资源**（图标仍占位 `X_UI_QUESTION`）。
- 结果仅展示在结果框内（不做飞行动画），成功/失败用 `alerter.message` 播报。
- 不改功能栏、不改创建英雄、不加调试命令（现有 `-card` 已足够造卡测试）。

### 3.1 品质与合成配置（文件开头 `codexData.icon` 之后新增）

```lua
--- 品质档数(1=最普通 .. 5=最高)
codexData.qualityMax = 5
--- 品质色(沿用 专属装备.lua 词条品质色)
codexData.qualityColor = { '|cff7aff0d', '|cff2af1ff', '|cffffff00', '|cffd992ff', '|cffff2190' }
--- 品质名
codexData.qualityName = { '普通', '优良', '稀有', '史诗', '传说' }
--- 合成概率表: 投入品质 -> 产出品质权重(下标=产出品质, 每行权重和=1000; 0 表示不产出该档)
---   约束: 不产出低于投入品质的档; 品质越高升档概率越低(体现"越高品质越难合成")
codexData.synthRate = {
    [1] = { 350, 500, 130, 20,   0 },   -- 投入普通: 升档概率 0.65
    [2] = {   0, 550, 350, 90,  10 },   -- 投入优良: 升档概率 0.45
    [3] = {   0,   0, 700, 250, 50 },   -- 投入稀有: 升档概率 0.30
    [4] = {   0,   0,   0, 850, 150 },  -- 投入史诗: 升档概率 0.15
    [5] = {   0,   0,   0,   0, 1000 }, -- 投入传说: 只产出传说(同档随机)
}
```

### 3.2 品质自动回填 + 按品质索引（文件**末尾**、羁绊配方转 id 之后追加）

```lua
--- 卡片品质: 按"在 35 条羁绊配方中的出场次数"自动分 5 档(出现越多越普通)
---   排序: 出场次数降序, 同次数按卡片 id 升序; 再按排名均分(每档 ceil(42/5)=9 张)
local appear = {}
for _, b in ipairs(codexData.bonds) do
    for _, r in ipairs(b.cards) do
        if (nil ~= r.id) then
            appear[r.id] = (appear[r.id] or 0) + 1
        end
    end
end
local ids = {}
for _, c in ipairs(codexData.cards) do
    ids[#ids + 1] = c.id
end
table.sort(ids, function(a, b)
    local ca, cb = appear[a] or 0, appear[b] or 0
    if (ca ~= cb) then return ca > cb end
    return a < b
end)
local perTier = math.ceil(#ids / codexData.qualityMax)
for rank, id in ipairs(ids) do
    codexData.cards[id].quality = math.min(codexData.qualityMax, math.floor((rank - 1) / perTier) + 1)
end

--- 品质 -> 卡片 id 列表(合成产出时在该品质内随机取一张)
codexData.byQuality = {}
for _, c in ipairs(codexData.cards) do
    local q = c.quality or 1
    codexData.byQuality[q] = codexData.byQuality[q] or {}
    table.insert(codexData.byQuality[q], c.id)
end
```

> 说明：品质纯计算、不落存档（数据驱动，改配方即改品质）。按上述算法，tier1≈{阿尔萨斯,伊利丹,萨尔,乌瑟尔,吉安娜,泰兰德,格罗姆,凯恩,玛法里奥}（出场 3~9 次），tier5 为末尾 6 张（剑圣/恶魔猎手/希尔瓦娜斯/地精工兵/娜迦海妖/血法师）。

复用文件内已有的 `GROUP_CARD`、`cardOf`、`isValid`。新增以下 API（放在「五、面板数据」之后新增一节「七、卡片合成」，并把 `sync.receive` 追加到「六、客户端请求」）。

### 4.1 对外 API

| API | 说明 |
|---|---|
| `codexFlow.cardQuality(cardId)` | 卡片品质（1..5），读 `codexData.cards[id].quality`，缺省 1 |
| `codexFlow.rollQuality(inQ)` | 按 `codexData.synthRate[inQ]` 权重随机产出品质（权重求和 → `math.rand(1,total)` → 累加命中） |
| `codexFlow.randomCardOf(q)` | 在 `codexData.byQuality[q]` 内均匀随机取一张卡片 id |
| `codexFlow.buildSynth(player, results)` | 组装合成面板数据（见 4.2） |
| `codexFlow.openSynth(player, results)` | `async.call` → `UIKit('xlik_cardsynth'):open/refresh(data)` |
| `codexFlow.synthesize(player, rows)` | 批量合成；返回 `ok, msg, results`（见 4.3） |

### 4.2 面板数据 `codexFlow.buildSynth(player, results)`

```lua
{
  rowMax = 5,                                   -- 右区固定 5 行
  qualityMax = 5,
  qualityColor = { ... },                        -- 透传给客户端渲染
  qualityName = { ... },
  cards = {                                      -- 仅"拥有(count>0)"的卡片
    { id, name, icon, count, quality }, ...
  },
  cardOwned = n,                                 -- 拥有的卡片种数
  results = { { row=1, id, name, icon, quality }, ... },  -- 本轮合成结果(可空)
}
```

### 4.3 合成 `codexFlow.synthesize(player, rows)`

- `rows`：长度 5 的数组，每项是「本次该行投入的卡片 id 列表」（0~3 个）。
- 取所有「恰好 3 张」的行；若一行都不满 → `return false, '没有可合成的行'`。
- **校验**（任一不满足即整体拒绝，返回 `false, 原因`，不扣卡）：
  1. 每行 3 张卡 `quality` 必须相同；
  2. 按卡片 id 汇总「本请求所需总数」≤ 该玩家 `saveArchive.get(handle,'图鉴卡牌',id)`。
- **执行**（逐行）：
  1. 扣 3 张（各行汇总后一次性 `saveArchive.set`）；
  2. `outQ = codexFlow.rollQuality(inQ)`；`winId = codexFlow.randomCardOf(outQ)`；
  3. `saveArchive.add(handle,'图鉴卡牌',winId,1)`；
  4. 记录 `results[#results+1] = { row = r, id = winId, name, icon, quality = outQ }`。
- 返回 `true, ('成功合成 %d 次'):format(#results), results`。

### 4.4 同步协议（追加到「六、客户端请求」）

```lua
--- 打开合成面板(transferData = { 玩家索引 })
sync.receive('xlik_cardsynth_open', function(syncData)
    codexFlow.openSynth(Player(syncData.transferData[1]))
end)

--- 执行合成(transferData = { 玩家索引, rows })  rows = { {id,...}, ... } 长度 5
sync.receive('xlik_cardsynth_do', function(syncData)
    local player = Player(syncData.transferData[1])
    local ok, msg, results = codexFlow.synthesize(player, syncData.transferData[2])
    async.call(player, function()
        alerter.message(player, ok and ('|cff6dff1e[图鉴]|r ' .. msg) or ('|cffff2121[图鉴]|r ' .. msg))
    end)
    codexFlow.openSynth(player, ok and results or nil)   -- 已打开则 refresh
end)
```

### 5.3 本地状态与交互

- `self._pending`：长度 5 的数组，每项是本次该行已放入的卡片 id 列表（最多 3）。
- `self._results`：最近一次合成结果（对应 `data.results`），渲染到结果框。
- **点击左区卡片 `clickCard(slot)`**：
  1. 换算到当前页数据下标，取卡片 id 与品质 `q`；
  2. 若「该卡已选总数」已等于其拥有数 → 不处理（可选：`sound` 提示）；
  3. 找到**第一个**满足「未满 3 张」且「本行为空或本行品质 == q」的行 → 追加该 id；
  4. 找不到可用行 → 不处理；`self._results = nil` 后重绘。
- **点击输入框 `clickSlot(row, j)`**：移除该 id 并使该行左移补位；`self._results = nil` 后重绘。
- **点击「合成」`clickSynthesize()`**：若没有任何一行满 3 张 → 不处理；否则 `sound.vcm` + `sync.send("xlik_cardsynth_do", { PlayerLocal():index(), self._pending })`。
- 收到 `open/refresh(data)`：用 `data.cards` 重绘左区、用 `data.results` 重绘结果框；若 `data.results` 非空则清空 `self._pending`（本次投入已被消耗）。

## 七、决策与假设

| 项 | 决定 |
|---|---|
| 合成范围 | 一次点击处理所有已填满 3 张的行（最多 5 次），未填满行跳过 |
| 投料约束 | 同一行 3 张必须同品质（客户端添加时即按此过滤；服务端再校验） |
| 产出品质 | 按「投入品质 → 产出品质」权重表（`synthRate`）随机，不降档，品质越高升档越难 |
| 产出卡片 | 在产出品质的卡片集合内均匀随机（可等于投入卡） |
| 品质分级 | 按羁绊配方出场次数降序、同次数按 id 升序，排名均分 5 档（出现越多越普通） |
| 存储 | 复用 `图鉴卡牌`（扣 3 涨 1），不新增存档组 |
| 左区显示 | 仅拥有(数量>0)的卡片；显示的数量 = 拥有数 − 已选数 |
| 结果展示 | 服务端回传 `results`，结果框显示图标；再次编辑即清除 |
| 入口 | 图鉴面板「卡片合成」按钮跳转（非功能栏、非页签） |
| 图标/资源 | 占位 `X_UI_QUESTION` + `通用边框.tga`，不新增资源 |
