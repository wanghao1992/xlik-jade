# 通行证系统迁移（老图 死灵狂潮 → xlik-jade demo）

## 一、目标与范围

把老图 [内容/通行证](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E9%80%9A%E8%A1%8C%E8%AF%81) 整套搬进 demo：

- **S1 赛季**（老图 [数据.lua:4](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E9%80%9A%E8%A1%8C%E8%AF%81/%E6%95%B0%E6%8D%AE.lua#L4) `通行证开放赛季 = 1`，故数据只生成 S1；S2~S8 在老图数据里本就没建）。
- **30 级 × 2 轨奖励**（普通版 / 进阶版），每档 `desc`（说明）+ 属性加成照搬（[数据.lua:102-1324](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E9%80%9A%E8%A1%8C%E8%AF%81/%E6%95%B0%E6%8D%AE.lua#L102-L1324)）。
- **6 个每日任务**：击杀小怪 1000 / 击杀变异怪 50 / 重铸专属 1 / 通关任意难度 1 / 洗练专属词条 20 / 洗练唯一被动 5。
- **经验与等级**：每次任务完成 = 100 经验，每级 200 经验，30 级封顶（[数据.lua:13-19](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E9%80%9A%E8%A1%8C%E8%AF%81/%E6%95%B0%E6%8D%AE.lua#L13-L19)、[注册.lua:119-147](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E9%80%9A%E8%A1%8C%E8%AF%81/%E6%B3%A8%E5%86%8C.lua#L119-L147)）。
- **持久化**：照搬老图存档键——任务进度 `TXZRW11`、任务完成次数 `TXZ1WCCS1`（数值组，位宽 4，槽位 = 任务序号）；等级由"完成次数"现算，不单独落盘。
- **面板**（新套件 `xlik_txz`）：等级 + 经验条 + 奖励网格（6 级/页 × 5 页，每级上普通/下进阶）+ 每日任务列表 + 关闭。
- **入口**：功能栏「通行证(F5)」（当前是 `print` 占位）。

## 三、改造方案

### 3.1 存档：[存档.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/%E5%AD%98%E6%A1%A3.lua#L122-L128) 新增通行证数值组

紧随 `FIELD['衣柜']` 之后追加：

```lua
--- 通行证组(照搬老图 内容/通行证/数据.lua:1329-1355 登记的存档类型数据, 非 11 平台口径)
---   '通行证1任务进度'   key 'TXZRW11'    数值 位宽4 -> 每 key 15 槽, 槽位 = 任务序号 1..6
---   '通行证1任务完成次数' key 'TXZ1WCCS1'  数值 位宽4 -> 槽位 = 任务序号 1..6(累计不重置, 用于换算经验/等级)
--- S2+ 未开放(老图 通行证开放赛季=1) -> 只登记 S1 两组
FIELD['通行证1任务进度'] = { type = 'num', keys = { 'TXZRW11' }, wk = 4 }
FIELD['通行证1任务完成次数'] = { type = 'num', keys = { 'TXZ1WCCS1' }, wk = 4 }
```

约束：任务序号 1..6 落在单条 key 的 15 个槽内，不会跨 key；`wk = 4` 单槽上限 90^4-1，足够放下累计完成次数。

单值键（不新增 FIELD，直接走 `saveArchive.valueNum/setValue`）：

| key | 用途 |
|---|---|
| `TXZDATE` | 最近一次"每日重置"的北京时间自然日 `YYYYMMDD`（照 签到 的 `QDDATE` 口径） |
