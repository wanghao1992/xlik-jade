# 新天赋「剑阵」实现计划

## 一、需求与结论

在现有天赋三选一面板中新增一条 **5 级机制卡链「剑阵」**（sword1 ~ sword5），与其他机制卡（剑气/法球/天雷/天降斩）结构一致。

- **触发**：普攻命中时，若内置冷却就绪，必定在英雄身前开阵（不赌概率）。
- **开阵表现**：英雄前方先出现 1 把剑，绕着剑阵中心快速旋转并"分裂"，在约 0.6 秒内补满一圈，形成**纵向（面向英雄前方）的圆形剑阵**。
- **输出阶段**：成阵后持续从阵中高速射出小剑，**持续时间随卡片等级提升（5 秒 → 8 秒）**；每把小剑沿英雄前方飞行，走**蛇形轨迹**，对路径上敌人造成物理伤害（每把剑对同一敌人只结算一次）。
- **结束**：持续时间结束后停止出剑，已飞出的小剑自然飞完；剑阵与全部小剑特效销毁。
- **数值口径**：单把小剑伤害 = 本次触发普攻伤害 × 单剑倍率，物理伤害；走 `talentMechanicDamage`，带 `_slkcMechanic` / `_extraDamage` 防止二次机制连锁。

## 三、卡片与数值设计（5 级链）

| 卡片 | key | 名称 | 冷却 | 持续 | 单剑倍率 | 射程 | 出剑间隔 | 剑阵半径 | 蛇形摆幅 | 命中半径 |
|---|---|---|---|---|---|---|---|---|---|---|
| I | sword1 | 剑阵·启阵 | 30s | 5s | 6% | 900 | 0.15s | 180 | 80 | 90 |
| II | sword2 | 剑阵·分流 | 28s | 6s | 7% | 1000 | 0.14s | 190 | 90 | 95 |
| III | sword3 | 剑阵·游龙 | 26s | 6.5s | 7% | 1100 | 0.13s | 200 | 100 | 100 |
| IV | sword4 | 剑阵·万刃 | 24s | 7s | 7.5% | 1200 | 0.12s | 210 | 110 | 105 |
| V | sword5 | 剑阵·天罗 | 22s | 8s | 8% | 1300 | 0.11s | 220 | 120 | 110 |

- 持续 **随等级从 5 秒提升到 8 秒**（用户要求最多 8 秒）。
- 出剑速度固定 1500，蛇形波长固定 260，成阵固定 0.6 秒。
- 单目标极限（全部剑命中同一人）：
  - I：5 / 0.15 ≈ 33 把 × 6% ≈ 198% 攻击伤害 / 30 秒；
  - III：6.5 / 0.13 = 50 把 × 7% = 350% 攻击伤害 / 26 秒；
  - V：8 / 0.11 ≈ 72 把 × 8% ≈ 576% 攻击伤害 / 22 秒，与「天降斩 V」（3×190% / 25 秒）同量级。
- 群体收益更高，但每把剑对同一敌人只结算一次，避免单帧重复伤害。

#### 1.4 新增「剑阵系统」（插入位置：`startLeapSlash` 结束之后、`-- ==== 天雷·雷劫化身系统` 之前，当前 [L1965-L1967](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/天赋.lua#L1965-L1967)）

实现要点：

```lua
--- ==== 剑阵系统 ====
local SWORD_MODEL = "魔剑.mdx"        -- model_wardrobe.lua 已注册别名(+X 为剑身方向)
local SWORD_TICK = 0.03               -- 统一刷新周期
local SWORD_FORM_TIME = 0.6           -- 成阵耗时
local SWORD_RING_COUNT = 16           -- 剑阵剑数(视觉)
local SWORD_RING_OFFSET = 180         -- 阵心在英雄前方的距离
local SWORD_RING_SPIN = 24            -- 成阵后整圈缓慢旋转(度/秒)
local SWORD_RING_SCALE = 0.9          -- 阵中剑缩放
local SWORD_SCALE = 0.45              -- 飞出小剑缩放
local SWORD_SPEED = 1500              -- 小剑飞行速度
local SWORD_WAVELENGTH = 260          -- 蛇形波长
local SWORD_DURATION_DEFAULT = 5      -- 持续出剑时长兜底(实际读 剑阵持续)
```

**状态结构**挂 `hero._talentSwordArrayState`，同一时间只允许一套剑阵：

```lua
state = {
    ring = {},          -- { effect=agileEffect, angle=数字 }
    swords = {},        -- { effect, ox, oy, z0, facing, phase, dist, hit={} }
    formElapsed = 0,    -- 成阵进度
    liveElapsed = 0,    -- 成阵后的持续时间(用于与 duration 比较)
    spawnAcc = 0,       -- 出剑累计器
    formed = false,
    ringPhase = 0,      -- 圈整体旋转相位
    params = {          -- 触发时快照 _attr 参数(含 duration)
        duration = ..., -- = _attr['剑阵持续'] (5~8 秒)
        ...
    },
    timer = Timer,
}
```

**向量/阵心计算**（每 tick 重算，剑阵始终跟随英雄身前）：

- 前向 `f = facing`；右向 `r = facing + 90`；
- 阵心 `cx, cy = vector2.polar(hero:x(), hero:y(), SWORD_RING_OFFSET, facing)`；
- 阵心高度 `cz = hero:z() + ringRadius + 40`（保证圆环最低点离地约 40）；
- 圆环上角度 `a` 的点：
  - `x = cx + math.cos(math.rad(a)) * radius * math.cos(math.rad(facing + 90))`
  - `y = cy + math.cos(math.rad(a)) * radius * math.sin(math.rad(facing + 90))`
  - `z = cz + math.sin(math.rad(a)) * radius`
- 所有阵中剑 `rotateZ = facing`（剑身指向英雄前方），形成"竖直的剑门"。

**成阵动画**：

1. 创建 16 把隐藏的阵剑 + 1 把「引导剑」；
2. `p = formElapsed / FORM_TIME`，引导剑沿 `a = 360 * p`、半径 `radius * p` 运动；
3. 每完成 `1/16` 进度，就在对应角度显示一把阵剑（"一把剑绕圈分裂成一圈"）；
4. `p >= 1` 后销毁引导剑，`formed = true`，进入输出阶段。

**输出阶段（每 tick）**：

- `ringPhase += SWORD_RING_SPIN * TICK`，16 把阵剑沿圆环缓慢转动（仍朝前方），保持法阵"活着"；
- `spawnAcc += TICK`，每达到「剑阵间隔」从随机环上角度生成 1 把小剑：
  - 初始坐标取环上该点，`facing + math.rand(-8, 8)` 作为小剑飞行方向；
  - `phase = math.rand(0, 359)` 作为蛇形初相；
  - 缩放 `SWORD_SCALE`，朝向 `facing`；
- 小剑推进：

```lua
s.dist = s.dist + SWORD_SPEED * SWORD_TICK
local wave = s.amp * math.sin(math.rad(s.dist / SWORD_WAVELENGTH * 360 + s.phase))
local x = s.ox + math.cos(math.rad(s.facing)) * s.dist
                + math.cos(math.rad(s.facing + 90)) * wave
local y = s.oy + math.sin(math.rad(s.facing)) * s.dist
                + math.sin(math.rad(s.facing + 90)) * wave
local z = s.z0 + (hero:z() + 40 - s.z0) * math.min(1, s.dist / (s.range * 0.35))
```

  - `rotateZ` 取路径切线角：`facing + math.deg(math.atan(导数))`，让小剑头始终顺着蛇形轨迹；
  - `dist >= range` 时销毁该小剑。

**伤害判定（性能关键：每 tick 只查一次敌群）**：

- 每 tick 用 `enemiesAround(hero + f * (range/2), range/2 + 240, owner, nil)` 取一次大圆范围敌人；
- 再遍历所有存活小剑，按 2D 距离 `< hitRadius` 判定；
- 每把小剑维护 `s.hit[handle]`，同一把剑对同一敌人只结算一次；
- 命中时先挂 `[[Abilities\Spells\Other\Cleave\CleaveDamageTarget.mdl]]` 受击特效，再 `talentMechanicDamage(hero, u, base * ratio, injury.damageType.physics)`。

**结束与清理**：

- `liveElapsed` 达到 `params.duration`（由 `_attr['剑阵持续']` 快照，5~8 秒）后停止出剑；
- 所有小剑飞完（`#swords == 0`）后销毁 16 把阵剑与计时器，清空 `hero._talentSwordArrayState`；
- 英雄死亡/销毁、或中断时立即 `stopSwordArray`，销毁全部灵动特效与计时器；
- `stopSwordArray(state)` 不依赖 hero 字段，避免英雄已销毁时读取报错。

## 五、假设与决策

1. **5 级链**：按用户选择，新增 sword1~sword5，`levelMax = 1`，逐级依赖，与现有机制卡完全一致。
2. **普攻命中触发**：按用户选择，`unitAttack` 事件触发；冷却锁字段 `_talentSwordLock`，命名与 `_talentQiLock` / `_talentLeapLock` 一致。
3. **阵型"纵向"**：圆环位于垂直于英雄前向的竖直平面（右向 × 上向张成），所以从英雄视角看是竖立的一圈剑。
4. **剑阵跟随英雄**：每 tick 重新按英雄位置与朝向计算阵心，保证始终在"英雄前方"；英雄转向时剑阵随之转向。
5. **一把剑分裂**：先用「引导剑」绕圈运动，按 1/16 进度逐把落下阵剑，满足"绕中心快速分裂成圆形剑阵"的表现。
6. **持续随等级提升**：5 → 6 → 6.5 → 7 → 8 秒（用户要求最多 8 秒）；升级同时提升单剑伤害、冷却、射程、出剑频率、剑阵半径与摆幅。
7. **性能**：全部小剑共用一个 0.03 秒计时器；每 tick 只做一次大圆取敌，再在内存里做逐剑距离判定，避免每把剑各自 `Group` 枚举。
8. **伤害防连锁**：统一走 `talentMechanicDamage`，自带 `_slkcMechanic` / `_extraDamage`，不会触发分裂/剑气/闪电链/专属装备等二次机制。
9. **每剑限一次**：每把小剑对同一敌人只结算一次，避免贴脸时单帧多段爆炸。
10. **其它系统**：不新增独立文件，全部内聚在 `天赋.lua`，与法球/剑气/天雷的组织方式一致。
