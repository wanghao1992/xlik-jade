# 「已获取」技能与面板实施方案

## 一、目标

1. 在英雄技能栏原「范围拾取」的位置（视觉槽位 10，热键 **C**）新增主动技能「已获取」。
2. 发动该技能时显示/隐藏新 UI 套件「已获取」：左侧分类（天赋 / 宝物 / 商品），右侧区域顶部带子分类「已获取 / 全部」，下方网格展示内容（图标 + 名称 + 鼠标悬停提示；「全部」中未获得的条目压暗蒙版）。
3. 移除功能栏（`xlik_funcbar`）中的「宝物」按钮，其余功能按钮布局自动收拢。
4. 数据范围（每个分类都同时提供「已获取」与「全部」两份数据）：
   - 天赋：「已获取」= `talent_<key>` 等级 > 0；「全部」= 全部天赋（未学习的压暗），悬停显示说明与等级。
   - 宝物：「已获取」= 英雄 `treasure_list` 中已拥有的宝物；「全部」= `treasure.names()` 全集（未拥有压暗），悬停显示宝物 tips。
   - 商品：「已获取」= `商店_已购_<key>` > 0 的商品；「全部」= 战功商店 21 件商品全集（未购买压暗），悬停显示品质、说明与已购次数。


### 2. 新增技能「已获取」

**新文件**：`projects/demo/scripts/globals/tpl/ability/已获取.lua`

```lua
--- 已获取: 发动时显示/隐藏「已获取」面板(仅本人可见)
local KIT = "xlik_acquired"

TPL_ABILITY.ACQUIRED = AbilityTpl()
    :name("已获取")
    :description({ [[发动后查看天赋、宝物与商品（已获取/全部）]] })
    :targetType(ability.targetType.none)
    :icon([[ReplaceableTextures\CommandButtons\BTNBookOfSummoning.blp]])
    :levelMax(1)
    :coolDownAdv(0.5, 0)

TPL_ABILITY.ACQUIRED:onEvent(eventKind.abilityEffective, function(abData)
    local player = abData.triggerPlayer
    if (false == class.isObject(player, PlayerClass)) then return end
    local data = buildData(player)   -- 服务端组装三分类纯数据
    async.call(player, function()
        if (type(isUIKit) ~= "function" or false == isUIKit(KIT)) then return end
        local ui = UIKit(KIT)
        if (ui:isOpen()) then
            ui:close()
        else
            ui:open(data)
        end
    end)
end)
```

`buildData(player)`（服务端组装三分类 × 两个子分类的纯数据）：

- 天赋：`talentFlow.items(player, false)` 为「已获取」，`talentFlow.items(player, true)` 为「全部」。
- 宝物：
  - 「已获取」：遍历 `hero.treasure_list[1.. treasure.AMBER_VOLUME]`，输出
    `{ name = tre.name, icon = tre.art or X_UI_QUESTION, title = tre.name, tips = { tre:tips(hero) } }`。
  - 「全部」：遍历 `treasure.names()`（已排序全集），用 `treasure.new(name)` 生成临时实例读取 `art` 并 `pcall(ins.tips, ins, hero)` 取提示；未拥有的条目补 `state = "未达成"`。
- 商品：`meritShopFlow.items(player, false)` / `meritShopFlow.items(player, true)`。
- 英雄/宝物栏不存在时对应分类 items 为空表；每个分类都固定输出 `已获取`、`全部` 两个 sub。

### 3. 导出天赋列表（已获取 / 全部）

**文件**：`projects/demo/scripts/globals/tpl/ability/天赋.lua`

在 `talentLevel` 定义之后新增全局接口：

```lua
talentFlow = talentFlow or {}

--- 天赋列表(供 xlik_acquired 面板展示)
---@param player Player
---@param includeAll boolean 是否包含未学习的天赋
---@return table[]
function talentFlow.items(player, includeAll)
    local out = {}
    for _, d in ipairs(TALENT_DEFS) do
        local lv = talentLevel(player, d.key)
        if (includeAll or lv > 0) then
            out[#out + 1] = {
                key = d.key,
                name = d.name,
                icon = d.icon,
                title = d.name,
                tips = { d.desc, ("等级 %d/%d"):format(lv, d.levelMax) },
                progress = ("Lv%d"):format(lv),
                state = (lv > 0) and nil or "未达成",
            }
        end
    end
    return out
end
```

### 4. 导出商品列表（已获取 / 全部）

**文件**：`projects/demo/scripts/process/战功商店.lua`

在 `ownedOf` / `GOODS_MAP` 之后新增：

```lua
--- 战功商品列表(供 xlik_acquired 面板展示)
---@param player Player
---@param includeAll boolean 是否包含未购买的商品
---@return table[]
function meritShopFlow.items(player, includeAll)
    local out = {}
    for _, g in ipairs(GOODS) do
        local owned = ownedOf(player, g.key)
        if (includeAll or owned > 0) then
            local desc = g.desc
            if (type(desc) == "function") then desc = desc(owned, player) end
            if (type(desc) == "table") then desc = table.concat(desc, "\n") end
            out[#out + 1] = {
                key = g.key,
                name = g.name,
                icon = g.icon,
                title = g.name,
                tips = {
                    colour.hex(QUALITY_COLOR[g.quality], "品质: " .. QUALITY_NAME[g.quality]),
                    desc or '',
                    ("已购买 %d/%d 次"):format(owned, g.limit),
                },
                progress = ("×%d"):format(owned),
                state = (owned > 0) and nil or "未达成",
            }
        end
    end
    return out
end
```

## 四、假设与决策

1. 「在原范围拾取技能位置加新技能」按**视觉槽位 10 / 热键 C** 实现；原 `范围拾取.lua` 模板保持不改（当前无任何挂载引用，属未使用模板），避免影响其他注释/测试文档。
2. 右侧子分类固定为「已获取 / 全部」，默认选中「已获取」；切换主分类时子分类自动回到「已获取」。
3. 「全部」中未获得的条目压暗蒙版（沿用存档面板的 `state = "未达成"` 机制），悬停仍展示说明；已获取条目无蒙版。
4. 已获取商品按 key 去重展示，右下角显示累计购买次数；Buff 类商品只展示获得过，不区分是否过期。
5. 宝物「已获取」按槽位顺序，「全部」按 `treasure.names()` 名称顺序；宝物栏（N 键）保留，仅移除功能栏入口按钮。
6. 已获取面板为只读展示，不提供任何购买/学习/卸下操作。
7. 图标沿用魔兽原生资源 `BTNBookOfSummoning.blp`，不新增美术资源。
