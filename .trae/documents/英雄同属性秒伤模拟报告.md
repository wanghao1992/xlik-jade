# 英雄同属性木桩秒伤模拟报告

> 目的：在**完全相同的基础属性**下，比较 45 个英雄对单体木桩 60 秒的总伤害与秒伤，定位战力/秒伤差距的来源，并给出可落地的数值调整建议。
>
> **当前版本：第三轮 P1 之后（P0 数值 bug + P1 机制上限 + P2 底部补强）**。第一轮、第二轮与第三轮的诊断结论保留在“四、差距归因”里作为对照。
>
> 模拟器：`tools/hero_dps_sim/sim.py`（可重跑、参数可调）
> 输出明细：`tools/hero_dps_sim/results_1000_fixed.csv`、`results_0_fixed.csv`（第三轮 P1 后）；`results_1000.csv`、`results_0.csv`（第一轮前）

剩余低于 1600 的 14 个英雄集中在 1253~1486，与上一轮相同，属于下一轮可选的底部微调；当前分布已从「7 倍断层」收敛到「2.2 倍」。

## 二、模拟口径

| 参数 | 取值 |
| --- | --- |
| 英雄等级 | 30 |
| 力量 / 敏捷 / 智力 | 100 / 100 / 100 |
| 基础攻击力 | 300 |
| 攻击间隔基准 | 1.0 秒，最终攻速 2.0 次/秒（攻速 +100） |
| 暴击 | 25%，暴伤 150%（期望乘区 1.375） |
| 生命上限 | 8000 |
| 三维精通 | 敏捷 100 → 物理 ×1.01；智力 100 → 法术 ×1.01 |
| 目标 | 单体木桩，0 护甲，不还手，无小怪，无控制 |
| 时长 | 60 秒 |
| 技能策略 | 卡 CD 释放、蓝量充足、AoE 对单体只计 1 次 |
| 击杀叠层 | 两组：0 击杀 / 1000 击杀 |

**叠层口径（`--stack-mode`）**：

- `intended`（**默认，即当前代码行为**）：上限 = 主属性（已剔除本叠层自身加成） × (capA + 等级 × capB)，1000 击杀时主属性最多 +210；
- `bug`：保留旧行为（`capAttr` 读到被叠层加成后的属性，上限自引用、永不封顶），仅用于对照。

## 四、差距归因

### 已修复（第一轮）

#### 1. 邪剑圣·致命一击：倍率单位用错 → 4463.2 降到 2021.2

[致命一击.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/邪剑圣/致命一击.lua#L29-L33)

原实现把「暴击倍率 20 + 等级×0.1」（本项目的百分点语义，23 表示 1.23 倍）直接当成「23 倍」使用，单次触发追加 6600 物理伤害，是普攻的 22 倍。

修复：倍率改为 `7 + 等级 × 0.04`（L30 = 8.2 倍），并改走统一函数 `job.critDamage`。

#### 2. 击杀叠层 `capAttr` 自引用 → 5 个英雄回落 46%~55%

[职业工具.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/职业工具.lua#L633-L643)

原实现 `cap = capAttr(hero) * (...)` 读取的是**已被叠层 Buff 加成过**的属性，上限随当前值一起上涨，形成自引用，1000 击杀时主属性堆到 1100 且永不封顶。

修复：计算上限时先剔除本叠层自身加成（`attr == capAttr` 时减 `hero[store]`），上限随英雄自然成长更新，同时不再自引用。

| 英雄 | 叠层属性 | 修复前 | 修复后 | 变化 |
| --- | --- | ---: | ---: | ---: |
| 光明游侠（圣光） | 敏捷 +210 | 4799.3 | 2173.1 | -54.7% |
| 痛苦女王（磨难） | 智力 +210 | 4506.9 | 2020.6 | -55.2% |
| 大魔导师（博学） | 智力 +210 | 4068.8 | 1895.8 | -53.4% |
| 炎魔之王（炽热） | 力量 +210 | 3174.7 | 1645.9 | -48.2% |
| 血魔法师（焚烧） | 智力 +210 | 2966.6 | 1588.0 | -46.5% |

另外 5 个叠层（灭世/时空/腐肉堆积/亡者/潮汐）参照属性与被加成属性不同，本来就没有自引用，不受影响；影魔的支配死灵是独立实现且按敏捷封顶攻击，也不受影响。

#### 3. 炼金术士·化学狂暴：攻速双重生效 → 4218.0 降到 1725.7

[化学狂暴.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/炼金术士/化学狂暴.lua#L42-L55)

原来 `attackSpeed += 150` **和** `attackSpace -= 0.2` 同时生效。攻击间隔公式是 `clamp(base / (1 + 攻速/100), 0.1, 5)`，两者叠加后直接撞到 0.1 秒的引擎下限，平均 7.45 次/秒。

修复：删除 `attackSpace` 改动，只保留 `+150 攻速`，平均 3.02 次/秒（15 秒持续 / 22 秒冷却）。

#### 4. 卓尔游侠·冰冻冷箭：系数随敏捷线性放大 → 4384.7 降到 2534.9

[冰冻冷箭.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/卓尔游侠/冰冻冷箭.lua#L16-L22)

系数 `0.5 + 0.12 × 等级` 在 L30 是 4.1，配合敏捷 277.5，每击附加 1238 法术伤害，是普攻的 3 倍。

修复：系数改为 `0.5 + 0.04 × 等级`（L30 = 1.7），每击 572。

#### 5. 暴击口径统一（结构性）

[职业工具.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/职业工具.lua#L183-L203) 新增 `job.critDamage(hero, target, base, mul, skinId)`，明确 `mul` 是**总倍率**（1.0 = 不暴击）。邪剑圣、幻影刺客、混沌骑士三处「追加伤害模拟暴击」的实现全部改走它，并顺带消除了重复的 8% 皮肤伤害代码。

#### 1. 神灵武士：残血收益不再无上限，DoT 真正生效

[狂战士之血.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/神灵武士/狂战士之血.lua) 原来 15% 血时损失 85% → +255 攻速（4.55 次/秒）、+595 攻击，没有上限；现在 `min(lost*3, 100)` / `min(力量系数*lost, 150)`，15% 血时固定 +100 攻速（3.0 次/秒）、+150 攻击。

[沸血之矛.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/神灵武士/沸血之矛.lua) 的 DoT 计时器原来挂在 Buff 里，每次普攻 `BuffClear` → `rollback` 销毁计时器 → 重新建一个 1/3 秒计时器；攻速 ≥ 3 次/秒时计时器永远跳不出来。现在计时器由 `ensureBurnTimer` 独立管理，`BuffClear` 只刷新层数与持续时间，不再重置计时；Buff 自然到期后计时器在下一拍发现层数为空自停。

修复后 DoT 占比从 1.4% 提升到 **21.3%**（597 秒伤），英雄总秒伤仍有 2799.3，落在木桩特例允许的 2600~3000。

#### 4. 叠层统一：一套上限预设 + 可见上限

[职业工具.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/职业工具.lua) 新增 `job.killStackPresets`：

| 预设 | 适用 | 上限公式（L30 / 参照属性 100） |
| --- | --- | --- |

| `hp` | 亡者/腐肉堆积 | 力量 × (20 + 等级×0.5) = 3500 |

`job.killStackCap` 统一计算上限（剔除本叠层自身加成），`job.killStackTips` 让技能描述在悬停时追加「当前已增加: X / 上限: N」。11 个叠层文件全部改走同一套结构，影魔支配死灵也删掉了独立实现。唯一数值变化是灭世上限 360 → 300。

## 六、敏感性说明

1. **0 击杀 vs 1000 击杀**：叠层修复后，叠层英雄的波动已经很有限（圣光 1486.6 → 2173.1，约 1.46 倍）。如果实际对局平均击杀在 300~500，建议改用 `--kills 400` 再看一版。第二轮的斧王依赖越战越勇（0 击杀 959.9 / 1000 击杀 1376.5），血魔法师依赖焚烧叠层（1256.0 / 1629.8），对击杀环境更敏感。
2. **`bug` 对照模式已不代表代码**：`--stack-mode bug` 仅用于复现修复前的数值，默认 `intended` 与当前代码一致。
3. **神灵武士 2799.3 仍是木桩特例**：该数值依赖「木桩不还手 + 自损压血」，但已加上硬上限，并把沸血之矛 DoT 修为独立计时器（占比 21.3%）；实战应在 2200~2800 量级，建议单列一条「木桩特例」而不参与平衡排名。
4. **暴击乘区**：所有主动/被动伤害都走统一暴击（1.375x），因此暴击属性对技能型英雄的收益和普攻型一致；若后续调整暴击期望，差距会等比放大。
5. **未计入**：蓝耗、技能前后摇、走位、控制、AoE 多目标、护甲（木桩 0 甲）。真实对局里，AoE 型英雄（月骑、大法师、风暴之灵）会更占优，纯单体英雄（邪剑圣、幻影刺客）会更吃亏。

## 七、复现方式

```powershell
cd tools/hero_dps_sim

# 第三轮 P1 口径，1000 击杀（默认 stack-mode=intended，与当前代码一致）
python sim.py --kills 1000 --csv results_1000_fixed.csv

# 无叠层基准
python sim.py --kills 0 --csv results_0_fixed.csv

# 对照修复前的叠层 bug（自引用、不封顶）
python sim.py --kills 1000 --stack-mode bug --csv results_1000_bug.csv

# 可调面板
python sim.py --attack 500 --aps 2.5 --crit 0.35 --crit-dmg 2.0 --hp 12000 --kills 400
```

`sim.py` 里的每个英雄都对应一段可读的建模代码（`build_heroes`），改动技能公式后可直接修改对应条目重新跑，不需要进游戏。
