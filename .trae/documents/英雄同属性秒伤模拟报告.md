# 英雄同属性木桩秒伤模拟报告

> 目的：在**完全相同的基础属性**下，比较 45 个英雄对单体木桩 60 秒的总伤害与秒伤，定位战力/秒伤差距的来源，并给出可落地的数值调整建议。
>
> 模拟器：`tools/hero_dps_sim/sim.py`（可重跑、参数可调）
> 输出明细：`tools/hero_dps_sim/results_0.csv`、`results_1000.csv`、`results_1000_intended.csv`

---

## 一、结论摘要

| 指标 | 数值 |
| --- | --- |
| 最高秒伤 | 神灵武士 5928.8 |
| 最低秒伤 | 斧王 833.2 |
| **极差** | **7.12 倍** |
| 中位秒伤（0 击杀） | 1638.7 |
| 中位秒伤（1000 击杀） | 1967.6 |
| 落在 1600~2600 目标区间的英雄 | 19 / 45（42%） |

差距不是「属性给错了」，而是集中在 **6 个可定位的机制/实现问题**上：

1. **邪剑圣·致命一击**倍率单位用错（23 倍 → 应为约 8 倍量级）——单技能撑起 81% 伤害；
2. **击杀叠层 `capAttr` 自引用**，主属性叠层永不封顶（血法/光明/痛苦/大魔导师/炎魔）；
3. **炼金术士·化学狂暴**攻速与攻击间隔双重生效，攻速顶到引擎上限；
4. **卓尔游侠·敏捷光环**自增益 + 冰冻冷箭随敏捷线性放大，双重滚雪球；
5. **神灵武士**在木桩场景可长期停在 15% 血，狂战士之血/活血术收益被无限放大（实战不成立）；
6. **底部 4 个英雄（斧王/幻影刺客/兽王/圣骑士）**的伤害被动在单体木桩下几乎不生效。

## 二、模拟口径

所有英雄使用**同一套面板**，不读实际装备/成长：

| 参数 | 取值 |
| --- | --- |
| 英雄等级 | 30 |
| 力量 / 敏捷 / 智力 | 100 / 100 / 100 |
| 基础攻击力 | 300 |
| 攻击间隔基准 | 1.0 秒，最终攻速 2.0 次/秒（攻速 +100） |
| 暴击 | 25%，暴伤 150%（期望乘区 1.375） |
| 生命上限 | 8000 |
| 三维精通 | 敏捷 100 → 物理 ×1.01；智力 100 → 法术 ×1.01 |
| 目标 | 单体木桩，0 护甲，不还手，无小怪，无控制 |
| 时长 | 60 秒 |
| 技能策略 | 卡 CD 释放、蓝量充足、AoE 对单体只计 1 次 |
| 击杀叠层 | 两组：0 击杀 / 1000 击杀 |

**叠层对照**（`--stack-mode`）：

- `bug`（默认，还原当前代码行为）：主属性叠层读取的是**已被加成后的属性**作为上限，因此 1000 击杀 = +1000 主属性，永不封顶；
- `intended`（假设修复上限）：1000 击杀按设计封顶，主属性最多 +210。

## 四、差距归因（按影响量级排序）

### 1. 邪剑圣·致命一击：倍率单位用错（+3630 秒伤，占比 81%）

[致命一击.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/邪剑圣/致命一击.lua#L28-L32)

```lua
local mul = 20 + lv * 0.1          -- L30 → 23
local crit = base * (mul - 1)      -- 追加 22 倍本次普攻伤害
```

注释写明「原实现走暴击系统（倍率 20+等级*0.1）」。而本项目的暴击系统里，倍率是**百分点**语义（`1 + 暴伤*0.01`），23 表示 1.23 倍。这里直接当成「23 倍」用，实际放大了约 **100 倍**。

- 单次触发追加 6600 物理伤害（普攻才 300）；
- 20% × 2 次/秒 → 0.4 次/秒，期望 3630 秒伤；
- 邪剑圣三个技能里，分裂和镜像都不产单体伤害，所以这一个 bug 决定了整个英雄的强度。

### 2. 击杀叠层的 `capAttr` 自引用，主属性永不封顶（最高 +3440 秒伤）

[职业工具.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/setup/职业工具.lua#L603-L635)

```lua
local cap = capAttr(hero) * (capA + level * capB)
```

`capAttr` 是 `job.primary`，读的是**已经被叠层 Buff 加成过**的属性。于是上限随当前值一起上涨，形成自引用，永远追不上。1000 击杀时：

| 英雄 | 叠层属性 | 当前代码秒伤 | 修复上限后 |
| --- | --- | ---: | ---: |
| 光明游侠（圣光） | 敏捷 1100 | 4799.3 | 2173.1 |
| 痛苦女王（磨难） | 智力 1100 | 4506.9 | 2020.6 |
| 大魔导师（博学） | 智力 1100 | 4068.8 | 1895.8 |
| 炎魔之王（炽热） | 力量 1100 | 3174.7 | 1645.9 |
| 血魔法师（焚烧） | 智力 1100 | 2966.6 | 1588.0 |

同一组英雄在 0 击杀时分别只有 1486 / 1406 / 1357 / 1239 / 1242，**叠层一项就带来 2~3.2 倍差距**，这是「差不多发育但战力差很多」最主要的来源。

### 3. 炼金术士·化学狂暴：攻速双重生效（+3385 秒伤）

[化学狂暴.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/炼金术士/化学狂暴.lua)

同时做了两件互相叠加的事：`attackSpeed += 150` **和** `attackSpace -= 0.2`。

框架的攻击间隔公式是 `clamp(base / (1 + 攻速/100), 0.1, 5)`：

- 只算 +150 攻速 → `1/3.5 = 0.286s`，即 3.5 次/秒；
- 再减 0.2 → `0.086s`，被下限夹到 **0.1s = 10 次/秒**（引擎硬上限）；
- 平均下来 **7.45 次/秒**，是基准 2.0 的 3.7 倍。

普攻分项因此单独就有 3106 秒伤。

### 4. 卓尔游侠：光环自增益 + 法球随敏捷线性放大（+3550 秒伤）

[敏捷光环.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/卓尔游侠/敏捷光环.lua) / [冰冻冷箭.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/卓尔游侠/冰冻冷箭.lua)

- 光环对**自己**也生效：`flat(160) + 自身敏捷 × 17.5%`，且每 0.5 秒刷新一次（模拟按实际叠到的 277.5 敏捷计算；即使按理论值 177.5，秒伤仍有约 3100）；
- 冰冻冷箭每击 = `100 + 敏捷 × (0.5 + 等级×0.12)`，L30 系数是 **4.1**，敏捷 277.5 时单次附加 **1238** 法术伤害，是普攻（417）的 3 倍；
- 而敏捷本身又吃「每 100 敏捷 +1% 物理伤害」和「每 5 点主属性 +1 攻击」，三层乘数叠在一起。

### 5. 神灵武士：木桩可长期 15% 血（+5095 秒伤）

[狂战士之血.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/神灵武士/狂战士之血.lua) / [沸血之矛.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/神灵武士/沸血之矛.lua)

- 每损失 1% 生命 → +3% 攻速、+力量×(1%+0.2%×等级) 攻击。15% 血时损失 85% → **+255 攻速、+595 攻击**；
- 活血术再 +33% 当前攻击（快照）；
- 木桩不还手，英雄靠沸血之矛自损稳定压在 15% 血，收益被最大化；
- **附加发现**：沸血之矛的 DoT 计时器每次普攻都会被 `BuffClear` 重置，攻速 ≥ 3 次/秒时 DoT 基本不生效（模拟里持续伤害只占 1.4%）。这本身是个 bug，但也正是它让神灵武士不至于更离谱。

实战中这个英雄会被瞬间击杀，所以 5928.8 **不能当作真实强度**，但它说明「按损失生命给收益」的机制没有软上限。

### 6. 底部四英雄：伤害被动在单体木桩下失效

### 7. 主动技能断层

- **月骑·月光**：[月光.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/ability/职业/月骑/月光.lua#L34) `1000 + 敏捷 × (2.5 + 等级×1.5)` = 5750 / 6 秒 = **958 秒伤**，单体主动里最高一档；
- **死骑·死亡缠绕**：6400 / 10 秒 = 640 秒伤，且是「无风险单体爆发」，同档的剑圣/狮鹫只有 200~520；
- **风暴之灵·球状闪电**：950 / 1 秒 CD = 950 秒伤，几乎等同于一个常驻被动；
- **大法师**：水元素 3 只（816 秒伤）+ 暴风雪固定 1086 秒伤，两个「独立于面板」的固定伤害源，导致大法师在同属性下比别人多一整个人的输出。

## 五、调整建议

目标：把 45 个英雄收进 **1600 ~ 2600 秒伤**（约中位 2000 的 ±30%），并保留职业特色。

### P0 — 必修（bug 级，改完极差从 7.1x 降到约 3.8x）

| # | 位置 | 现状 | 建议 | 预期秒伤 |
| ---: | --- | --- | --- | --- |
| 1 | 邪剑圣·致命一击 | `crit = base * (mul - 1)`，mul = 23 | `mul = 7 + lv * 0.04`（L30 → 8.2），即追加约 7.2 倍 | 4463 → **约 1990** |
| 2 | 职业工具·killStack | `capAttr(hero)` 读加成后属性 | 用 `capAttr` 在**首次叠层前**的快照（或直接读基础属性）计算上限 | 光明 4799→2173，痛苦 4507→2021，大魔导师 4069→1896 |
| 3 | 炼金·化学狂暴 | `+150 攻速` 与 `-0.2 攻击间隔` 同时生效，撞 10 APS 上限 | 删除 `attackSpace -= 0.2`；冷却 30 → 22 秒补偿 | 4218 → **约 1950** |
| 4 | 卓尔·冰冻冷箭 | 系数 `0.5 + 0.12×等级` = 4.1 | 改为 `0.5 + 0.04×等级` = 1.7 | 4385 → **约 2540** |
| 5 | 卓尔·敏捷光环 | 对自己也生效，且每次刷新基于当前敏捷 | 明确「只对友军生效」或对自己只给固定值（不吃百分比） | 随上一条一并回落 |

> 只修这 5 项，前 7 名里有 6 名会回落到 1900~2600 区间，中位基本不变。

## 六、敏感性说明

1. **0 击杀 vs 1000 击杀**：叠层英雄的排名波动最大（光明 1486 → 4799）。如果实际对局平均击杀在 300~500，建议把模拟器改成 `--kills 400` 再看一版。
2. **`intended` 对照**：修复叠层上限后，最高秒伤从 5928 降到 5928（神灵不受影响），极差仍是 7.12x——说明**叠层 bug 不是唯一的差距来源**，P0 的 1/3/4/5 项必须一起改。
3. **神灵武士 5928.8 不可直接采信**：该数值依赖「木桩不还手 + 自损压血」，实战应在 2500~3000 量级。建议单列一条「木桩特例」而不参与平衡排名。
4. **暴击乘区**：所有主动/被动伤害都走统一暴击（1.375x），因此暴击属性对技能型英雄的收益和普攻型一致；若后续调整暴击期望，差距会等比放大。
5. **未计入**：蓝耗、技能前后摇、走位、控制、AoE 多目标、护甲（木桩 0 甲）。真实对局里，AoE 型英雄（月骑、大法师、风暴之灵）会更占优，纯单体英雄（邪剑圣、幻影刺客）会更吃亏。

## 七、复现方式

```powershell
cd tools/hero_dps_sim

# 当前代码行为，1000 击杀
python sim.py --kills 1000 --csv results_1000.csv

# 无叠层基准
python sim.py --kills 0 --csv results_0.csv

# 假设修复叠层上限
python sim.py --kills 1000 --stack-mode intended --csv results_1000_intended.csv

# 可调面板
python sim.py --attack 500 --aps 2.5 --crit 0.35 --crit-dmg 2.0 --hp 12000 --kills 500
```

`sim.py` 里的每个英雄都对应一段可读的建模代码（`build_heroes`），改动技能公式后可直接修改对应条目重新跑，不需要进游戏。
