# 战力系统迁移（老图 死灵狂潮 → xlik-jade demo）

## 一、目标与范围

把老图战力相关的三块搬进 demo：

1. **战力公式**：照搬老图 [core/types/unit.lua:1198-1201](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/core/types/unit.lua#L1198-L1201) 的 `unit:get_power()`，落到 `game.method.heroPower(hero)`。
2. **多面板战力列**：老图 [流程/刷怪/界面.lua:16-113](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E6%B5%81%E7%A8%8B/%E5%88%B7%E6%80%AA/%E7%95%8C%E9%9D%A2.lua#L16-L113) 的六列多面板（玩家/战力/杀敌/等级/英雄/金币）在本项目已由 `slkc_boss` 复刻，但战力列是占位 `return 0` → 本次接真实公式，并照搬老图的 `R2S_CN` 中文大数显示。
3. **落地战力**：照搬老图 [内容/杂项/落地战力.lua](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E6%9D%82%E9%A1%B9/%E8%90%BD%E5%9C%B0%E6%88%98%E5%8A%9B.lua) —— 建英雄 2 秒后取一次战力，按量级写入老图同名单值存档 key（供平台排行榜），并播报。

### 已确认的决策（用户拍板）

| 项 | 决定 |
|---|---|
| 迁移范围 | **公式 + 面板战力列 + 落地战力存档/播报**；不含排行榜面板 |
| 数值格式 | **照搬老图 `R2S_CN`**（万/亿/兆/京/垓…恒河沙），战力列与播报同款 |
| 存档键名 | **沿用老图同名 key**（`ldzl/ldzl2/ldzl4/ldzl5/ldzl6/ldzl7` + 单值 `LDZL`），老玩家数据与平台排行榜直接可沿用 |

### 明确不做

- **排行榜面板**（老图 [内容/排行榜/数据.lua:83-125](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E6%8E%92%E8%A1%8C%E6%A6%9C/%E6%95%B0%E6%8D%AE.lua#L83-L125) 拉 11 平台后台数据 + 界面）：本项目无排行榜系统，属另一套系统。
- 老图 `pla:is_cheating()` 的作弊分支（[落地战力.lua:7-8](file:///d:/Lua/%E6%AD%BB%E7%81%B5%E7%8B%82%E6%BD%AE/map/scripts/maps/%E5%86%85%E5%AE%B9/%E6%9D%82%E9%A1%B9/%E8%90%BD%E5%9C%B0%E6%88%98%E5%8A%9B.lua#L7-L8)）—— demo 无作弊检测。
- `内容/杂项/团队BOSS/数据.lua` 的 `lost.战力前10`（BOSS 取名池）、`混沌裂隙` 里"变相增加己方战力"的文案 —— 与战力系统无关，不迁移。
- `内容/杂项/显示游玩信息.lua`（老图内为空实现，单开一个函数体没写内容）—— 不迁移。

文件尾追加战力公式（[game.lua:439-469](file:///d:/Lua/xlik-jade/projects/demo/library/common/game.lua#L439-L469)）：

```lua
--- 英雄战力(照搬老图 unit:get_power)
---   攻击速度%   = attackSpeed/100   (老图分数; 本项目为百分比点)
---   全属性      = str + agi + int
---   攻击力/护甲/生命上限       = attack() / defend() / hp()
---   伤害加成%/物理伤害%/法术伤害% = _attr 的百分比点 / 100
---   护甲因子 0.04 照搬老图 config/attribute.lua:12
game.method.heroPower = function(hero)
    ...
    return (((as * 100 * 10 + all * 3 + atk) * (1 + dmg + phys * 0.4 + magic * 0.4))
        * (armor * hp / 15)) / 10000
end
```

要点：
- `class.isObject(hero, UnitClass)` 不成立时返回 0（面板对未选英雄的空行需要）。
- 全部取值走 `tonumber(...) or 0`，避免引擎返回 nil 时公式炸掉。
