# 洗练配置系统迁移（老图 死灵狂潮 → xlik-jade demo）

## 一、目标与范围

把老图 [内容/专属/洗练配置](file:///d:/Lua/死灵狂潮/map/scripts/maps/内容/专属/洗练配置) 整套搬进 demo，并让它真正生效（三块一起做）：

1. **配置面板**：每个专属部位（武器/防具/饰品/手套）配 4 个「期望词条」，落盘在平台 key `k5`~`k8`（老图口径，逗号分隔，空槽写 `nil`）。
2. **铁匠铺商品「智能洗练[专属X]」**：专属达到 100 级 + 200 万金币，每件仅一次，按配置把 4 条词条**重写为目标词条**（保留原品质与强化次数）。
3. **铁匠「洗练」的智能洗练开关**：开启后，手动洗练某条词条时会**自动连洗**（每 100ms 一次、照扣金币）直到该装备 4 条词条与配置的多重集一致；满足时提示「已经洗练到期望属性」。

### 3.4 专属装备：[专属装备.lua](file:///d:/Lua/xlik-jade/projects/demo/scripts/globals/tpl/item/专属装备.lua#L882-L910) 补 3 个只读接口

```lua
--- 该部位可洗词条名清单(等同老图 random_att_list; 供洗练配置面板展示)
---@param index number
---@return string[]
function exclusive.pool(index)
    local def = EQUIP_DEFS[index]
    return (nil == def) and {} or def.affixPool
end

--- 某段位词条名(无词条返回 nil)
---@param it Item
---@param pos number
---@return string|nil
function exclusive.affixName(it, pos)
    local affix = it._equipAffix and it._equipAffix[pos]
    return affix and affix.name or nil
end

--- 智能洗练需求(老图 铁匠铺/商品.lua:274-277)
exclusive.smartLevel = 100
exclusive.smartGold = 2000000

--- 智能洗练: 按配置重写 4 条词条(保留原品质与强化次数; 老图 铁匠铺/商品.lua:216-268)
--- 4 条词条须已全部解锁(专属 100 级时必然满足: 10/20/30/40 级各解锁 1 条)
---@param pla Player
---@param it Item
---@param names table 4 段目标词条名(须全部非空且在该部位 affixPool 内)
---@return boolean
function exclusive.smartRefine(pla, it, names)
    local def = it._equipDef
    if (nil == def or type(names) ~= 'table') then
        return false
    end
    for pos = 1, 4 do
        local name = names[pos]
        if (nil == name or nil == AFFIX_DEFS[name]) then
            alerter.message(pla, colour.hex(colour.indianred, "请先完成该专属的 4 条洗练配置"))
            return false
        end
    end
    ...
    --- 逐槽: 保留原 quality(色号)与 upgrade(强化次数), 数值取 AFFIX_DEFS[目标名].tier[quality][2]
    --- 完成后 it._equipSmart = true; equipRefresh; 播报 + slkc_exclusive_reroll 事件(计入通行证每日任务5)
    return true
end
```
