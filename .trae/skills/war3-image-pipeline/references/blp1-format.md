# BLP1 调色板格式要点

本项目所有 128×128 图标统一用「BLP1 + 调色板压缩」。这是魔兽原生的图标格式，兼容性最好；实测原生 128 图标同样使用该结构。

## 文件结构

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 4 | 魔数 `BLP1` |
| 4 | 4 | 压缩方式：`0`=JPEG，`1`=调色板（本项目用 1） |
| 8 | 4 | flags（写 0） |
| 12 | 4 | 宽 |
| 16 | 4 | 高 |
| 20 | 4 | pictureType（项目内 128 图标取 5） |
| 24 | 4 | pictureSubType（取 1） |
| 28 | 64 | 16 个 mip 的文件偏移（uint32×16） |
| 92 | 64 | 16 个 mip 的大小（uint32×16） |
| 156 | 1024 | 调色板 256 项，每项 **BGRA**（B,G,R,A 顺序） |
| 1180 | - | mip 数据，每级为 8 位调色板索引，按行自上而下 |

## 体积计算（128×128）

- mip 链 128/64/32/16/8：`16384+4096+1024+256+64 = 21824`
- 头 156 + 调色板 1024 → 单张 **23004 B**；同样尺寸的 32 位 TGA 是 `128×128×4+18 ≈ 65580 B`
- 24 位 TGA 仍有 49170 B，只省 25%，不划算

## 写入约定

- 调色板第 4 字节：原图全不透明时写 255（部分原生文件写 0，容易在别的解码器里变全透明）
- 索引数据行序自上而下（用原生 128 图标解码验证过；文字正立）
- mip 一律量化到同一张主调色板，不要每级各生成一张

## 生成脚本

`scripts/tga2blp.py` 已实现上述全部细节，并自带回读 + PSNR 校验。
