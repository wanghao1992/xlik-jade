# X-LIK 框架单位肖像显示问题

## 问题

`Unit(Player(1), TPL_UNIT.DEMO, 0, -100, 270)` 创建的单位选择后，右下角肖像（3D 模型预览）不显示。

## 根因

xlik 框架通过 SLK 物编自定义单位系统。`UnitTpl("Footman", "avatar")` 中的：

- 第一个参数 `"Footman"` = **语音名称**（speech），用于查找语音资源
- 第二个参数 `"avatar"` = **额外模组名称**（speechExtra），用于查找 SLK 条目变体

流程链路：

```
UnitTpl("Footman", "avatar")
  → japi.AssetsSpeech("Footman")  → 语音存在，返回 "Footman"
  → slk.n2i("Footman|EX|avatar")  → 查找 SLK 条目 "Footman|EX|avatar"
    └─ 如果找到 → 使用该 SLK 条目的模型创建单位 → 肖像正常
    └─ 如果没找到 → 回退到 "Footman|D"（默认条目，file=".mdl"虚拟模型）
      → J.CreateUnit 创建虚拟模型单位
      → :model("Footman") 通过 DZ_SetUnitModel 切换模型
      → DZ_SetUnitModel 不会更新肖像 ← 根因
```

**关键点**：`DZ_SetUnitModel` 只替换游戏内模型，不替换大头像中的模型（DZ API 明确说明）。

## 解决方案：方案A（推荐）

在 `assets/speech.lua` 中，为语音添加 `avatar` 额外模组并指定模型：

```lua
-- 步兵
assets_speech("Footman", {
    avatar = assets_speech_extra({ model = "Footman" }),
})
```

这样构建时会生成 SLK 条目 `Footman|EX|avatar`，其 `file` 字段为实际模型路径，`J.CreateUnit` 直接创建正确模型的单位，War3 原生处理肖像。

### 更多用法

可以为同一个语音定义多个额外模组，显示不同的肖像：

```lua
assets_speech("Footman", {
    avatar = assets_speech_extra({ model = "Footman" }),   -- 显示步兵肖像
    aaa    = assets_speech_extra({ model = "Rifleman" }),  -- 显示火枪手肖像
    bbb    = assets_speech_extra({ model = "Gyrocopter" }),-- 显示飞机肖像
})
```

```lua
UnitTpl("Footman", "avatar")  -- 步兵外观 + 步兵肖像
UnitTpl("Footman", "aaa")     -- 步兵外观 + 火枪手肖像
UnitTpl("Footman", "bbb")     -- 步兵外观 + 飞机肖像
```

### 原理

`assets_speech_extra({ model = "..." })` 中的 `model` 字段是一个**模型别名**，构建系统会将其解析为实际模型路径（如 `"Footman"` → `"units\\human\\Footman\\Footman.mdl"`），并写入 SLK 条目的 `file` 字段。

模型别名需要在 `assets/model_origin.lua` 等文件中通过 `assets_model(path, alias)` 提前注册。War3 原生模型的别名已在模板中预置。

### 适用范围

- 需要在 `assets/speech.lua` 中为每个语音类型单独配置
- 需要对应的 `assets_model()` 模型别名注册
- 构建后生效，需要重新构建项目

## 方案B（备选，已废弃）

之前尝试在 `_vastModifier.lua` 的 `_model` modifier 中添加 `DZ_SetUnitPortrait` 调用。这种运行时补丁方式不如方案A彻底。

## 总结对比

| 方案 | 位置 | 机制 | 优点 | 缺点 |
|---|---|---|---|---|
| **A（推荐）** | `assets/speech.lua` | SLK 物编层直接设定正确模型 | War3 原生，肖像自动正常 | 需每个语音单独配置 |
| **B（已废弃）** | `_vastModifier.lua` | 运行时 `DZ_SetUnitPortrait` 补丁 | 全局生效无需配置 | 依赖 _Portrait 命名约定，不彻底 |
