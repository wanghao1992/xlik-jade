# 将已有地形图应用到 xlik 项目

## 前置准备

- 地形图文件：`xxx.w3x`
- xlik 项目目录：`projects/<项目名>/`

## 步骤

### 1. 解包地形图

```bash
w2l lni xxx.w3x
```

解包后生成 `map/`、`table/`、`resource/` 等目录。

### 2. 覆盖地形文件

地形核心文件在 `map/` 目录中：

```bash
xcopy /E /Y map\* projects\<项目名>\w3x\map\
```

| 文件 | 说明 | 必须 |
|---|---|---|
| `war3map.w3e` | 地形贴图 | 是 |
| `war3map.shd` | 阴影 | 推荐 |
| `war3map.wpm` | 路径网格 | 推荐 |
| `war3map.doo` | 装饰物 | 可选 |
| `war3mapUnits.doo` | 放置单位 | 可选 |
| `war3map.w3r` | 区域 | 可选 |
| `war3map.mmp` | 小地图 | 可选 |

**注意：** 不要覆盖 `war3map.j`（JASS 入口），xlik 有自己的 Lua 引擎入口。

### 3. 同步小地图

小地图文件必须是 `war3mapMap.blp`（BLP 格式），放在 `w3x/` 根目录：

```bash
copy 解包目录\war3mapMap.blp projects\<项目名>\w3x\war3mapMap.blp
```

如果解包出来的是 `.tga` 格式，需要用 WE 打开保存自动生成，或用工具转换。

### 4. 处理物编（可选）

如果新地形中有自定义单位/物品/技能，需要同步物编数据：

```bash
xcopy /E /Y table\* projects\<项目名>\w3x\table\
```

**注意：** 这会覆盖项目的物编数据。xlik 框架的 SLK 条目（`LK_UNIT_TOKEN`、视野技能等）会在构建时自动补充，不影响。

### 5. 构建测试

```bash
xlik run <项目名> -l
```

## 快捷流程（全量替换）

```bash
w2l lni 地形图.w3x
xcopy /E /Y map\* projects\项目名\w3x\map\
copy war3mapMap.blp projects\项目名\w3x\
xcopy /E /Y table\* projects\项目名\w3x\table\
```

## 常见问题

**Q：构建报错 `ACCESS_VIOLATION` / `exit status 1`？**
A：通常是因为地形文件中的单位/物品 ID 在物编中找不到定义。要么同步 `table/` 解决，要么只替换地形层（`war3map.w3e` + `war3map.shd` + `war3map.wpm`）不替换放置物。

**Q：小地图不更新？**
A：检查文件名必须是 `war3mapMap.blp`（BLP 格式，区分大小写），放在 `w3x/` 根目录。
